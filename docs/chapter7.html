Section 7.1

UPS Specific Requirements

An Uninterruptible Power Supply makes one absolute promise to the load: when mains power fails, the load never knows. That promise translates into five hard engineering requirements that shape every BMS decision for a UPS battery: always-ready state, sub-10ms switchover, sustained backup at rated load, rapid recharge, and recovery from full discharge. Each requirement creates a unique challenge for LFP chemistry that the BMS must solve.

① Always Ready — Float State
A UPS battery must be at 100% SoC at all times — it cannot be partially discharged. This requires a float charging state where the BMS holds the pack at a stable voltage indefinitely without overcharging. For LFP: float at 3.38–3.40V/cell (pack 54.1–54.4V). This is the most unique operational mode of a UPS BMS, not present in EV or pure ESS applications.
② Instant Response — <10ms
IEC 62040-3 Class 3 specifies output voltage interruption ≤10ms. The battery DSG FET must already be closed (or close within microseconds) when mains fails — there is no time for the BMS to "decide" to connect. This means the BMS cannot open the DSG FET for non-critical conditions during mains-connected float — only true faults warrant FET opening on standby.
③ Sustain Rated Load
During an outage, the BMS must sustain the rated load until either mains restores or the battery reaches UVP (2.5V/cell). SoP discharge limit must match the UPS inverter's rated power. A 3kVA UPS at 0.8 PF = 2.4kW load. At 51.2V pack: I = 2400/51.2 = 46.9A continuous. The BMS must sustain this for the full backup duration without throttling.
④ Rapid Recharge
After an outage event, the UPS must return to 100% SoC as quickly as possible — the next outage may follow within hours. LFP accepts 0.5C continuous charge safely, so a 280Ah pack can recharge at 140A. Full recharge from 0% to 100%: 280Ah / 140A = 2 hours. The BMS must allow maximum charge current immediately after discharge — not throttle "for safety."
⑤ Deep Discharge Recovery
If mains fails for an extended period, the battery may fully discharge to UVP. The BMS must safely recover from this state using a pre-charge recovery sequence before allowing full current. LFP cells below 2.5V need care — copper dissolution risk at <2.0V. A locked-out BMS requires controlled recovery, not simply connecting a charger at full current.

Float Charging — The UPS-Specific State

Float charging is a state unique to standby power applications. The battery sits fully charged, connected to a constant voltage source, for months or years at a time. For lead-acid, float is straightforward — the chemistry tolerates continuous overcharge at low current. For LFP, float requires careful BMS management: the wrong float voltage slowly destroys the battery.

Why 3.38V, Not 3.65V for Float
3.65V/cell is the maximum charge voltage — used during CC/CV charging to reach 100% SoC quickly. Holding LFP at 3.65V continuously accelerates SEI layer growth on the anode, which is the dominant calendar aging mechanism. At 3.65V float, the electrolyte is under maximum oxidative stress 24/7. Research shows LFP held at 3.65V for 10 years retains only ~62% capacity. The same cells held at 3.38V retain ~92%. The BMS must transition to float voltage immediately after reaching 100% SoC — never hold at charge voltage.
Float SoC: ~95–100%
At 3.38V/cell float, LFP sits at approximately 95–98% SoC. This is not a problem for UPS — the 2–5% headroom is negligible for backup time (a 5kWh pack at 95% SoC has 4.75kWh — barely noticeable). What matters is keeping SoC high enough that full backup time is available. The BMS periodically checks: if pack voltage drifts below 3.35V/cell (SoC ≈ 90%), it initiates a top-up charge cycle back to 3.40V float.
Float Trickle Current
At float voltage with a fully charged battery, the BMS will see a small trickle current (~50–200mA) flowing from the rectifier into the pack — compensating for self-discharge and leakage. This is normal. If trickle current is abnormally high (>500mA sustained), the BMS should log a warning: it indicates a cell with elevated self-discharge (degraded cell) or an internal leakage path. Monitoring float current is a free SoH indicator.
BMS Float State Machine
The BMS float state is a separate entry in the state machine (between CHARGE and IDLE). In FLOAT: CHG FET open (rectifier connected directly through a current-limiting stage), DSG FET closed (ready for instant discharge). Monitoring: cell voltage every 10ms (same as normal), top-up trigger at V < 3.35V/cell, transition to DISCHARGE on load demand, and calendar aging accumulation via RTC (Chapter 6 Arrhenius integral).

Float State Firmware

/* UPS float charging state — runs every 1s */ #define FLOAT_TARGET_V 3.390f /* V per cell — 3.39×16 = 54.24V */ #define FLOAT_TOPUP_V 3.350f /* Trigger top-up below this */ #define FLOAT_TRICKLE_WARN 0.500f /* Warn if float current > 500mA */ void BMS_FloatState_Run(BMS_State_t *bms) { float v_avg = bms->pack_voltage / 16.0f; /* Check for top-up needed */ if (v_avg < FLOAT_TOPUP_V) { bms->state = STATE_CHARGE; /* Brief CC/CV cycle to restore SoC */ Log_Write(LOG_INFO, EVT_FLOAT_TOPUP, (int16_t)(v_avg*1000), 0xFF); return; } /* Monitor trickle current anomaly */ if (fabsf(bms->pack_current) > FLOAT_TRICKLE_WARN) { bms->float_anomaly_count++; if (bms->float_anomaly_count > 10) { /* 10s sustained */ Log_Write(LOG_WARN, EVT_FLOAT_OVERCURRENT, (int16_t)(bms->pack_current*1000), 0xFF); bms->float_anomaly_count = 0; } } else { bms->float_anomaly_count = 0; } /* Accumulate calendar aging (Arrhenius) */ BMS_AccumulateCalendarAging(bms, bms->temp_avg + 273.15f); /* DSG FET must remain CLOSED — ready for instant backup */ GPIO_SetFET(FET_DSG, FET_CLOSED); /* Send CAN status — SoC ~98%, FLOAT mode flag */ bms->can_status_flags |= CAN_FLAG_FLOAT_MODE; }

Backup Time Calculation

Backup time is the first question every UPS customer asks. The BMS must not only compute it accurately but must also account for the multiple factors that make real backup time less than the theoretical calculation — and communicate this to the user via CAN.

Worked Example: 3kVA UPS with 16S 280Ah LFP Pack
Pack capacity: 280Ah × 51.2V = 14,336 Wh = 14.3kWh
Load power: 3kVA × 0.8 PF = 2,400W
Theoretical time: 14,336 / 2,400 = 5.97 hours
Actual time after deductions:
− Inverter efficiency (90%): 14,336 × 0.90 = 12,902 Wh usable
− DoD limit (95%): 12,902 × 0.95 = 12,257 Wh
− Temperature derate (25°C): ×1.0 (no derate)
− Peukert factor (0.5C ≈ k=1.05): ×0.96
Actual backup: 12,257 × 0.96 / 2400 = 4.90 hours
Why Real < Theoretical:
1. Inverter losses: DC→AC conversion ~8–12% loss. Always include.
2. DoD limit: BMS cuts off at 2.5V/cell — not all stored energy is extractable at full power.
3. Peukert effect: At high current, apparent capacity reduces. LFP has lower Peukert exponent (k≈1.05) than lead-acid (k≈1.2), but effect still applies at high C-rates.
4. Temperature: At 0°C, LFP delivers ~82% of 25°C capacity — a cold server room or outdoor cabinet dramatically cuts backup time.
5. SoH: An aged pack at 85% SoH delivers 85% of its rated backup time.
Theoretical backup time
t = (C_Ah × V_nom × η_inv) / P_load
η_inv = inverter efficiency (~0.90). Always multiply pack Wh by inverter efficiency before dividing by load.
Peukert-corrected capacity
C_act = C_rated × (I_rated/I_act)^(k−1)
LFP k≈1.05. At 1C discharge (I_act = I_rated): C_act = C_rated (no effect). At 2C: C_act ≈ 0.95×C_rated. LFP much better than lead-acid (k≈1.2).
Temperature-adjusted backup time
t_T = t_25 × η(T) × SoH
η(0°C) ≈ 0.82, η(−20°C) ≈ 0.60. BMS reports t_T via CAN (time-to-empty estimate).
Time to empty (BMS calculation)
TTE = (SoC × C_full × V × η_inv) / P_load
Computed by BMS in real-time. Updated every 10s. Sent via CAN 0x356 as part of SoF reporting.

Deep Discharge Recovery

In a prolonged mains outage, the UPS battery fully discharges. The BMS trips the UVP at 2.5V/cell and latches the discharge FET open. When mains returns, the BMS cannot simply allow full charge current — cells below 2.5V require a pre-charge recovery sequence to avoid copper dissolution damage and thermal stress.

Step 1: UVP Latch (t=0)
BMS detects one or more cells below 2.5V. Opens DSG FET. Logs fault event with RTC timestamp. Broadcasts CAN 0x35A: UVP fault flag set, SoC=0%. UPS inverter stops. Backup session complete.
Step 2: Mains Restore Detection
BMS detects rectifier voltage on charge terminals (V > 10V on CHG pin). BMS recognises: pack is in deep discharge lockout, charger is now available. Initiates recovery sequence. Does NOT open CHG FET at full current yet.
Step 3: Recovery Pre-Charge (0.05C limit)
BMS enables CHG FET with current limit set to 0.05C (14A for 280Ah). This "trickle recovery" phase continues until all cells rise above 2.8V. Duration: approximately 30–60 minutes. During this phase, BMS monitors dT/dt — any temperature spike indicates damaged cell that may not accept charge.
Step 4: Cell Validation
Once all cells reach 2.8V, BMS pauses for 5 minutes and measures OCV. If any cell's OCV drops back below 2.5V within 5 minutes (indicating high self-discharge — likely separator damage), that cell is flagged and the pack is placed in DEGRADED mode. Log event with cell index.
Step 5: Normal Charge Resumption
If all cells pass validation, BMS transitions to normal CHARGE state (CC at 0.5C, CV to 3.65V/cell). Full recharge time from 0%: approximately 2 hours. Logs cycle count increment. After full charge, transitions to FLOAT at 3.38V/cell.
Step 6: UPS Ready
BMS broadcasts CAN 0x35C: Discharge Enable flag set. SoC restored. Float mode active. UPS is now fully operational again. Total time from mains-restore to UPS-ready: typically 2.5–3 hours depending on depth of discharge.
⚠
Never Charge a Deep-Discharged LFP at Full Current

Cells below 2.5V are electrochemically stressed. Immediately applying 0.5C charge causes a sudden thermal event in the SEI layer as the intercalation sites re-equilibrate. The correct maximum recovery current is 0.05C until cells reach 2.8V. This is also why lab "reviving" of deeply discharged cells by connecting them directly to a bench supply at 5A is a battery-destroying practice — even if it "works," it permanently damages the SEI layer.

Section 7.2

Home ESS Requirements

A home energy storage system sits in a garage or utility room, cycling once per day for ten to fifteen years, under the critical eye of a homeowner who does not have engineering training but has paid $8,000 for the system. The requirements are fundamentally different from UPS: maximise calendar life, guarantee indoor safety, enable accurate user-visible SoC, and integrate seamlessly with solar and grid tariffs.

Daily Cycling Profile

Partial Cycles and SoH
Most home ESS cycles are partial: charge to 80–90% (avoiding Li plating risk at 100%), discharge to 20–30% (protecting against UVP events). A 60–70% DoD cycle causes less stress than 100% DoD. The BMS tracks cycle count as full-cycle-equivalents: N_equiv += ΔAh / (2 × C_full). This means partial cycles accumulate fractionally — a 50% DoD cycle counts as 0.5 full cycles. Result: an ESS doing 1.5 daily partial cycles accumulates ~550 full equivalent cycles per year.
SoC Window Optimisation
For maximum calendar life in ESS, the optimal SoC window is 20–90%. Never charging to 100% reduces the time spent at high SoC (high-stress state for SEI growth). The BMS can offer a "calendar life mode" that caps charge at 90% SoC — communicated to the inverter as a reduced CVL in CAN 0x351. Homeowners trade ~10% capacity for ~20% longer battery life — a compelling option for systems targeting 15-year operation.
Silent Operation Requirement
Unlike UPS systems in server rooms, home ESS is in a living space. The BMS and associated hardware must be silent: no cooling fans, no contactor click during normal operation. This means: passive cooling (design for <45°C pack temperature at 0.5C), solid-state FET switching (no relay sound), and charge/discharge transitions smooth enough not to create audible inverter artifacts. The BMS derating curve (Chapter 3) must be aggressive enough to never need emergency fan-cooling.

Safety for Indoor Home Installation

Home energy storage is one of the most safety-critical consumer applications ever deployed at scale. A battery failure in a garage adjacent to a bedroom is a life-threatening event. LFP chemistry provides the first line of defence — but the BMS provides the intelligent second line.

LFP Indoor Safety — The NFPA 855 Advantage

NFPA 855 §15.3 allows reduced installation clearances for ESS that: (1) use LFP chemistry, (2) have a UL 9540A-tested propagation rating, (3) communicate fault status to the building fire alarm system via BMS CAN/Modbus. A standard NMC system requires 3-foot clearances from walls and openings. A BMS-equipped LFP system with fire alarm integration can be wall-mounted with reduced clearances — enabling installations that NMC systems physically cannot achieve in typical garages.

BMS Fault Response for Home ESS
A home ESS fault response must be: (1) silent initially — no immediate alarm that frightens the family, (2) logged immediately with full context, (3) escalated via CAN to the inverter/gateway which then notifies the homeowner via app push notification, (4) require a deliberate reset action (not automatic). A BMS that cries wolf with false alarms that wake homeowners at 3am gets switched off — creating a more dangerous unmonitored state.
User-Visible SoC Accuracy
Homeowners look at the app display and see "73% charged." They do not understand that LFP's flat OCV curve makes SoC estimation difficult between 20–80%. The BMS must provide ±5% accuracy visible to the user — achieved by: frequent OCV corrections at end of charge/discharge, coulomb counting with temperature correction, and clamping display SoC to 0% only when discharge FET opens (not at 5% estimated SoC). Never show "0%" while the pack can still deliver power.
Dynamic Power Management
A solar + ESS home system has time-of-use (TOU) tariffs: charge during cheap solar hours, discharge during expensive evening peak. The BMS must work with the inverter's power management algorithm: accept charge current setpoint commands via CAN, enforce cell-level limits that override setpoint (never exceed OVP/OCP even if inverter requests it), and provide SoP to the inverter so it can correctly plan how much solar excess to store vs export.
Section 7.3

Why LFP Fits Perfectly

Point-by-point: LFP material properties mapped to UPS and Home ESS engineering requirements — why this chemistry is uniquely suited.

⚡
Chemistry as System Design

The best BMS firmware cannot overcome a poorly chosen cell chemistry. LFP's properties were not accidental — they emerged from Goodenough's olivine crystal research (1997) and happen to align almost perfectly with stationary energy storage requirements. Each property below solves a real installation engineering problem.

Property Deep Dives

🔬
Property 1: Thermal Stability — The P–O Bond Argument

LFP's olivine structure (LiFePO₄) has phosphate groups where the P–O bond requires 544 kJ/mol to break. By comparison, the Co–O bond in LiCoO₂ requires only ~150 kJ/mol. This means the oxygen release that initiates thermal runaway in NMC/NCA cells does not occur in LFP until temperatures exceed 270°C — versus ~150°C for NMC. The practical consequence: an LFP cell that reaches 100°C during a fault will self-cool. An NMC cell at 100°C is already on the runaway cascade. For indoor installations — garages, basement utility rooms, data center UPS rooms — this is not a preference but a code requirement. NFPA 855 and UL 9540A both impose significantly stricter installation requirements on chemistries with lower thermal runaway onset temperatures.

🔄
Property 2: Cycle Life — Volume Change Physics

During Li-ion intercalation, the host crystal lattice expands and contracts as lithium ions enter and leave. LFP exhibits only ~6.8% volume change per cycle (a and b lattice parameters shift, c is nearly fixed). NMC811 exhibits ~5–7% but with anisotropic strain that causes microcracking after 500–800 cycles. The practical result: LFP cells from reputable manufacturers regularly demonstrate 3,000–5,000 cycles to 80% capacity at 1C rate, 25°C. At 0.5C (common ESS rate), cycle life extends further. A home ESS completing one full cycle per day reaches 3,000 cycles in 8.2 years — well within the 10–15 year target. UPS batteries completing fewer cycles (standby with occasional mains failures) extend even further.

📊
Property 3: Flat OCV — Blessing and Engineering Challenge

The two-phase Li intercalation mechanism in LFP produces a flat OCV plateau from ~20–80% SoC. This plateau sits at 3.20–3.35V/cell with less than 30mV variation across 60% of the capacity. For inverter design this is excellent: the DC bus voltage barely moves, simplifying the inverter's boost/buck stage design and reducing output THD variation. But for BMS SoC estimation it creates a challenge — you cannot use OCV to determine SoC in the plateau region. Solution: (1) Use coulomb counting during the plateau. (2) Use OCV corrections only at the plateau endpoints (charge transition at ~3.45V, discharge transition at ~3.10V). (3) Apply EKF to catch accumulated drift. This is exactly the hybrid estimation algorithm in Chapter 2 Section 2.6.

🌡️
Property 4: Temperature Range — Discharge vs Charge Asymmetry

LFP can discharge at −20°C (with capacity derating: ~70% at −20°C versus 25°C baseline). However, charging below 0°C causes lithium plating on the anode — metallic lithium dendrites that create short-circuit risk and permanent capacity loss. The BMS must enforce this asymmetry: DSG FET remains enabled to −20°C, CHG FET is blocked below 0°C. For outdoor installations (garden sheds, garages in cold climates), this means the home ESS remains available to supply power during a cold-night power outage, but will not accept solar charge until ambient warms. Some premium systems add a small self-heating circuit (driven by pack energy) to bring cell temperature to 5°C before enabling charging — the BMS controls this as a pre-charge heating state.

Section 7.4

EV BMS vs ESS BMS

Electric vehicle BMS design priorities differ fundamentally from stationary storage. Applying EV BMS assumptions to an ESS produces a system optimized for the wrong problem.

⚠
The EV Engineer's ESS Mistake

Many BMS engineers trained on EV projects bring EV assumptions into ESS design: maximize energy density, optimize for peak power bursts, design cooling for 3–5C charge rates, tolerate 1–2% SoC error (GPS can verify range). In an ESS, all of these priorities invert. The result is a system that performs adequately but degrades 50% faster than necessary, costs 30% more than required, and occasionally fails safety inspections.

Critical Design Differences

C-Rate: The Fundamental Difference
An EV accelerating at 0–100 km/h in 4 seconds draws 3–5C from the battery. An ESS accepting morning solar surplus charges at 0.1–0.3C. This 10–50× difference in current rate changes nearly every hardware decision: shunt resistor sizing, FET RDS(on) budget, thermal pad area, wire gauge, protection response timing. An EV BMS designed for 5C continuous does not fail in an ESS; it simply over-engineers thermal management while under-optimizing for the long float periods that dominate ESS operation.
Balancing Window: Float vs Drive
EV cells balance once per charge cycle at the top-of-charge plateau. The balancing window is brief (minutes). ESS cells in float mode spend hours or days near the same SoC — passive balancing produces significant parasitic heat with no benefit. Active balancing (energy shuttling via inductors or switched capacitors) is more complex and expensive, but prevents continuous thermal dissipation and is more effective for maintaining pack uniformity over years of float operation.
Communication: Inverter Ecosystem Lock-in
EV BMS communicates with the vehicle's powertrain ECU using proprietary CAN protocols. ESS BMS must communicate with third-party inverters — Victron, SMA, Growatt, Deye, Huawei — using published protocols: PYLON CAN (widely cloned), Victron VE.CAN, SMA CAN, generic Modbus RTU RS485. BMS firmware that hard-codes one inverter brand fails in the field. The ESS BMS must support at least 3 protocol profiles selectable via DIP switch or commissioning command.
SoC Accuracy: Energy vs Range
EV SoC error of ±5% means ±15km range error on a 300km vehicle — acceptable. ESS SoC error of ±5% on a 10kWh system means ±500Wh billing error in a TOU arbitrage scenario. Over 365 cycles, that is 182kWh of mistracked energy — potentially €30–50/year of misallocated cost in high-tariff markets. ESS BMS must achieve ±2–3% via frequent OCV recalibrations and the EKF algorithm from Chapter 2. UPS BMS targets ±1% to provide accurate runtime estimates to building management systems.
State Machine Complexity
EV BMS state machine centres around drive states: PARK, DRIVE, REGEN, CHARGE, DCFC. ESS BMS adds states without EV equivalent: FLOAT (UPS standby), SOLAR_CHARGE (MPPT current source input), GRID_CHARGE (AC coupled), GRID_EXPORT (feed-in), PEAK_SHAVE, TOU_HOLD. Chapter 6's 11-state machine is ESS-oriented. Mapping an EV state machine onto an ESS control loop produces a BMS that cannot distinguish between "float fully charged" and "bulk charging" — leading to continuous charge current at full SoC.
Regulatory Path: IEC 62619 vs ECE R100
EV battery systems certify to UNECE Regulation R100 (vehicle safety) plus OEM-specific requirements. ESS certifies to IEC 62619 (stationary Li-ion safety), UL 9540A (thermal runaway propagation), UL 1973 (stationary BMS), and NFPA 855 (installation). These are completely different test suites. An EV-certified battery cannot be re-labelled as ESS-certified. Engineers crossing from EV to ESS programmes commonly underestimate this regulatory gap — especially the installation fire code requirements that have no EV equivalent.

C-Rate Impact: EV vs ESS Thermal Profile

📐
Design Rule: Size Thermal Management for Actual Operating Rate

Heat generation scales as I². An ESS operating at 0.3C generates (0.3)² = 0.09 relative heat units. An EV at 3C generates (3)² = 9 — exactly 100× more heat per unit resistance. This means an ESS with passive air cooling (adequate for 0.3C) cannot be directly used in an EV application, and an EV's liquid cooling system is massively over-specified for an ESS. Right-sizing thermal management to the actual C-rate reduces cost, complexity, and maintenance burden significantly.

Chapter Summary

10 Design Principles

The application-layer principles that govern BMS design for UPS and home energy storage systems.

01
Float ≠ Full Charge
UPS float voltage must be 3.38–3.40V/cell, not 3.65V. Float at rated voltage causes SEI stress and reduces 10-year capacity from 92% to 62%. The BMS implements a separate FLOAT state in its state machine — not a continuation of the CHARGE state.
02
DSG FET Never Opens in Float
A UPS BMS must keep the discharge FET permanently closed during standby. The IEC 62040-3 Class 3 <10ms switchover requirement cannot be met if the BMS must re-enable the DSG FET after mains failure. BMS is not on the critical switchover path.
03
Deep Discharge Recovery Protocol
Cells below 2.5V/cell must recover at 0.05C pre-charge until reaching 2.8V before normal charging resumes. Full current on deeply discharged LFP cells causes permanent capacity loss and copper dissolution at the anode below 2.0V.
04
Home ESS: 20–90% SoC Window
Cycling within 20–90% SoC instead of 0–100% extends cycle life by 40–60%. The BMS must communicate usable capacity (not total capacity) to the inverter via CAN charging voltage/current setpoints — the inverter must never see the full cell voltage range.
05
LFP Chemistry = Indoor Installation
NFPA 855 §15.3 allows reduced clearances for LFP + UL 9540A + BMS-to-fire-alarm communication. This is not a preference — NMC/NCA systems require 3-foot clearances from walls that make typical garage/basement installations code-non-compliant.
06
Partial Cycles Count Fractionally
ESS daily cycling is rarely a complete cycle. The BMS must track: N_equiv += ΔAh/(2×C_full) per charge/discharge event. After 15 years × 365 partial cycles, accumulated equivalent cycles determine replacement decision — not calendar time alone.
07
ESS BMS ≠ EV BMS
EV BMS is optimised for 3–5C burst rates, liquid cooling, brief balancing windows, and ISO 15765 CAN. ESS BMS optimises for 0.1–0.3C continuous rates, passive cooling, extended float balancing, and inverter-ecosystem protocol compatibility (PYLON, Modbus, VE.CAN).
08
Backup Time Formula
t = (SoC × C_full × V_nom × η_inv) / P_load
With Peukert (k≈1.05), temperature (η≈0.82 at 0°C), and SoH multiplier. The BMS must publish all component variables via CAN for the building management system to calculate runtime accurately.
09
Silent First, Escalate Second
Home ESS fault response must be silent initially (log only), then escalate via CAN to gateway, then push-notify the homeowner. A BMS that triggers audible alarms at 3am for a minor cell imbalance event gets switched off permanently — creating a more dangerous unmonitored state than no alarm at all.

Key parameters, formulas, and thresholds for UPS and Home ESS BMS engineering.

Key Formulas

Backup Time (UPS)
t = (SoC × C_full × V_nom × η_inv) / P_load
η_inv ≈ 0.92–0.96; V_nom = 3.2V/cell × N_series; C_full in Ah
Temperature Derating
η(T) = 1 − 0.009 × (25 − T_celsius)
Valid for T = 0°C to 45°C. η(0°C) ≈ 0.775; η(45°C) ≈ 1.18 → cap at 1.0
Peukert Correction
C_eff = C_rated × (I_rated / I_actual)^(k−1)
k ≈ 1.05 for LFP (nearly ideal); minimal effect at low ESS C-rates
Partial Cycle Counting
N_equiv += ΔAh / (2 × C_full)
Accumulate per charge and discharge event; sum = total equivalent full cycles
Float Trickle Current Check
I_trickle = (V_float − OCV) / R_internal
Normal: 50–200mA. Warning: >500mA indicates degraded cell or internal leakage
Calendar Aging (Arrhenius)
k_age = exp(−Eₐ/kT) / exp(−Eₐ/kT_ref)
Eₐ ≈ 0.35 eV LFP; T_ref = 298.15K (25°C); every +10°C doubles aging rate
