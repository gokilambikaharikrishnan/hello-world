Section 9.1

Firmware Design Philosophy

BMS firmware is safety-critical embedded software. Unlike an app or a web service, a firmware bug can destroy a battery pack, ignite a fire, or silently under-report SoC until a UPS fails on power cut. The design philosophy must reflect this reality.

Core Principles

Principle 01
Safety First, Features Second
Protection thresholds are hard-coded constants — never overwritten by CAN commands without authenticated write + watchdog confirmation. An attacker must not be able to raise OVP via a CAN frame.
Principle 02
Deterministic Execution
No dynamic memory allocation (malloc/free) after init. No recursion in safety paths. All buffers are static. Execution time of every ISR and task must be bounded and measured.
Principle 03
Defensive Programming
Assert every assumption. Validate every input. Check pointer != NULL before dereference. Range-check every sensor reading before using it in a decision. Return explicit error codes.
Principle 04
Fail-Safe Defaults
On any undefined state or assert failure, open both DSG and CHG FETs, log the fault, and halt or reset. Never continue operating in an unknown state. The safe default is to disconnect the pack.
Principle 05
Minimal Trusted Core
The protection loop (read → compare → trip FET) is implemented in <100 lines of C with no dependencies. It runs in the fastest interrupt. Everything else is application-layer.
Principle 06
Observable System
Every state change, fault event, and calibration write is logged with a 32-bit timestamp. The log is NVM-backed. Engineers must be able to reconstruct what happened from the log alone.

MISRA C:2012 — What It Actually Means

MISRA C is a coding standard, not a programming language subset. It constrains dangerous C patterns to reduce undefined behaviour. For a safety-critical BMS these rules matter:

RuleWhat it forbidsWhy it matters
Rule 1.3Undefined behaviour (signed overflow, OOB array)Signed overflow is UB in C — compilers may silently optimise it away
Rule 11.3Pointer cast between object typesAliasing violations cause data corruption on optimised builds
Rule 15.5Single point of exit per functionReduces missed cleanup, easier static analysis
Rule 17.2Recursive function callsStack depth becomes unbounded and unanalysable

⚡ Pragmatic Adoption

Full MISRA C compliance requires a commercial static analyser (LDRA, PC-lint, Polyspace). For a start-up or hobbyist BMS, adopt the most impactful rules: no malloc, no recursion, explicit types, single exit. Use cppcheck --enable=all for free partial coverage.

Section 9.2

Layered Firmware Architecture

A well-structured BMS firmware separates hardware-specific code from application logic. The 4-layer model ensures portability across STM32 variants and makes unit testing possible without real hardware.

The Four Layers

▲ Layer 4 · Application Layer
Files: app_bms.c, app_soc.c, app_balance.c, app_can.c, app_nvm.c
Responsibility: BMS business logic — SoC algorithm, balancing decisions, CAN message encoding, fault manager, power state machine.
Depends on: Middleware API only. Never calls HAL directly. No register addresses.
▲ Layer 3 · Middleware / Services
Files: mw_filter.c, mw_coulomb.c, mw_event_log.c, mw_scheduler.c
Responsibility: Algorithm implementations agnostic to hardware — IIR filters, Coulomb counter, circular event log, cooperative task scheduler.
Depends on: Driver API. Can be unit-tested on host PC.
▲ Layer 2 · Driver Layer
Files: drv_afe.c, drv_can.c, drv_flash.c, drv_temp.c
Responsibility: Device-specific drivers for AFE (BQ76952), CAN peripheral, flash/EEPROM, NTC thermistors. Exposes clean C API; hides register details.
Depends on: HAL API. Swappable per chip variant.
▲ Layer 1 · HAL / BSP
Files: stm32g4xx_hal_*.c (vendor), bsp_init.c, bsp_gpio.c
Responsibility: STM32 HAL (auto-generated by CubeMX), clock tree, pin assignments, peripheral init. Board Support Package maps logical names to physical pins.
Depends on: Silicon vendor CMSIS. Never modified — regenerated by CubeMX.

Startup & Init Sequence

/* main.c — startup order matters */
int main(void) {
    HAL_Init();               /* SysTick @ 1 ms, NVIC defaults */
    SystemClock_Config();     /* 170 MHz from PLL (STM32G474) */
    BSP_GPIO_Init();          /* FET pins OUTPUT LOW (safe) */

    DRV_AFE_Init();           /* BQ76952 I2C config, OVP/UVP set */
    DRV_CAN_Init(250000U);    /* 250 kbps, filters 0x351-0x380 */
    DRV_Flash_Init();         /* NVM partition verify + CRC */

    MW_Scheduler_Init();      /* register tasks, periods */
    MW_EventLog_Init();       /* restore NVM log head pointer */

    APP_BMS_Init();           /* restore SoC, check wake reason */
    APP_CAN_Init();           /* send 0x351 announcement frame */

    MW_Scheduler_Run();       /* never returns */
}
ℹ️ Cooperative Scheduler vs RTOS

For <16 cells, 1 MCU, a simple cooperative round-robin scheduler is sufficient and easier to certify than FreeRTOS. Use an RTOS only if you need preemption (e.g., <1 ms protection response competing with 50 ms CAN frame assembly). The STM32G4 protection ISR runs independent of the scheduler anyway.

Section 9.3

Functional Module Implementations

Each BMS firmware module has a well-defined API, owns its data, and exposes only what other layers need. Below are the 7 core modules with C code examples for the 16S1P reference design.

Module 01 · Measurement (drv_afe.c + app_meas.c)

Reads cell voltages and temperatures from the BQ76952 via I2C, applies IIR smoothing, and stores in a shared data structure. All voltages stored as uint16_t in millivolts to avoid float.

/* app_meas.h — public types */
#define CELL_COUNT   16U
#define TEMP_COUNT    3U   /* top / mid / bottom NTC */

typedef struct {
    uint16_t cell_mv[CELL_COUNT]; /* 2800–3650 mV */
    int16_t  temp_dc[TEMP_COUNT]; /* deci-Celsius, -400..+850 */
    uint16_t pack_mv;             /* sum of cells */
    int32_t  current_ma;          /* signed: +charge, -discharge */
    uint8_t  valid;               /* bitmask: bit0=volt, bit1=temp, bit2=curr */
} BMS_Meas_t;

extern BMS_Meas_t g_meas; /* single shared instance */
/* app_meas.c — measurement task (runs every 100 ms) */
void APP_Meas_Task(void) {
    uint16_t raw[CELL_COUNT];
    int16_t  temps[TEMP_COUNT];

    if (DRV_AFE_ReadVoltages(raw, CELL_COUNT) != HAL_OK) {
        g_meas.valid &= ~0x01U;   /* invalidate voltage data */
        APP_Fault_Set(FAULT_AFE_COMM);
        return;
    }

    uint32_t sum = 0U;
    for (uint8_t i = 0U; i < CELL_COUNT; i++) {
        /* IIR filter: y = 0.8*y + 0.2*x  (fixed-point: *10 scale) */
        g_meas.cell_mv[i] = (uint16_t)(
            ((uint32_t)g_meas.cell_mv[i] * 8U + (uint32_t)raw[i] * 2U) / 10U
        );
        sum += g_meas.cell_mv[i];
    }
    g_meas.pack_mv = (uint16_t)(sum / 1U); /* store as mV (fits uint16_t for <60V) */
    g_meas.valid |= 0x01U;
}
✅ IIR Filter Coefficient Choice

0.8/0.2 (α=0.2) gives ~5 sample time constant. At 100 ms period that's ~500 ms settling. For UPS float voltage accuracy use α=0.05 (0.95/0.05) — slower but eliminates noise from load transients. Scale factor 10 keeps fixed-point error <0.1 mV.

Module 02 · Protection (app_protect.c)

The protection module is the most critical path. It compares measurements against thresholds and trips the appropriate FET. It must run fast and have no dependencies beyond the measurement struct.

/* app_protect.h */
typedef enum {
    PROT_NONE   = 0x00,
    PROT_OVP    = 0x01,  /* over-voltage */
    PROT_UVP    = 0x02,  /* under-voltage */
    PROT_OCP_D  = 0x04,  /* over-current discharge */
    PROT_OCP_C  = 0x08,  /* over-current charge */
    PROT_OTP    = 0x10,  /* over-temperature */
    PROT_UTP    = 0x20,  /* under-temperature charge */
    PROT_SCP    = 0x40,  /* short-circuit */
} Prot_Fault_t;

/* Thresholds — hard-coded, not RAM-configurable */
#define OVP_MV        3650U   /* per cell */
#define UVP_MV        2800U
#define OVP_HYST_MV     50U   /* re-engage after OVP-hyst */
#define OCP_D_MA      50000L  /* 50 A discharge */
#define OCP_C_MA      30000L  /* 30 A charge */
#define OTP_DC          550   /* 55.0 °C */
#define UTP_CHARGE_DC  (-50)  /* -5.0 °C, disable charge only */
/* app_protect.c */
static Prot_Fault_t s_active = PROT_NONE;

void APP_Protect_Task(void) {
    if ((g_meas.valid & 0x01U) == 0U) { return; } /* no valid data */

    Prot_Fault_t new_fault = PROT_NONE;

    /* --- Voltage checks --- */
    for (uint8_t i = 0U; i < CELL_COUNT; i++) {
        if (g_meas.cell_mv[i] > OVP_MV)  { new_fault |= PROT_OVP; break; }
        if (g_meas.cell_mv[i] < UVP_MV)  { new_fault |= PROT_UVP; break; }
    }

    /* --- Current checks --- */
    if (g_meas.current_ma >  (int32_t)OCP_C_MA) { new_fault |= PROT_OCP_C; }
    if (g_meas.current_ma < -(int32_t)OCP_D_MA) { new_fault |= PROT_OCP_D; }

    /* --- Temperature checks --- */
    for (uint8_t j = 0U; j < TEMP_COUNT; j++) {
        if (g_meas.temp_dc[j] > OTP_DC)        { new_fault |= PROT_OTP; }
        if (g_meas.temp_dc[j] < UTP_CHARGE_DC) { new_fault |= PROT_UTP; }
    }

    /* Trip / clear FETs */
    if (new_fault != s_active) {
        s_active = new_fault;
        BSP_FET_SetDSG((new_fault & (PROT_UVP|PROT_OCP_D|PROT_OTP|PROT_SCP)) == 0U);
        BSP_FET_SetCHG((new_fault & (PROT_OVP|PROT_OCP_C|PROT_UTP))          == 0U);
        APP_EventLog_Write(EVT_PROT_CHANGE, (uint32_t)new_fault);
    }
}

Module 03 · State-of-Charge (app_soc.c)

SoC is estimated using a hybrid of Coulomb Counting (CC) and OCV-lookup, with periodic re-anchoring when the pack is at rest. The CC accumulator uses 64-bit integer arithmetic to avoid drift over long periods.

/* app_soc.h */
#define SOC_SCALE    1000U  /* internal: 0–1000 = 0.0–100.0 % */

typedef struct {
    uint16_t soc_ppt;       /* parts-per-thousand, 0–1000 */
    int64_t  cc_uah;        /* coulomb counter in µAh */
    uint8_t  anchored;      /* 1 = last CC anchor is valid */
    uint32_t anchor_ts;     /* HAL_GetTick() at last anchor */
} SoC_State_t;

extern SoC_State_t g_soc;
/* app_soc.c — Coulomb counter update (100 ms period) */
#define CC_PERIOD_MS   100U
#define CAPACITY_UAH   (280000000LL)  /* 280 Ah = 280,000,000 µAh */

void APP_SoC_CoulombUpdate(void) {
    /* current_ma is signed: +charge, -discharge */
    /* µAh += mA * 100ms / 3600s  =>  µAh += mA * 100 / 3600 */
    int64_t delta_uah = ((int64_t)g_meas.current_ma * CC_PERIOD_MS) / 3600LL;
    g_soc.cc_uah += delta_uah;

    /* Clamp to physical limits */
    if (g_soc.cc_uah > CAPACITY_UAH)  { g_soc.cc_uah = CAPACITY_UAH; }
    if (g_soc.cc_uah < 0LL)           { g_soc.cc_uah = 0LL; }

    g_soc.soc_ppt = (uint16_t)((g_soc.cc_uah * SOC_SCALE) / CAPACITY_UAH);
}
/* OCV re-anchor: called when |current| < 500 mA for 30 s */
/* LFP OCV lookup: 8 breakpoints (mV vs SoC ppt) */
static const uint16_t ocv_mv[8]   = {2800,3100,3200,3280,3320,3340,3380,3400};
static const uint16_t ocv_soc[8]  = {   0,  50, 100, 200, 400, 600, 850,1000};

static uint16_t OCV_Lookup(uint16_t mv) {
    if (mv <= ocv_mv[0]) { return ocv_soc[0]; }
    if (mv >= ocv_mv[7]) { return ocv_soc[7]; }
    for (uint8_t i = 1U; i < 8U; i++) {
        if (mv <= ocv_mv[i]) {
            /* linear interpolation (fixed-point) */
            uint16_t range_mv  = ocv_mv[i]  - ocv_mv[i-1U];
            uint16_t range_soc = ocv_soc[i] - ocv_soc[i-1U];
            uint16_t offset    = mv - ocv_mv[i-1U];
            return ocv_soc[i-1U] + (uint16_t)((uint32_t)offset * range_soc / range_mv);
        }
    }
    return 0U; /* unreachable */
}

void APP_SoC_AnchorOCV(void) {
    /* Use median cell voltage for flat OCV curve region */
    uint16_t mid_mv = g_meas.cell_mv[CELL_COUNT / 2U];
    uint16_t soc_from_ocv = OCV_Lookup(mid_mv);
    /* Re-anchor CC accumulator */
    g_soc.cc_uah    = ((int64_t)soc_from_ocv * CAPACITY_UAH) / SOC_SCALE;
    g_soc.anchored  = 1U;
    g_soc.anchor_ts = HAL_GetTick();
    APP_EventLog_Write(EVT_SOC_ANCHOR, (uint32_t)soc_from_ocv);
}

Module 04 · Balancing (app_balance.c)

Passive top balancing: enable the bleed resistor FET for cells above average voltage. Only runs when pack voltage is above 90% SoC to avoid wasting energy at low SoC.

/* app_balance.c — passive balancing decision (5 s period) */
#define BAL_ENABLE_SOC_PPT   900U   /* only balance above 90% */
#define BAL_DELTA_MV          10U   /* start balancing if Vcell > Vavg + 10 mV */

void APP_Balance_Task(void) {
    if (g_soc.soc_ppt < BAL_ENABLE_SOC_PPT) {
        DRV_AFE_SetBalance(0x0000U); /* all off */
        return;
    }

    /* Compute average voltage */
    uint32_t sum = 0U;
    for (uint8_t i = 0U; i < CELL_COUNT; i++) { sum += g_meas.cell_mv[i]; }
    uint16_t avg_mv = (uint16_t)(sum / CELL_COUNT);

    /* Build bitmask of cells to balance */
    uint16_t bal_mask = 0U;
    for (uint8_t i = 0U; i < CELL_COUNT; i++) {
        if (g_meas.cell_mv[i] > (uint16_t)(avg_mv + BAL_DELTA_MV)) {
            bal_mask |= (uint16_t)(1U << i);
        }
    }
    DRV_AFE_SetBalance(bal_mask);
}
⚡ Temperature Gate

Always gate balancing on temperature. If any NTC reads >45 °C, disable all balance FETs — the bleed resistors add heat. This is especially important in a sealed UPS enclosure where convection is limited.

Module 05 · CAN Communication (app_can.c)

The CAN module assembles PYLON-compatible frames and transmits them every 1 second. It also handles incoming charge voltage/current setpoints from the inverter (0x356 / 0x35C).

/* PYLON message set — 0x351 through 0x355 */
/* 0x351: Charge voltage limit + current limit */
void CAN_TX_0x351(void) {
    uint8_t data[8] = {0};
    uint16_t cv_limit = (uint16_t)(OVP_MV * CELL_COUNT); /* pack CV limit in 100mV */
    uint16_t ci_limit = (uint16_t)(OCP_C_MA / 100U);     /* 0.1 A per bit */
    uint16_t di_limit = (uint16_t)(OCP_D_MA / 100U);

    data[0] = (uint8_t)(cv_limit & 0xFFU);
    data[1] = (uint8_t)(cv_limit >> 8);
    data[2] = (uint8_t)(ci_limit & 0xFFU);
    data[3] = (uint8_t)(ci_limit >> 8);
    data[4] = (uint8_t)(di_limit & 0xFFU);
    data[5] = (uint8_t)(di_limit >> 8);
    /* data[6..7] = discharge voltage minimum */
    data[6] = (uint8_t)((UVP_MV * CELL_COUNT / 100U) & 0xFFU);
    data[7] = (uint8_t)((UVP_MV * CELL_COUNT / 100U) >> 8);

    DRV_CAN_Transmit(0x351U, data, 8U);
}

/* 0x355: SoC % and SoH % */
void CAN_TX_0x355(void) {
    uint8_t data[8] = {0};
    data[0] = (uint8_t)(g_soc.soc_ppt / 10U);   /* 0–100% */
    data[1] = 0U;
    data[2] = 100U;  /* SoH fixed 100 (no degradation model yet) */
    data[3] = 0U;
    DRV_CAN_Transmit(0x355U, data, 8U);
}

/* 0x356: Pack voltage, current, temperature */
void CAN_TX_0x356(void) {
    uint8_t data[8] = {0};
    int16_t pv = (int16_t)(g_meas.pack_mv / 10U);   /* 0.01V/bit */
    int16_t pc = (int16_t)(g_meas.current_ma / 100L); /* 0.1A/bit, signed */
    int16_t pt = g_meas.temp_dc[1];                   /* mid NTC */
    data[0]=(uint8_t)(pv & 0xFF); data[1]=(uint8_t)(pv>>8);
    data[2]=(uint8_t)(pc & 0xFF); data[3]=(uint8_t)(pc>>8);
    data[4]=(uint8_t)(pt & 0xFF); data[5]=(uint8_t)(pt>>8);
    DRV_CAN_Transmit(0x356U, data, 8U);
}

Module 06 · NVM / Flash (drv_flash.c)

Persistent storage uses an emulated EEPROM approach with two flash pages (ping-pong). Critical data: SoC anchor, event log, calibration. Never store protection thresholds in NVM — hardcode them.

/* drv_flash.h — NVM partition layout */
/* STM32G474 internal flash: 512 KB, pages 63+64 reserved for NVM */
#define NVM_PAGE_A      63U
#define NVM_PAGE_B      64U
#define NVM_PAGE_SIZE   2048U   /* bytes, STM32G4 */

typedef struct __attribute__((packed)) {
    uint32_t magic;          /* 0xBEEF1234 — valid marker */
    uint32_t seq;            /* write sequence counter */
    int64_t  cc_uah;         /* SoC Coulomb counter */
    uint16_t soc_ppt;        /* last known SoC */
    uint32_t cycle_count;    /* full cycles since manufacture */
    uint32_t crc32;          /* CRC of bytes [0..N-5] */
} NVM_Data_t;                /* 28 bytes */

HAL_StatusTypeDef DRV_Flash_WriteNVM(const NVM_Data_t *d);
HAL_StatusTypeDef DRV_Flash_ReadNVM(NVM_Data_t *d);

Module 07 · Event Logger (mw_event_log.c)

A circular log of 128 events stored in NVM. Each event has a type, 32-bit data, and millisecond timestamp. Critical for post-mortem fault analysis.

/* mw_event_log.h */
typedef enum {
    EVT_POWER_ON      = 0x01,
    EVT_POWER_OFF     = 0x02,
    EVT_PROT_CHANGE   = 0x10,  /* data = fault bitmask */
    EVT_SOC_ANCHOR    = 0x20,  /* data = new SoC ppt */
    EVT_OVER_TEMP     = 0x30,  /* data = temp_dc */
    EVT_CAN_TIMEOUT   = 0x40,
    EVT_NVM_ERROR     = 0x50,
    EVT_WATCHDOG_RST  = 0x60,
} EventType_t;

typedef struct __attribute__((packed)) {
    uint8_t  type;       /* EventType_t */
    uint32_t ts_ms;      /* HAL_GetTick() */
    uint32_t data;       /* event-specific payload */
} Event_t;              /* 9 bytes */

#define EVT_LOG_SIZE   128U
void MW_EventLog_Write(EventType_t type, uint32_t data);
Event_t *MW_EventLog_GetLatest(uint8_t n);
/* mw_event_log.c */
static Event_t s_log[EVT_LOG_SIZE];
static uint8_t s_head = 0U;

void MW_EventLog_Write(EventType_t type, uint32_t data) {
    s_log[s_head].type  = (uint8_t)type;
    s_log[s_head].ts_ms = HAL_GetTick();
    s_log[s_head].data  = data;
    s_head = (uint8_t)((s_head + 1U) % EVT_LOG_SIZE);
    /* Flush to NVM every 8 events to reduce flash writes */
    if ((s_head % 8U) == 0U) { DRV_Flash_FlushEventLog(s_log, EVT_LOG_SIZE); }
}
ℹ️ Flash Endurance

STM32 internal flash: 10,000 erase cycles. At 8 events per flush and 1 event per second worst case, that's 10,000 × 2048 bytes / (9 bytes × 8) ≈ 284,000 seconds ≈ 3.3 years of worst-case logging before endurance limit. Use ping-pong pages to double effective life.

Section 9.3 · Addendum

Protection State Machine

Every BMS protection module implements an implicit state machine. Understanding the state transitions prevents common bugs — like re-enabling FETs before the fault condition has actually cleared.

C Implementation: State Machine Core

/* app_prot_sm.h — Protection State Machine */
typedef enum {
    PROT_STATE_NORMAL   = 0,
    PROT_STATE_WARN     = 1,   /* pre-fault: derate output */
    PROT_STATE_OVP      = 2,   /* CHG FET open */
    PROT_STATE_DSG_TRIP = 3,   /* DSG FET open */
    PROT_STATE_HARD     = 4,   /* both FETs open, manual reset needed */
    PROT_STATE_RECOVERY = 5,   /* checking if fault cleared */
} ProtState_t;

/* Hysteresis: must be clear for N consecutive ticks before recovery */
#define PROT_CLEAR_TICKS   30U   /* 30 × 100ms = 3 seconds */
/* State machine tick — called every 100ms */
static ProtState_t s_state = PROT_STATE_NORMAL;
static uint8_t s_clear_count = 0U;

void APP_ProtSM_Tick(void) {
    Prot_Fault_t f = APP_Protect_GetActive();

    switch (s_state) {
    case PROT_STATE_NORMAL:
        if (f & PROT_SCP) { s_state = PROT_STATE_HARD; s_clear_count=0; break; }
        if (f & PROT_OTP) { s_state = PROT_STATE_HARD; s_clear_count=0; break; }
        if (f & (PROT_UVP|PROT_OCP_D)) { s_state = PROT_STATE_DSG_TRIP; s_clear_count=0; break; }
        if (f & (PROT_OVP|PROT_OCP_C)) { s_state = PROT_STATE_OVP;      s_clear_count=0; break; }
        if (g_meas.cell_mv[APP_MaxCellIdx()] > WARN_OVP_MV) { s_state = PROT_STATE_WARN; }
        break;

    case PROT_STATE_WARN:
        if (f) { s_state = (f & PROT_SCP) ? PROT_STATE_HARD : PROT_STATE_OVP; break; }
        if (g_meas.cell_mv[APP_MaxCellIdx()] < (WARN_OVP_MV - 20U)) { s_state = PROT_STATE_NORMAL; }
        break;

    case PROT_STATE_OVP:
    case PROT_STATE_DSG_TRIP:
        if (!f) { s_clear_count++;
            if (s_clear_count >= PROT_CLEAR_TICKS) { s_state = PROT_STATE_RECOVERY; s_clear_count=0; }
        } else { s_clear_count = 0U; }
        break;

    case PROT_STATE_RECOVERY:
        if (f) { s_state = PROT_STATE_DSG_TRIP; s_clear_count=0; break; }
        s_clear_count++;
        if (s_clear_count >= 5U) { s_state = PROT_STATE_NORMAL; s_clear_count=0;
            APP_EventLog_Write(EVT_PROT_RECOVERY, 0); }
        break;

    case PROT_STATE_HARD:
        /* Only exits via manual reset or watchdog reboot */
        BSP_FET_SetDSG(false); BSP_FET_SetCHG(false);
        break;
    }
    APP_ProtSM_ApplyFETs();
}
⚡ Hysteresis Is Non-Optional

Without hysteresis on the recovery path, a FET will chatter: trip → clear → re-enable → trip → clear, potentially hundreds of times per second. This stresses the MOSFET, generates RF interference, and destroys gate driver lifetime. The 3-second clear window above is the minimum; use 10s for SCP recovery.

Type Safety Rules

Rule T1
Use <stdint.h> fixed-width types
Never use int, long, or char for data. Always uint8_t, int16_t, uint32_t, etc. Width and signedness are explicit.
Rule T2
Explicit casts at boundaries
When narrowing (e.g., uint32_t → uint16_t) always add an explicit cast and a range check or assert before the cast.
Rule T3
Bitmasks with U suffix
All integer literals used as bitmasks must have U suffix: 0x01U, (1U << 3). Prevents sign-extension surprises.
Rule T4
Boolean-returning functions
Use bool from <stdbool.h> for predicate functions. Never return 1/0 as int and compare with == 1.

Function Design Rules

/* GOOD: single responsibility, explicit error return, no side effects on error */
HAL_StatusTypeDef DRV_AFE_ReadVoltages(uint16_t *out, uint8_t count) {
    if (out == NULL)    { return HAL_ERROR; }  /* guard: null pointer */
    if (count == 0U)    { return HAL_ERROR; }  /* guard: zero count */
    if (count > 16U)    { return HAL_ERROR; }  /* guard: over spec */

    /* ... I2C burst read ... */
    return HAL_OK;
}

/* BAD: modifies globals on error path, no return value, magic numbers */
void read_voltages(void) {
    for (int i=0; i<16; i++) {
        cells[i] = AFE_Read(i);  /* no error check */
    }
}

Portability & Generic Code Patterns

Hardware independence allows the same BMS firmware to run on STM32F103, STM32G474, or a PC-based HIL simulator. The key is separating the what (application logic) from the how (hardware access).

Section 9.6

Embedded Optimisation Techniques

The STM32G474 at 170 MHz has ample headroom for BMS tasks, but writing efficient code prevents surprises at scale — especially when soft-real-time guarantees are required for the protection loop.

Fixed-Point Arithmetic

Avoid floating-point in ISR and protection paths. The STM32G4 has an FPU, but FP operations take 3–14 cycles and are not re-entrant without a context save. Fixed-point integer arithmetic is faster and deterministic.

/* Fixed-point Q12.4 format: 1 bit sign + 11 int + 4 frac bits */
/* Voltage in mV (integer) is already natural fixed-point */

/* Example: Compute pack power in watts */
/* P = V_pack_mV * I_pack_mA / 1_000_000 */
/* Use 64-bit to avoid overflow: 58000 mV * 50000 mA = 2.9e9, fits int32_t barely */
int32_t APP_GetPackPower_W(void) {
    int64_t p_uw = (int64_t)g_meas.pack_mv * (int64_t)g_meas.current_ma;
    return (int32_t)(p_uw / 1000000LL);  /* µW → W */
}

/* Avoid: float version (slower, FPU context) */
float BAD_GetPackPower(void) {
    return ((float)g_meas.pack_mv / 1000.0f) * ((float)g_meas.current_ma / 1000.0f);
}

Lookup Table vs Runtime Calculation

/* LFP OCV curve: 16-point LUT stored in flash (const = ROM) */
/* RAM cost: 0 bytes. Access: single array index + interpolation */

Memory Efficiency

/* Pack structs tightly — use __attribute__((packed)) for NVM structs only */
/* For RAM structs, let compiler align naturally (faster access) */

/* GOOD — natural alignment, 12 bytes, fast access */
typedef struct {
    uint32_t timestamp;   /* 4B, aligned at 0 */
    uint16_t voltage_mv;  /* 2B, aligned at 4 */
    int16_t  current_ma;  /* 2B, aligned at 6 */
    uint8_t  flags;       /* 1B, aligned at 8 */
    uint8_t  pad[3];      /* explicit pad, 12 bytes total */
} Sample_t;

/* BAD — packed wastes cycles on unaligned reads */
typedef struct __attribute__((packed)) {
    uint8_t  flags;
    uint32_t timestamp;   /* unaligned! */
    uint16_t voltage_mv;
} BadSample_t;

Section 9.8

Testing Strategy

BMS firmware testing has three distinct levels: host-based unit tests (no hardware), Hardware-in-the-Loop (HIL) simulation, and final pack-level integration testing. All three are necessary.

Level 1: Host Unit Tests (Unity / CMock)

Application and middleware layers are hardware-independent. They can be compiled for a host PC and tested with the Unity test framework. Mock the BSP layer to inject controlled inputs.

/* test_soc.c — Unity unit test for SoC Coulomb counter */
#include "unity.h"
#include "app_soc.h"
#include "mock_bsp_hal.h"  /* CMock-generated mock */

void setUp(void) {
    /* Reset SoC state before each test */
    g_soc.cc_uah   = 0LL;
    g_soc.soc_ppt  = 0U;
    g_soc.anchored = 0U;
    /* Set initial measurement values */
    g_meas.current_ma = 0L;
    g_meas.valid = 0x07U;
}

void test_CoulombCounter_Charge_100ms(void) {
    g_meas.current_ma = 10000L;    /* 10 A charge */
    APP_SoC_CoulombUpdate();        /* 100 ms tick */
    /* Expected: 10000 mA * 100 ms / 3600 s = 277.7 µAh */
    TEST_ASSERT_INT64_WITHIN(5LL, 277LL, g_soc.cc_uah);
}

void test_CoulombCounter_Clamps_AtCapacity(void) {
    g_soc.cc_uah = CAPACITY_UAH - 100LL;
    g_meas.current_ma = 100000L;   /* huge current — should clamp */
    APP_SoC_CoulombUpdate();
    TEST_ASSERT_EQUAL_INT64(CAPACITY_UAH, g_soc.cc_uah);
    TEST_ASSERT_EQUAL_UINT16(1000U, g_soc.soc_ppt);  /* 100% */
}

void test_SoC_OCV_Anchor_AtRest(void) {
    /* Cell at 3320 mV ≈ 40% SoC on LFP OCV curve */
    for (uint8_t i = 0; i < CELL_COUNT; i++) {
        g_meas.cell_mv[i] = 3320U;
    }
    APP_SoC_AnchorOCV();
    TEST_ASSERT_UINT16_WITHIN(20U, 400U, g_soc.soc_ppt);
    TEST_ASSERT_EQUAL_UINT8(1U, g_soc.anchored);
}

Level 2: Hardware-in-the-Loop (HIL)

A second STM32 acts as a "battery simulator" — it drives I2C with fake cell voltages and injects known currents via a DAC into the shunt sense input. The BMS firmware runs unmodified on real hardware.

HIL Component
Cell Voltage Injector
STM32 acts as I2C slave, responds to BQ76952 register read addresses with programmable values. Inject OVP scenario: set cell 7 = 3660 mV, verify CHG FET opens within 200 ms.
HIL Component
Current DAC
12-bit DAC drives the shunt sense amplifier input. Ramp current from 0→55 A over 1 s. Verify OCP trip at 50 A ± 2 A. Verify DSG FET opens, CAN 0x359 alarm frame transmitted.
HIL Component
Fault Injection
Pull ALERT pin low at precise times. Corrupt I2C ACK to simulate AFE comms loss. Measure BMS response latency with logic analyser. Verify event log entry written.
HIL Component
CAN Bus Monitor
Raspberry Pi with MCP2515 CAN HAT captures all frames. Python script validates PYLON message timing (<2 s gap), payload encoding, and alarm bits set correctly.

Chapter Summary

Chapter 9 · Key Takeaways

The 10 principles that define production-grade BMS firmware:

Principle 1
Safety is architectural
Protection thresholds are compile-time constants in flash, never RAM-configurable over CAN without cryptographic authentication.
Principle 2
Layer strictly
HAL → Driver → Middleware → App. Application code never writes a register address. This enables host-based unit tests and chip portability.
Principle 3
No dynamic memory
malloc/free after init is forbidden. All buffers are static. Execution time is bounded and heap fragmentation is impossible.
Principle 4
Fixed-point everywhere
Integer millivolts and milliamps are natural fixed-point. Avoid FP in ISRs. 64-bit integer handles Coulomb counting without overflow for 280 Ah packs.
Principle 5
Log everything
Every fault, state change, and calibration event gets a timestamp and a NVM-backed entry. Post-mortem debugging without a log is guesswork.
Principle 6
One config header
bms_config.h is the single source of truth for thresholds, cell count, capacity. Board variants = separate config folder, same firmware binary.
Principle 7
Measure latency
Use DWT cycle counter or GPIO toggles to measure every ISR. Protection ISR must trip FETs in <10 µs for SCP, <200 ms for software OVP/UVP.
Principle 8
OCV anchor drift
Re-anchor Coulomb counter with OCV lookup whenever |I| < 500 mA for 30 s. LFP flat OCV curve means ±3 mV accuracy gives ±8% SoC at inflection.
Principle 9
PYLON-compatible CAN
Implement 0x351–0x355 message set. Tested with Victron MultiPlus-II and Growatt SPF 5000. No proprietary protocol needed for most home ESS inverters.
Principle 10
Test at all levels
Host unit tests for algorithms. HIL for hardware interactions. Pack integration for end-to-end validation. All three are necessary for production confidence.

⚡ R&D Thinking — Why Does Fault Speed Matter?

An OVP that trips in 5ms vs 500µs isn't a minor difference. At 1C charging into a 16S pack, voltage rises at roughly 5mV/second per cell. In 5ms, that's 0.025mV — negligible. But a short circuit (SCC) dumps current at 10C or higher. A 280Ah cell at 10C = 2800A. In 5ms, that's 14 Coulombs of charge into an already-full cell. Cell temperature spikes 10–30°C. Dendrite nucleation begins. That 4.5ms difference between your BMS and a good one can determine whether the battery catches fire or survives.

This is why hardware OVP (BQ76952 HW comparator) trips in <500µs independent of firmware, and why the firmware path is a backup, not the primary protection.
