How Hardware Architecture is Decided

Every BMS starts from battery requirements. Cell count → AFE choice. Current range → sensing method. Protection topology follows from fault modes. Every decision is derived, not arbitrary.

Cell Count → Voltage Range → AFE Choice

Series cell count directly sets voltage range and AFE cell-count requirement. 16S needs ≥16-cell AFE support. Above 18 cells, daisy-chain topologies (LTC6813, BQ79616) are required.

// DESIGN RULE

≤12S → single-chip AFE (BQ76952, ISL94216)
13–18S → mid-tier single AFE or daisy-chain
>18S → daisy-chain (LTC6813, BQ79616)

// SECTION 8.2

AFE Selection

The Analog Front End (AFE) is the most critical IC in the BMS — it measures cell voltages, manages balancing, and detects faults. Getting this wrong means redesigning the board.

Key Specs to Evaluate

CELL COUNT SUPPORT
8–18S
Most single-chip AFEs support 8–16 cells. Plan for daisy-chain if >16S. Verify max count includes all cell positions.
MEASUREMENT ACCURACY
±1–5 mV
Cell voltage accuracy at full scale. BQ76952 achieves ±2mV typical. Critical for SoC estimation accuracy near flat OCV region.
BALANCING CURRENT
50–200 mA
Passive balancing FET drive current. Higher = faster balance but more heat. 100mA is typical for 280Ah cells (slow balance is fine).
INTERFACE
SPI / I²C
SPI preferred for BMS (faster, more robust, easier to daisy-chain). I²C works for lower cell counts. BQ76952 uses I²C/SPI selectable.
BUILT-IN FAULT DETECTION
OVP/UVP/OTP
Hardware protection thresholds independent of MCU. Essential for safety — MCU firmware failure must not disable protection.
TEMPERATURE RANGE
−40 to +85°C
AFE must operate across full battery operating range. Automotive grade (−40 to +125°C) for harsh environments.

MCU Selection for BMS

The MCU runs the state machine, EKF, CAN stack, NVM writes, and watchdog. It is not a simple microcontroller task — it is a real-time safety-critical embedded system. Peripheral choice matters as much as clock speed.

// COMMON MISTAKE

Choosing MCU by clock speed or flash size alone. The critical question is: does it have the right peripherals? Missing FDCAN, no backup SRAM, or no hardware watchdog = redesign.

Why CAN Must Be Hardware

Software bit-banged CAN is not acceptable for BMS. Hardware CAN peripheral guarantees:

✓ HARDWARE CAN

Bit timing from crystal, error counting, automatic retransmit, bus-off recovery, ISO 11898 compliant, interrupt-driven

✗ BIT-BANG CAN

Timing jitter from interrupts, no error frame handling, fails under load, not certifiable, CPU hog at 250kbps

Key Peripherals to Verify in CubeMX

FDCAN / bxCAN

Verify bit-timing at 250kbps with your crystal. Check filter banks for 0x351–0x380 range. Enable error interrupts.

Backup SRAM

Enable PWR_CR_DBP to unlock backup domain. SRAM contents survive VBAT brownout. Map SoC, cycle count, SoH here.

IWDG + WWDG

IWDG = independent watchdog (LSI clock, MCU reset if not kicked). WWDG = window watchdog (too-early kick also resets). Use both.

RTC calibration

Use 32.768 kHz crystal. Enable smooth calibration. Accuracy target: <1 min/month for Arrhenius aging timestamp reliability.

Internal VREF

Enable VREFBUF for stable ADC reference. Bypass with 1μF + 10nF. Critical for current sense accuracy at all temperatures.

DMA for SPI

Use DMA for AFE polling (continuous SPI transfers). Frees CPU for EKF computation. Target: AFE read every 10ms, CPU free 95%.

High Voltage Considerations

A 16S LFP pack sits at 40–58V. The BMS must interface between this high-voltage domain and the 3.3V MCU logic. Incorrect isolation design is a safety and regulatory failure.

// SAFETY CRITICAL

For UPS/ESS applications (IEC 62619): the CAN interface must be isolated. Use ISO1042 or equivalent. Creepage between HV and LV conductors must meet IEC 60664-1 requirements (≥2mm for 60V systems, reinforced = ≥6mm).

Creepage and Clearance Rules

CLEARANCE

Shortest path through air. For 60V working voltage, pollution degree 2: ≥1.0mm basic, ≥2.0mm reinforced.

CREEPAGE

Shortest path along surface. CTI group material dependent. FR4 (CTI 175–249): ≥2.0mm basic, ≥4.0mm reinforced.

// SECTION 8.6

PCB Design Guidelines

The BMS PCB carries both millivolt-level cell voltage sense signals and high-current shunt sense signals on the same board. Routing discipline is mandatory.

CELL VOLTAGE SENSE ROUTING

Run sense wires as differential pairs. Keep away from switching nodes (MOSFET gates, DC-DC). Use 0.1μF filter cap at each AFE input pin. Match trace length within 2mm per cell group.

CURRENT SENSE AMPLIFIER

Place INA228 directly adjacent to shunt resistor. Use Kelvin (4-wire) connection. Minimize trace resistance from shunt pad to INA input. Decouple VS with 100nF + 10μF.

NTC SIGNAL CONDITIONING

Use voltage divider with 1% resistor. Decouple ADC input with RC filter (10kΩ + 100nF). Route away from power planes. Shield with ground pour if near high-frequency switching.

MOSFET GATE DRIVE

Gate drive traces must be short (<10mm). Add gate resistor (10–47Ω) to control switching speed and reduce EMI. TVS diode gate-to-source for ESD protection.

CAN BUS TERMINATION

120Ω at each end of bus stub. Use split termination (2× 60Ω + 4.7nF to ground) for common-mode filtering. Do not place in middle of bus. TVS on CANH/CANL for ESD.

THERMAL DESIGN

MOSFETs on copper pours connected to vias (thermal vias 0.3mm, 0.5mm pitch). BMS PCB typically dissipates 2–5W total. Add temperature monitor near high-power area.

POWER DECOUPLING

MCU VDD: 100nF per power pin + 10μF bulk. AFE VDD: 100nF + 1μF + 10μF. Place caps within 0.5mm of IC power pin. Separate analog and digital ground planes, single-point join.

EMC CONSIDERATIONS

Switching current loops must be minimized. Add ferrite bead on MCU VDD supply. Place bulk cap (100μF) at board power entry. CAN interface: common-mode choke before RJ45/connector.
