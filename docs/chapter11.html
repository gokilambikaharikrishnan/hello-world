Section 11.1

BMS Fault Diagnosis & Fault Tree Analysis

Every BMS fault begins as one of four root causes: overvoltage, undervoltage, overcurrent, or overtemperature. Everything else — thermal runaway, ISC, capacity fade — is a downstream effect. A fault tree maps every observable symptom back to its root cause, giving the service engineer a deterministic diagnostic path without guesswork.

Animated Fault Tree — 16S1P LFP Pack

ISC vs Soft Short: An ISC (metallic dendrite across separator) shows R < 10mΩ and triggers thermal runaway within minutes. A soft short (electrolyte contamination) may show R = 50–500Ω and cause only accelerated self-discharge — detectable as >2%/day SoC drop at rest. Never confuse the two; only the ISC requires immediate cell replacement.
