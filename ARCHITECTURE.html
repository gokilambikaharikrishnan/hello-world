What it can do
7 Documentation Modes
MODE 1
Code Docs
How is this module written? One module, code only, developer view
In: .c + .h files, one module
Out: 10-section design doc — functions, config, flow, diagrams
MODE 2
Module Docs
How does this subsystem work end to end? All layers + hardware, full feature view
In: All CAN/NVM/SOC layers + schematic + spec docs
Out: Full subsystem overview HTML
MODE 3
Code Review
What is wrong, risky, or improvable? Auditor mode — reads and reports only
In: .c + .h files per module
Out: Audit report — memory issues, style problems, optimisation flags
MODE 4
Event Log Analysis
What happened during this run? Upload a log, get it explained vs code
In: Excel / CSV event log + code
Out: Timeline, what went well, what failed, root cause clues
MODE 5
CAN Log Analysis
What was on the bus during this session? Decode raw CAN traffic into signals
In: .trc or .asc log + .dbc file
Out: Decoded signal plots, anomaly flags, timing charts, HTML report
MODE 6
Full System Doc
How does the entire BMS product work? Hardware to software, for managers and auditors
In: All schematics + spec docs + full codebase
Out: Complete BMS system overview — architecture, protection, comms
MODE 7
Datasheet Simplifier
What does this IC actually do in our system? 250-page datasheet → what matters
In: IC datasheet PDF + driver code
Out: Simplified reference — only the registers, modes, sequences we use
Shared by all 7 modes
Generation Engine Pipeline
File Reader
fileReader.ts · includeResolver.ts
Reads .c .h .pdf .dbc .csv .xls · walks #include chain · 90k char cap
Prompt Builder
promptBuilder.ts
5 layer prompts · domain context · audience definition · 10-section instructions · swaps strategy per mode and per layer
LLM Caller
llmClient.ts
GitHub Copilot via vscode.lm API · gpt-4o preferred · streaming tokens · error handling
HTML Renderer
docRenderer.ts
Parses 10 sections · converts markdown → HTML · Mermaid diagrams · hljs syntax highlight · dark theme
docs/{MODULE}_design.html
Saved to /docs in the repo · opens in browser · 10-section sidebar navigation
