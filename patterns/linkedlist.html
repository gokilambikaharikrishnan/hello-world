Pattern 01 Node Structure and Traversal
① Story First
A treasure hunt where each clue tells you the location of the next clue. You start at the first clue (head), follow the arrow to the next, and keep going until there are no more arrows (NULL). That's a linked list: each node holds data and a pointer to the next node.
② The Insight
A linked list node is a struct with a value and a next pointer. Traversal is just following next pointers until NULL. Unlike arrays, there's no random access — reaching node k costs O(k). But insertion and deletion at a known point cost O(1).
③ Step-by-Step Logic
  1. Define struct Node { int val; struct Node *next; }.
  2. Head pointer points to first node; last node's next == NULL.
  3. Traversal: Node *cur = head; while (cur) { use cur->val; cur = cur->next; }.
  4. Always check cur != NULL before dereferencing.
Diagram
head → [1|•] → [2|•] → [3|•] → [4|NULL] val next val next Traversal: cur=head(1) → cur=2 → cur=3 → cur=4 → cur=NULL → stop
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int val;
    struct Node *next;   /* pointer to next node (NULL if last) */
} Node;

/* Allocate and initialize a new node */
Node *new_node(int val) {
    Node *n = malloc(sizeof(Node));
    n->val = val;
    n->next = NULL;
    return n;
}

/* Print all values in list */
void print_list(Node *head) {
    for (Node *cur = head; cur; cur = cur->next)
        printf("%d ", cur->val);
    printf("\n");
}

/* Free all nodes */
void free_list(Node *head) {
    while (head) {
        Node *tmp = head->next;   /* save next before freeing */
        free(head);
        head = tmp;
    }
}

int main(void) {
    Node *head = new_node(1);
    head->next = new_node(2);
    head->next->next = new_node(3);
    print_list(head);   /* 1 2 3 */
    free_list(head);
    return 0;
}
⑤ Dry Run
print_list(head): cur=&Node(1): print 1, cur=cur->next=&Node(2) cur=&Node(2): print 2, cur=cur->next=&Node(3) cur=&Node(3): print 3, cur=cur->next=NULL cur=NULL: stop output: 1 2 3 ✓
⚠ Gotcha: Save next pointer before freeing

In free_list: always save head->next in a temp variable BEFORE calling free(head). After free, the memory is returned to the allocator and head->next is undefined behavior to read.

N/A (fundamental structure)
When working with linked lists → think: node = {val, *next}; traverse with cur=cur->next until NULL.
Pattern 02 Insert at Head
① Story First
Inserting at the front of a line: the new person becomes the first in line and points to whoever was first before. Two pointer updates, O(1) time — no matter how long the list is.
② The Insight
Head insertion is the cheapest list operation. New node's next = old head; head = new node. The key pattern: always set the new node's pointer first, then update head — doing it in the other order loses the rest of the list.
③ Step-by-Step Logic
  1. Allocate new node, set val.
  2. new_node->next = head (new node points to old first).
  3. head = new_node (head now points to new first).
Diagram
Before: head → [2] → [3] → NULL Insert 1 at head: new->next = head → new → [2] → [3] → NULL head = new → head → [1] → [2] → [3] → NULL
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

/* Returns new head — caller must update their head pointer */
Node *insert_head(Node *head, int val) {
    Node *n = malloc(sizeof(Node));
    n->val = val;
    n->next = head;   /* step 1: point new node to old head */
    return n;          /* step 2: new node IS the new head */
}

int main(void) {
    Node *head = NULL;
    head = insert_head(head, 3);
    head = insert_head(head, 2);
    head = insert_head(head, 1);
    for (Node *c = head; c; c = c->next) printf("%d ", c->val);
    /* 1 2 3 */
    return 0;
}
⑤ Dry Run
head=NULL insert_head(NULL, 3): new->{3,NULL}, return new → head=[3]→NULL insert_head([3], 2): new->{2,[3]}, return new → head=[2]→[3]→NULL insert_head([2..],1): new->{1,[2]}, return new → head=[1]→[2]→[3]→NULL ✓
⚠ Gotcha: Return the new head — don't modify through double pointer unless designed that way

A common pattern is void push(Node **head, int val) which modifies head through a pointer-to-pointer. Both styles work, but mixing them causes bugs. Pick one convention and stick with it throughout your codebase.

Pattern 03 Insert at Tail
① Story First
Joining the back of a queue. You walk to the end (following all the next pointers until you find the last person with no one behind them), then you link in. If you maintain a tail pointer, you skip the walk and get O(1) append.
② The Insight
Naïve tail insert is O(n) — you must traverse to find the last node. With a tail pointer maintained alongside head, append becomes O(1). The tail pointer always points to the node whose next == NULL.
③ Step-by-Step Logic
  1. If list is empty: head = tail = new_node.
  2. Else: tail->next = new_node; tail = new_node.
  3. new_node->next = NULL (already set in new_node()).
Diagram
Before: head→[1]→[2]→NULL, tail→[2] Append 3: tail->next = new → [2]→[3]→NULL tail = new → tail→[3] After: head→[1]→[2]→[3]→NULL, tail→[3]
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

typedef struct { Node *head; Node *tail; } List;

void append(List *L, int val) {
    Node *n = malloc(sizeof(Node));
    n->val = val; n->next = NULL;
    if (!L->head) {
        L->head = L->tail = n;   /* first node: both head and tail */
    } else {
        L->tail->next = n;       /* link old tail to new node */
        L->tail = n;              /* advance tail pointer */
    }
}

int main(void) {
    List L = {NULL, NULL};
    append(&L, 1); append(&L, 2); append(&L, 3);
    for (Node *c = L.head; c; c = c->next) printf("%d ", c->val);
    /* 1 2 3 */
    return 0;
}
⑤ Dry Run
append(1): head=tail=[1]→NULL append(2): tail->next=[2], tail=[2] → head=[1]→[2]→NULL append(3): tail->next=[3], tail=[3] → head=[1]→[2]→[3]→NULL ✓
⚠ Gotcha: Update tail when the first node is inserted

When the list is empty, both head AND tail must be set to the new node. If you only set head, tail remains NULL and the next append will null-pointer-dereference on L->tail->next = n.

N/A (fundamental)Used in queue implementations
When appending to a list → think: keep a tail pointer; tail->next=new; tail=new. O(1) vs O(n) traversal.
Pattern 04 Insert at Position
① Story First
You want to cut into a queue at position k. Walk to person k-1 (the one just before the gap), make them point to you, and make yourself point to whoever they were pointing to. Two pointer reassignments while standing in the right place.
② The Insight
To insert before position k (0-indexed), walk to node k-1 (the predecessor). Then: new->next = prev->next; prev->next = new. Order matters: set new->next first, then update prev->next — otherwise you lose the rest of the list.
③ Step-by-Step Logic
  1. Special case: pos==0 → insert at head.
  2. Walk to node at position pos-1 (the predecessor).
  3. new->next = prev->next (point new to what was after prev).
  4. prev->next = new (link prev to new).
Diagram
List: [1]→[2]→[4]→NULL, insert 3 at pos=2 Walk to pos=1: prev→[2] new->next = prev->next = [4] → new→[3]→[4]→NULL prev->next = new → [2]→[3]→[4]→NULL Result: [1]→[2]→[3]→[4]→NULL ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;
Node *new_node(int v) { Node *n=malloc(sizeof(Node)); n->val=v; n->next=NULL; return n; }

Node *insert_at(Node *head, int pos, int val) {
    Node *n = new_node(val);
    if (pos == 0) { n->next = head; return n; }   /* head insert */

    Node *prev = head;
    for (int i = 0; i < pos-1 && prev->next; i++)
        prev = prev->next;          /* walk to predecessor */

    n->next = prev->next;           /* new points to what was after prev */
    prev->next = n;                  /* prev now points to new */
    return head;
}

int main(void) {
    Node *h = new_node(1);
    h->next = new_node(2);
    h->next->next = new_node(4);
    h = insert_at(h, 2, 3);        /* insert 3 between 2 and 4 */
    for (Node *c=h; c; c=c->next) printf("%d ",c->val); /* 1 2 3 4 */
    return 0;
}
⑤ Dry Run
insert_at(h, 2, 3): pos=2, walk: prev=h[1]→prev=h->next=[2] (i=0,pos-1=1) n->{3,NULL} n->next = prev->next = [4] → n->{3,[4]} prev->next = n → [2]->[3]->[4] return h → [1]->[2]->[3]->[4]->NULL ✓
⚠ Gotcha: Set new->next BEFORE updating prev->next

If you do prev->next = new first, you lose the pointer to the rest of the list (the old prev->next value). Always wire the new node's next pointer before redirecting the predecessor.

Pattern 05 Delete by Value
① Story First
Someone leaves the queue. The person behind them needs to bridge the gap — pointing directly to the person in front. Walk along until you find the person to remove, remember who's behind them, and relink.
② The Insight
To delete a node, you need its predecessor (the node before it). Walk keeping a prev pointer one step behind cur. When cur->val matches: prev->next = cur->next, then free cur. Head deletion is a special case.
③ Step-by-Step Logic
  1. If head->val == target: head = head->next; free old head.
  2. Walk with prev=head, cur=head->next until cur->val==target or cur==NULL.
  3. Found: prev->next = cur->next; free(cur).
  4. Handle "not found" (cur reached NULL without match).
Diagram
Delete 2: [1]→[2]→[3]→NULL prev=[1], cur=[2]: cur->val==2 prev->next = cur->next = [3] → [1]→[3]→NULL free(cur=[2]) Result: [1]→[3]→NULL ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *delete_val(Node *head, int val) {
    if (!head) return NULL;
    if (head->val == val) {         /* head deletion */
        Node *tmp = head->next;
        free(head);
        return tmp;
    }
    Node *prev = head, *cur = head->next;
    while (cur && cur->val != val) {
        prev = cur;
        cur = cur->next;
    }
    if (cur) {                       /* found */
        prev->next = cur->next;
        free(cur);
    }
    return head;
}

int main(void) {
    /* build 1→2→3 */
    Node *h = malloc(sizeof(Node)); h->val=1;
    h->next = malloc(sizeof(Node)); h->next->val=2;
    h->next->next = malloc(sizeof(Node)); h->next->next->val=3;
    h->next->next->next = NULL;
    h = delete_val(h, 2);
    for (Node *c=h; c; c=c->next) printf("%d ", c->val); /* 1 3 */
    return 0;
}
⑤ Dry Run
delete_val([1]→[2]→[3], 2): head->val=1 ≠ 2 prev=[1], cur=[2]: cur->val==2 → found prev->next = cur->next = [3] free([2]) return head=[1]→[3]→NULL ✓
⚠ Gotcha: Deleting the head needs special handling

You can't use the prev/cur approach for the head node because there's no predecessor. Always check head first as a special case, or use a sentinel (dummy) node before head to unify all deletions.

Pattern 06 Delete Nth Node from End
① Story First
You don't know the list length, and you want to remove the 3rd node from the end. Send a scout n steps ahead. Then walk both the scout and a follower together. When the scout hits the end, the follower is exactly at the node to delete. One pass, O(n).
② The Insight
Two-pointer gap technique: advance fast pointer n+1 steps (n+1 so slow lands on the predecessor, not the node itself). Then advance both until fast == NULL. Slow is now at the predecessor of the target. Use a dummy head to handle deleting the actual head.
③ Step-by-Step Logic
  1. Create dummy node pointing to head. fast = slow = dummy.
  2. Advance fast n+1 steps.
  3. Advance both fast and slow until fast == NULL.
  4. slow->next = slow->next->next (skip the target node).
Diagram
List: D→[1]→[2]→[3]→[4]→[5]→NULL, remove 2nd from end fast advances 3 steps: fast→[3] both advance until fast=NULL: fast=[4],slow=[1] → fast=[5],slow=[2] → fast=NULL,slow=[3] slow->next=[4]=slow->next->next → [1]→[2]→[3]→[5]→NULL ✓ (node [4] deleted, was 2nd from end)
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *remove_nth_from_end(Node *head, int n) {
    Node dummy = {0, head};        /* dummy node before head */
    Node *fast = &dummy, *slow = &dummy;

    for (int i = 0; i <= n; i++) fast = fast->next;  /* n+1 steps */

    while (fast) { fast = fast->next; slow = slow->next; }

    Node *del = slow->next;
    slow->next = slow->next->next;   /* skip deleted node */
    free(del);
    return dummy.next;
}

int main(void) {
    /* build 1→2→3→4→5 */
    Node *h=NULL, *t=NULL;
    for (int i=1; i<=5; i++) {
        Node *n=malloc(sizeof(Node)); n->val=i; n->next=NULL;
        if(!h) h=t=n; else { t->next=n; t=n; }
    }
    h = remove_nth_from_end(h, 2);
    for (Node *c=h; c; c=c->next) printf("%d ",c->val); /* 1 2 3 5 */
    return 0;
}
⑤ Dry Run
remove_nth_from_end([1..5], n=2): dummy→[1]→[2]→[3]→[4]→[5]→NULL fast advances 3 steps: fast→[3] both advance: fast=[4],slow=[1] fast=[5],slow=[2] fast=NULL,slow=[3] del=[4]; slow->next=[5] list: [1]→[2]→[3]→[5]→NULL ✓
⚠ Gotcha: Advance fast n+1 times, not n

Advancing n times would land slow ON the node to delete, not its predecessor — and you can't relink without the predecessor. The extra step (+1) ensures slow lands one node before the target. The dummy node makes this work even when deleting the head (n == length).

Pattern 07 Reverse a Linked List — Iterative
① Story First
Reversing a line of people: each person turns around and grabs the shoulder of the person who was behind them. You need three pointers — who you were holding (prev), who you are (cur), and who you'll hold next (next_tmp) — because once you reverse your grip, you've lost the forward chain.
② The Insight
Three-pointer iterative reversal: at each step, save next, flip the arrow (cur->next = prev), advance prev and cur. After the loop, prev points to the new head. This is the most important linked list pattern — it appears as a subroutine in dozens of problems.
③ Step-by-Step Logic
  1. prev=NULL, cur=head.
  2. While cur: save next=cur->next; cur->next=prev; prev=cur; cur=next.
  3. Return prev (new head).
Diagram
Before: NULL ← ? [1]→[2]→[3]→NULL Step 1: prev=NULL, cur=[1], next=[2] cur->next=NULL → [1]→NULL prev=[1], cur=[2], next=[3] Step 2: cur->next=[1] → [2]→[1]→NULL prev=[2], cur=[3], next=NULL Step 3: cur->next=[2] → [3]→[2]→[1]→NULL prev=[3], cur=NULL → stop Return prev=[3] (new head) ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *reverse(Node *head) {
    Node *prev = NULL, *cur = head;
    while (cur) {
        Node *next = cur->next;   /* save forward link before breaking it */
        cur->next = prev;          /* reverse the arrow */
        prev = cur;                /* prev advances to cur */
        cur = next;                /* cur advances to saved next */
    }
    return prev;   /* prev is now the last node = new head */
}

int main(void) {
    /* build 1→2→3→4→5 */
    Node *h = NULL;
    for (int i=5; i>=1; i--) {
        Node *n=malloc(sizeof(Node)); n->val=i; n->next=h; h=n;
    }
    h = reverse(h);
    for (Node *c=h; c; c=c->next) printf("%d ",c->val); /* 5 4 3 2 1 */
    return 0;
}
⑤ Dry Run
reverse([1]→[2]→[3]): prev=NULL, cur=[1] iter1: next=[2], [1]->NULL, prev=[1], cur=[2] iter2: next=[3], [2]->[1], prev=[2], cur=[3] iter3: next=NULL, [3]->[2], prev=[3], cur=NULL return [3]→[2]→[1]→NULL ✓
⚠ Gotcha: Save next BEFORE overwriting cur->next

The moment you write cur->next = prev, the forward pointer is gone. If you forgot to save next = cur->next first, you've lost the rest of the list forever. The save-then-flip order is non-negotiable.

Pattern 08 Reverse a Linked List — Recursive
① Story First
Trust the recursion: "reverse everything after head, then make head the tail." When the recursion unwinds, head->next (which is now the last node of the reversed sublist) gets its next pointer updated to point back to head, making head the new tail.
② The Insight
Recursive reverse: the base case is a single node or empty list. Otherwise: reverse(head->next) returns the new head of the reversed tail. Then: head->next->next = head (make the old second node point back to head); head->next = NULL (head is now the tail). Return new_head.
③ Step-by-Step Logic
  1. Base: if head==NULL or head->next==NULL: return head.
  2. new_head = reverse(head->next) — recursively reverse the rest.
  3. head->next->next = head — make old second node point back to head.
  4. head->next = NULL — head is now the last node.
  5. Return new_head.
Diagram
reverse([1]→[2]→[3]): recurse: reverse([2]→[3]) → returns [3] as new_head head=[1], head->next=[2] head->next->next = head → [2]->[1] head->next = NULL → [1]->NULL Full list: [3]→[2]→[1]→NULL, new_head=[3] ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *reverse_rec(Node *head) {
    if (!head || !head->next) return head;  /* base case */

    Node *new_head = reverse_rec(head->next); /* reverse rest */
    head->next->next = head;   /* old second node points back to head */
    head->next = NULL;          /* head is now the new tail */
    return new_head;            /* new head is unchanged from recursion */
}

int main(void) {
    /* build 1→2→3 */
    Node a={1,NULL}, b={2,NULL}, c={3,NULL};
    a.next=&b; b.next=&c;
    Node *h = reverse_rec(&a);
    for (Node *cur=h; cur; cur=cur->next) printf("%d ",cur->val); /* 3 2 1 */
    return 0;
}
⑤ Dry Run
reverse_rec([1]→[2]→[3]): call reverse_rec([2]→[3]): call reverse_rec([3]): base → return [3] new_head=[3]; [2]->next=[3]; [3]->next=[2]; [2]->next=NULL return [3] (new head) back in first call: new_head=[3] head=[1], head->next=[2]; [2]->next=[1]; [1]->next=NULL return [3] → [3]→[2]→[1]→NULL ✓
⚠ Gotcha: O(n) stack depth — use iterative for long lists

Recursive reversal uses O(n) call stack frames. For a list of 100,000 nodes, this overflows the stack. In production, use the iterative version (Pattern 07). The recursive version is elegant for understanding and interviews on small inputs.

Pattern 09 Reverse K-Group
① Story First
Instead of reversing the whole list, reverse every k consecutive nodes as a group. If fewer than k nodes remain at the end, leave them as-is. This requires finding each group, reversing it, and then stitching the groups together.
② The Insight
Walk k steps to check if a full group exists. If yes, reverse those k nodes (reusing the three-pointer technique), then recursively (or iteratively) handle the rest. Connect the tail of the reversed group to the result of processing the remainder.
③ Step-by-Step Logic
  1. Check if k nodes remain (walk k steps; if not, return head as-is).
  2. Reverse k nodes using three-pointer technique; group_tail is original head.
  3. group_tail->next = reverse_k(remaining, k) — attach reversed tail.
  4. Return new_head (old k-th node).
Diagram
[1]→[2]→[3]→[4]→[5], k=2: Group 1: reverse [1,2] → [2]→[1], tail=[1] Group 2: reverse [3,4] → [4]→[3], tail=[3] Remainder: [5] (less than k, keep as-is) Connect: [2]→[1]→[4]→[3]→[5] ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *reverse_k_group(Node *head, int k) {
    /* Check if k nodes remain */
    Node *check = head;
    for (int i = 0; i < k; i++) {
        if (!check) return head;   /* fewer than k nodes: don't reverse */
        check = check->next;
    }

    /* Reverse k nodes */
    Node *prev = NULL, *cur = head;
    for (int i = 0; i < k; i++) {
        Node *next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    /* head is now the tail of the reversed group */
    head->next = reverse_k_group(cur, k);  /* attach reversed remainder */
    return prev;   /* prev is the new head of this group */
}

int main(void) {
    /* build 1→2→3→4→5 */
    Node *h=NULL, *t=NULL;
    for (int i=1; i<=5; i++) {
        Node *n=malloc(sizeof(Node)); n->val=i; n->next=NULL;
        if(!h) h=t=n; else{t->next=n;t=n;}
    }
    h = reverse_k_group(h, 2);
    for (Node *c=h;c;c=c->next) printf("%d ",c->val); /* 2 1 4 3 5 */
    return 0;
}
⑤ Dry Run
reverse_k_group([1..5], k=2): check: 2 nodes exist (check=[3] after 2 steps) reverse [1],[2]: prev=[2]→[1]→NULL, cur=[3], head=[1] head->next = reverse_k_group([3..5], 2) check: 2 exist (check=[5]) reverse [3],[4]: prev=[4]→[3]→NULL, cur=[5], head=[3] head->next = reverse_k_group([5],2) check: only 1 node, return [5] head=[3]->next=[5] → [4]→[3]→[5] return [4] head=[1]->next=[4]→[3]→[5] → [2]→[1]→[4]→[3]→[5] ✓
⚠ Gotcha: Check BEFORE reversing, not after

Check k nodes are available before doing any reversals. If you reverse first and then find fewer than k nodes, you've already mutated the list and can't put it back. The check pass is read-only; the reversal pass is destructive.

Pattern 10 Find Middle of Linked List
① Story First
A hare and tortoise race. The hare runs twice as fast. When the hare reaches the finish line (end of list), the tortoise is at the halfway point. That's Floyd's middle-finding trick — one pointer moves one step, the other moves two steps.
② The Insight

③ Step-by-Step Logic

Pattern 11 Detect Cycle — Floyd's Algorithm
① Story First
A tortoise and hare run on a circular track. The hare is faster. If there's a loop, the hare will eventually lap the tortoise and they'll meet. If there's no loop, the hare runs off the end of the track without meeting the tortoise.
② The Insight
If a cycle exists, fast (2x speed) will eventually catch slow (1x) inside the cycle. No cycle → fast reaches NULL. This is Floyd's cycle detection: O(n) time, O(1) space. Two pointers, no visited hash set needed.
③ Step-by-Step Logic
  1. slow = head, fast = head.
  2. While fast and fast->next: slow = slow->next; fast = fast->next->next.
  3. If slow == fast: cycle detected. If fast reaches NULL: no cycle.

    return 0;
}

Pattern 12 Find Cycle Start
① Story First
After detecting a cycle, you want to find exactly where the loop begins. Mathematical trick: once slow and fast meet, reset one pointer to head. Advance both one step at a time. Where they meet again is the cycle start. No math intuition needed — trust the algebra.
② The Insight
After the first meeting point, the distance from head to cycle start equals the distance from meeting point to cycle start (going forward in the cycle). So resetting one pointer to head and advancing both at speed 1 brings them together exactly at the cycle start.
③ Step-by-Step Logic
  1. Run Floyd's until slow == fast (meeting point).
  2. Reset slow = head; keep fast at meeting point.
  3. Advance both one step at a time until slow == fast.
  4. That meeting point is the cycle start.

#include <stdlib.h>

Node *find_cycle_start(Node *head) {

}

Pattern 13 Find Intersection of Two Lists
① Story First
Two rivers merge into one. You want to find the confluence point. If you walk both rivers simultaneously, you'll reach the merge at different times if the rivers have different upstream lengths. The trick: after reaching the end, switch rivers — the path lengths equalize and you meet exactly at the merge point.
② The Insight
Walk pointer A through list A then list B. Walk pointer B through list B then list A. Both traverse the same total distance (lenA + lenB). They'll meet at the intersection node — or both reach NULL simultaneously if there's no intersection.
③ Step-by-Step Logic
  1. a = headA, b = headB.
  2. While a != b: a = a ? a->next : headB; b = b ? b->next : headA.
  3. Return a (either the intersection node or NULL).
Diagram
A: [a1]→[a2]→[c1]→[c2]→[c3]→NULL B: [b1]→[c1]→[c2]→[c3]→NULL a walks: a1,a2,c1,c2,c3,NULL→b1,c1 b walks: b1,c1,c2,c3,NULL→a1,a2,c1 Both arrive at [c1] simultaneously ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *get_intersection(Node *headA, Node *headB) {
    Node *a = headA, *b = headB;
    while (a != b) {
        /* When a reaches end, redirect to headB; same for b */
        a = a ? a->next : headB;
        b = b ? b->next : headA;
    }
    return a;  /* NULL if no intersection, intersection node otherwise */
}

    Node b1={5};
    b1.next=&c1;               /* B: 5→3→6 */

    printf("intersection: %d\n", inter ? inter->val : -1);  /* 3 */
    return 0;
}

Pattern 14 Palindrome Linked List
① Story First
"Racecar" reads the same forwards and backwards. For a linked list, you can't step backwards — so you: find the middle, reverse the second half, compare first half with reversed second half, then restore the list.
② The Insight
Combines Pattern 10 (find middle) and Pattern 07 (reverse). Find the middle, reverse from there to the end, compare node by node. This runs in O(n) time and O(1) space. Optionally restore the list after checking.
③ Step-by-Step Logic
  1. Find middle using slow/fast.
  2. Reverse second half (from middle->next to end).
  3. Compare first half and reversed second half node by node.
  4. Optionally restore (reverse second half again and relink).

#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

static Node *reverse(Node *h) {
    Node *prev=NULL, *cur=h;
    while (cur) { Node *nx=cur->next; cur->next=prev; prev=cur; cur=nx; }
    return prev;
}

int is_palindrome(Node *head) {
    if (!head || !head->next) return 1;

    /* Find end of first half */
    Node *slow=head, *fast=head;
    while (fast->next && fast->next->next) {
        slow=slow->next; fast=fast->next->next;
    }

    Node *second = reverse(slow->next);  /* reverse second half */
    Node *p1=head, *p2=second;
    int result=1;
    while (p2) {
        if (p1->val != p2->val) { result=0; break; }
        p1=p1->next; p2=p2->next;
    }
    slow->next = reverse(second);   /* restore */
    return result;
}

    c.val=3;
    printf("%d\n", is_palindrome(&a));   /* 0 */
    return 0;
}

Pattern 15 Merge Two Sorted Lists
① Story First
Two sorted piles of cards. Pick the smaller top card from either pile, place it face-down. Repeat until both piles are empty. The face-down stack is fully sorted. In linked list terms: compare the two heads, attach the smaller one to the result, advance that list's pointer.
② The Insight
Use a dummy head to avoid special-casing the first node. Compare list1->val and list2->val; attach the smaller one to tail->next and advance both tail and the chosen pointer. After one list empties, attach the remainder of the other list directly (it's already sorted).
③ Step-by-Step Logic
  1. Create dummy node; tail = &dummy.
  2. While both lists non-empty: pick smaller head, attach to tail, advance.
  3. Attach remaining non-empty list to tail->next.
  4. Return dummy.next.

#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *merge_sorted(Node *l1, Node *l2) {
    Node dummy = {0, NULL};
    Node *tail = &dummy;

    while (l1 && l2) {
        if (l1->val <= l2->val) {
            tail->next = l1;   /* attach smaller node */
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;     /* advance tail */
    }
    tail->next = l1 ? l1 : l2;   /* attach remainder */
    return dummy.next;
}

① Story First
K sorted card piles. Naïve: pick the minimum from K piles each time — O(nK). Better: use a min-heap of size K. The heap always gives you the current minimum in O(log K). Pop it, attach it, push its successor back in. Total O(n log K).

③ Step-by-Step Logic
  1. Divide-and-conquer: pair up lists and merge each pair.
  2. Repeat with the merged lists until only one list remains.
  3. O(log K) rounds, each round O(n total nodes) → O(n log K).

Pattern 19 Remove Duplicates from Unsorted List
① Story First

  3. Always advance cur. Return head.

#include <stdlib.h>
#include <string.h>

① Story First

② The Insight

  2. Walk: if cur->val < x: append to less side; else append to greater side.
  3. lt->next = greater_dummy.next (stitch together).
  4. gt->next = NULL (terminate). Return less_dummy.next.

Pattern 21 Rotate List
① Story First
Rotating a list by k positions right means the last k nodes become the front. "1 2 3 4 5" rotated by 2 becomes "4 5 1 2 3". Strategy: make the list circular, find the new tail, break the circle there.
② The Insight
Find the length. Effective rotation = k mod len (rotating by len is a no-op). The new tail is at position len - (k mod len) - 1. Connect the old tail to head (make circular), then break at the new tail.
③ Step-by-Step Logic
  1. Find length and tail. k = k mod len (effective rotation).
  2. If k == 0: return head unchanged.
  3. tail->next = head (make circular).
  4. Walk to new tail (position len-k-1). New head = new_tail->next. new_tail->next = NULL.

#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *rotate_right(Node *head, int k) {
    if (!head || !head->next || k == 0) return head;

    int len = 1;
    Node *tail = head;
    while (tail->next) { tail = tail->next; len++; }

    k %= len;
    if (k == 0) return head;

    tail->next = head;   /* make circular */

    Node *new_tail = head;
    for (int i = 0; i < len - k - 1; i++)
        new_tail = new_tail->next;

    Node *new_head = new_tail->next;
    new_tail->next = NULL;   /* break circle */
    return new_head;
}

    for(Node *c=h;c;c=c->next) printf("%d ",c->val); /* 4 5 1 2 3 */
    return 0;
}

If k is a multiple of len, rotating produces the same list. Without the if (k == 0) return head check after the modulo, you'll still do work and potentially produce a corrupted list (the circle break position would be at len-1, wrapping back to the original head).

① Story First

  1. Walk cur from head.

#include <stdlib.h>

typedef struct MNode {
    int val;
    struct MNode *prev, *next, *child;
} MNode;

MNode *flatten(MNode *head) {
    for (MNode *cur = head; cur; cur = cur->next) {
        if (!cur->child) continue;

        MNode *child = cur->child;
        MNode *next  = cur->next;

        cur->child = NULL;   /* clear child pointer */

    return head;
}

Pattern 24 Copy List with Random Pointer
① Story First
A linked list where each node also has a random pointer to any node in the list. Deep-copying requires preserving the random pointer relationships. The O(1) space trick: weave clone nodes between originals, set random pointers, then unweave.
② The Insight
Three-pass O(1) space approach: Pass 1: interleave clones (orig → clone → orig->next). Pass 2: for each clone, clone.random = orig.random.next (the clone of the random target is right after it). Pass 3: unweave — restore original list, extract clone list.
③ Step-by-Step Logic
  1. Pass 1: for each node, create clone and insert after it.
  2. Pass 2: clone->random = orig->random ? orig->random->next : NULL.
  3. Pass 3: unweave: orig->next = clone->next; clone->next = clone->next ? clone->next->next : NULL.

Original: [1|r→3] → [2|r→1] → [3|r→3] After interleave: [1] → [1'] → [2] → [2'] → [3] → [3'] Pass 2: [1']->random = [1]->random->next = [3]->next = [3'] Pass 3: unweave → original restored, clone: [1']→[2']→[3'] ✓

#include <stdio.h>
#include <stdlib.h>

typedef struct RNode { int val; struct RNode *next, *random; } RNode;

RNode *copy_random_list(RNode *head) {
    if (!head) return NULL;

    /* Pass 1: interleave clones */
    for (RNode *cur = head; cur; cur = cur->next->next) {
        RNode *clone = malloc(sizeof(RNode));
        clone->val = cur->val;
        clone->next = cur->next;   /* clone points to orig's next */
        cur->next = clone;          /* orig points to clone */
        clone->random = NULL;
    }

    /* Pass 2: set random pointers for clones */
    for (RNode *cur = head; cur; cur = cur->next->next) {
        if (cur->random)
            cur->next->random = cur->random->next;  /* clone of random target */
    }

    /* Pass 3: unweave */
    RNode dummy = {0, NULL, NULL};
    RNode *clone_tail = &dummy;
    for (RNode *cur = head; cur; cur = cur->next) {
        RNode *clone = cur->next;
        cur->next    = clone->next;          /* restore original */
        clone->next  = NULL;
        clone_tail->next = clone;
        clone_tail = clone;
    }
    return dummy.next;
}

int main(void) {
    RNode a={1},b={2},c={3};
    a.next=&b; b.next=&c; c.next=NULL;
    a.random=&c; b.random=&a; c.random=&c;
    RNode *copy = copy_random_list(&a);
    while(copy) { printf("[%d|r=%d] ",copy->val, copy->random?copy->random->val:-1); copy=copy->next; }
    return 0;
}

① Story First

③ Step-by-Step Logic

  2. Reverse second half.
  3. Merge: alternately take from first and second half.

typedef struct Node { int val; struct Node *next; } Node;

static Node *rev(Node *h) {
    Node *p=NULL,*c=h; while(c){Node *n=c->next;c->next=p;p=c;c=n;} return p;
}

void reorder_list(Node *head) {
    if (!head || !head->next) return;

    /* Find first middle */
    Node *slow=head, *fast=head;
    while(fast->next && fast->next->next){slow=slow->next;fast=fast->next->next;}

    Node *second = rev(slow->next);
    slow->next = NULL;   /* sever */

    while(second) {
        Node *fn = first->next, *sn = second->next;
        first->next = second;
        second->next = fn;
        first = fn;
        second = sn;
    }
}

Pattern 29 LRU Cache — Doubly Linked List + HashMap
① Story First
Least Recently Used cache: when the cache is full and you need to add a new item, evict the one that hasn't been used for the longest time. Maintain a doubly linked list ordered by recency: most recent at the head, least recent at the tail. A hash map gives O(1) access to any node's position in the list.
② The Insight
Hash map: key → node pointer (O(1) lookup). Doubly linked list: newest at head, oldest at tail, with dummy head/tail sentinels for easy insertion/deletion. On get/put: move the accessed node to the head. On capacity exceeded: remove tail's predecessor.
③ Step-by-Step Logic
  1. get(key): if not in map, return -1. Else move node to head, return val.
  2. put(key, val): if exists, update val and move to head. Else create node, add to head, add to map. If over capacity, remove LRU (tail's prev), remove from map.
Diagram
Capacity=2: put(1,1) put(2,2) List: H ↔ [2] ↔ [1] ↔ T (2 is most recent) get(1): move [1] to head → H ↔ [1] ↔ [2] ↔ T put(3,3): full → evict tail-prev=[2], add [3] → H ↔ [3] ↔ [1] ↔ T (key 2 evicted) ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAXCAP 3001

typedef struct DNode { int key, val; struct DNode *prev, *next; } DNode;

typedef struct {
    DNode *map[MAXCAP];   /* simple array-based "hash map" for int keys */
    DNode head, tail;     /* sentinel dummies */
    int capacity, size;
} LRUCache;

static void remove_node(DNode *n) {
    n->prev->next = n->next;
    n->next->prev = n->prev;
}
static void insert_after_head(LRUCache *c, DNode *n) {
    n->next = c->head.next;
    n->prev = &c->head;
    c->head.next->prev = n;
    c->head.next = n;
}

LRUCache *lru_create(int cap) {
    LRUCache *c = calloc(1, sizeof(LRUCache));
    c->capacity = cap;
    c->head.next = &c->tail;
    c->tail.prev = &c->head;
    return c;
}
int lru_get(LRUCache *c, int key) {
    DNode *n = c->map[key];
    if (!n) return -1;
    remove_node(n); insert_after_head(c, n);
    return n->val;
}
void lru_put(LRUCache *c, int key, int val) {
    if (c->map[key]) {
        c->map[key]->val = val;
        remove_node(c->map[key]); insert_after_head(c, c->map[key]);
        return;
    }
    if (c->size == c->capacity) {
        DNode *lru = c->tail.prev;
        remove_node(lru); c->map[lru->key]=NULL; free(lru); c->size--;
    }
    DNode *n = malloc(sizeof(DNode));
    n->key=key; n->val=val;
    insert_after_head(c, n); c->map[key]=n; c->size++;
}

int main(void) {
    LRUCache *cache = lru_create(2);
    lru_put(cache,1,1); lru_put(cache,2,2);
    printf("%d\n", lru_get(cache,1));   /* 1 */
    lru_put(cache,3,3);                 /* evict key 2 */
    printf("%d\n", lru_get(cache,2));   /* -1 */
    printf("%d\n", lru_get(cache,3));   /* 3 */
    free(cache); return 0;
}

Pattern 30 Doubly Linked List Full Implementation
① Story First
A singly linked list is one-way traffic. A doubly linked list adds a lane going the other direction — every node knows both its successor and its predecessor. This makes backward traversal, O(1) deletion (given a pointer to the node), and ordered data structures like deques possible.
② The Insight
Every operation must maintain both prev and next pointers. Insertions and deletions touch four pointers instead of two. Using sentinel dummy head and tail eliminates all boundary special cases — every real node always has valid prev and next neighbors.
③ Step-by-Step Logic
  1. Node: {val, *prev, *next}. List: dummy head ↔ ... ↔ dummy tail.
  2. Insert after node p: new->next=p->next; new->prev=p; p->next->prev=new; p->next=new.
  3. Delete node n: n->prev->next=n->next; n->next->prev=n->prev; free(n).
Diagram
H ↔ [1] ↔ [2] ↔ [3] ↔ T Insert [X] after [1]: X->next=[2], X->prev=[1], [2]->prev=X, [1]->next=X H ↔ [1] ↔ [X] ↔ [2] ↔ [3] ↔ T ✓
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct DNode { int val; struct DNode *prev, *next; } DNode;
typedef struct { DNode head, tail; int size; } DList;

    L->head.next=&L->tail; L->tail.prev=&L->head;
    L->head.prev=L->tail.next=NULL; L->size=0;
}
void dl_insert_after(DList *L, DNode *p, int val) {
    DNode *n=malloc(sizeof(DNode)); n->val=val;
    n->next=p->next; n->prev=p;
    p->next->prev=n; p->next=n; L->size++;
}
void dl_delete(DList *L, DNode *n) {
    n->prev->next=n->next; n->next->prev=n->prev;
    free(n); L->size--;
}
void dl_print(DList *L) {
    for(DNode *c=L->head.next; c!=&L->tail; c=c->next)
        printf("%d ",c->val);
    printf("\n");
}

int main(void) {
    DList L; dl_init(&L);
    dl_insert_after(&L, &L.head, 1);
    dl_insert_after(&L, &L.head, 2);   /* insert at front: 2 1 */
    dl_insert_after(&L, L.tail.prev, 3); /* insert at back: 2 1 3 */
    dl_print(&L);   /* 2 1 3 */
    dl_delete(&L, L.head.next);  /* delete first real node (2) */
    dl_print(&L);   /* 1 3 */
    return 0;
}

Pattern 31 Circular Linked List
① Story First
Instead of the last node pointing to NULL, it points back to the head. Like a carousel that never stops — you can traverse indefinitely. Useful for round-robin scheduling and the Josephus problem.
② The Insight
In a circular list, the last node's next == head. Traversal stops after one full revolution (when cur == head again, not when cur == NULL). Insertion and deletion require finding the node before the target — which in a circular list always exists (there's no true "end").
③ Step-by-Step Logic
  1. Single node: node->next = node (points to itself).
  2. Append: find node before head (walk until next==head), insert after it.
  3. Traversal: start at head, stop when cur->next == head (or cur == head after first step).
Diagram
Circular: [1]→[2]→[3]→[4]→back to [1] ↑________________________↑ Traversal: start=1, visit 1,2,3,4, next=1=head → stop
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

Node *circular_append(Node *head, int val) {
    Node *n = malloc(sizeof(Node));
    n->val = val;
    if (!head) { n->next = n; return n; }   /* first node: self-loop */

    /* Walk to the node before head */
    Node *tail = head;
    while (tail->next != head) tail = tail->next;

    tail->next = n;   /* old tail → new node */
    n->next = head;   /* new node → head */
    return head;
}

void circular_print(Node *head, int count) {
    Node *cur = head;
    for (int i = 0; i < count; i++) {
        printf("%d ", cur->val);
        cur = cur->next;   /* wraps around automatically */
    }
    printf("\n");
}

int main(void) {
    Node *h = NULL;
    h = circular_append(h, 1);
    h = circular_append(h, 2);
    h = circular_append(h, 3);
    circular_print(h, 6);   /* 1 2 3 1 2 3 (wraps) */
    return 0;
}

⚠ Gotcha: Never use NULL check to detect list end

In a circular list, no node's next is ever NULL. Traversal must check cur == head (or cur->next == head) to detect a full revolution. Using while(cur) as the loop condition results in an infinite loop.

Pattern 32 XOR Linked List — Memory-Efficient Doubly Linked List
① Story First
A doubly linked list normally stores two pointers per node (prev and next). XOR trick: store prev XOR next in a single pointer field. To find next, XOR the "both" field with prev. To find prev, XOR with next. Halves pointer storage at the cost of needing to always know the previous node's address.
② The Insight
XOR is its own inverse: (a XOR b) XOR a = b. If each node stores prev_addr XOR next_addr, and you know where you came from (prev), you can compute where to go: next = node->both XOR prev. Traversal requires always knowing the previous node's pointer.
③ Step-by-Step Logic
  1. Node: {val, uintptr_t both} where both = (uintptr_t)prev XOR (uintptr_t)next.
  2. Traverse: keep prev and cur. next = (Node*)(cur->both XOR (uintptr_t)prev).
  3. Advance: prev=cur; cur=next.
Diagram
Nodes: [A] [B] [C] A.both = 0 XOR &B = &B B.both = &A XOR &C C.both = &B XOR 0 = &B Traverse forward from A: prev=NULL, cur=A next = A.both XOR 0 = &B → prev=A, cur=B next = B.both XOR &A = &C → prev=B, cur=C
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>

typedef struct XNode { int val; uintptr_t both; } XNode;

static uintptr_t XOR(XNode *a, XNode *b) {
    return (uintptr_t)a ^ (uintptr_t)b;
}

XNode *xlist_append(XNode *tail, XNode *prev_of_tail, int val) {
    XNode *n = malloc(sizeof(XNode));
    n->val = val;
    n->both = XOR(tail, NULL);   /* new tail: both = old_tail XOR NULL */
    if (tail) tail->both = XOR(prev_of_tail, n);  /* update old tail's next */
    return n;
}

void xlist_print(XNode *head) {
    XNode *prev = NULL, *cur = head;
    while (cur) {
        printf("%d ", cur->val);
        XNode *next = (XNode*)(cur->both ^ (uintptr_t)prev);
        prev = cur;
        cur = next;
    }
    printf("\n");
}

int main(void) {
    XNode *a=malloc(sizeof(XNode)); a->val=1; a->both=0;
    XNode *b=malloc(sizeof(XNode)); b->val=2; b->both=XOR(a,NULL);
    a->both=XOR(NULL,b);   /* a: prev=NULL, next=b */
    XNode *c=malloc(sizeof(XNode)); c->val=3; c->both=XOR(b,NULL);
    b->both=XOR(a,c);      /* b: prev=a, next=c */
    xlist_print(a);   /* 1 2 3 */
    free(a); free(b); free(c);
    return 0;
}

Pattern 33 Skip List — Concept and Structure
① Story First
A phone book with express lanes: the bottom layer has every entry, the layer above skips every other, the one above skips every fourth, and so on. To find something, start at the top express lane and drop down when you overshoot. Expected O(log n) search with O(n) space.
② The Insight
A skip list is a probabilistic data structure — each node is promoted to higher levels with probability 0.5 per level. Expected levels = log₂n. It achieves sorted-set operations (search, insert, delete) in O(log n) expected time without the complexity of balanced tree rotations.
③ Step-by-Step Logic
  1. Node has array of next[] pointers, one per level.
  2. Search: start at top level, advance while next[level] is ≤ target, then drop level.
  3. Insert: find insertion point per level, flip coins to determine height, link at each level.
  4. Delete: find predecessors at each level, relink.
Diagram
Level 3: [H] ─────────────────── [9] ─── [T] Level 2: [H] ─────── [3] ──────── [9] ─── [T] Level 1: [H] ─ [1] ─ [3] ─ [6] ─ [9] ─── [T] Level 0: [H] ─ [1] ─ [3] ─ [6] ─ [9] ─ [12] ─ [T] Search 6: start level 3: H→9 (overshoot), drop to L2 L2: H→3→9 (overshoot), drop to L1 L1: 3→6 FOUND ✓

#include <stdlib.h>
#include <time.h>

#define MAXLEVEL 16

typedef struct SNode {
    int val;
    struct SNode *next[MAXLEVEL];
} SNode;

typedef struct { SNode *head; int level; } SkipList;

static SNode *new_snode(int val) {
    SNode *n = calloc(1, sizeof(SNode));
    n->val = val; return n;
}

static int random_level(void) {
    int lvl = 1;
    while (rand() & 1 && lvl < MAXLEVEL) lvl++;
    return lvl;
}

SkipList *sl_create(void) {
    SkipList *sl = malloc(sizeof(SkipList));
    sl->head = new_snode(-1); sl->level = 1; return sl;
}

void sl_insert(SkipList *sl, int val) {
    SNode *update[MAXLEVEL];
    SNode *cur = sl->head;
    for (int i = sl->level-1; i >= 0; i--) {
        while (cur->next[i] && cur->next[i]->val < val)
            cur = cur->next[i];
        update[i] = cur;
    }
    int lvl = random_level();
    if (lvl > sl->level) {
        for (int i = sl->level; i < lvl; i++) update[i] = sl->head;
        sl->level = lvl;
    }
    SNode *n = new_snode(val);
    for (int i = 0; i < lvl; i++) {
        n->next[i] = update[i]->next[i];
        update[i]->next[i] = n;
    }
}

int sl_search(SkipList *sl, int val) {
    SNode *cur = sl->head;
    for (int i = sl->level-1; i >= 0; i--)
        while (cur->next[i] && cur->next[i]->val < val)
            cur = cur->next[i];
    return cur->next[0] && cur->next[0]->val == val;
}

int main(void) {
    srand(42);
    SkipList *sl = sl_create();
    sl_insert(sl,3); sl_insert(sl,6); sl_insert(sl,9);
    printf("%d\n", sl_search(sl,6));  /* 1 */
    printf("%d\n", sl_search(sl,5));  /* 0 */
    return 0;
}

Skip lists are probabilistic. With unlucky coin flips, all nodes could land at level 1, making the structure a plain linked list with O(n) search. Pattern 34 Swap Node Values vs Swap Nodes
① Story First
Two ways to "swap" nodes in a linked list: the easy way (just swap the values stored in the nodes — O(1) pointer work) and the hard way (actually rewire the nodes themselves, preserving pointer topology). The hard way matters when external pointers or prev-pointers reference specific nodes.
② The Insight
Value swap: tmp=a->val; a->val=b->val; b->val=tmp. Simple, but breaks if the caller holds a pointer to a node expecting a specific value. Pointer swap (actual node swap) is complex because you need to find predecessors of both nodes and handle the case where the nodes are adjacent.
③ Step-by-Step Logic
  1. Swap values: just swap the val fields. O(1). Externally visible pointers are stable.
  2. Swap nodes: find prev1, prev2. Handle adjacent case separately. Rewire four next pointers.
  3. LeetCode 1721 only asks for value swap after finding the kth-from-start and kth-from-end.
Diagram
Swap values (simple): [A:1] ↔ [B:2] ↔ [C:3] swap A.val ↔ C.val → [A:3] ↔ [B:2] ↔ [C:1] External ptr to A still points to A — value changed ✓ Swap nodes (hard): prev_A→[A]→...→[C]→next_C needs: prev_A→[C]→...→[A]→next_C (complex rewiring)

#include <stdio.h>

typedef struct Node { int val; struct Node *next; } Node;

/* Swap values of kth from start and kth from end */
Node *swap_kth(Node *head, int k) {
    Node *first=head, *second=head, *cur=head;

    /* Find kth from start */
    for(int i=1;i<k;i++) first=first->next;

    /* Use two-pointer gap to find kth from end */
    cur=first;
    while(cur->next){cur=cur->next;second=second->next;}
    /* second is now kth from end */

    /* Swap values — simple and correct */
    int tmp=first->val; first->val=second->val; second->val=tmp;
    return head;
}

Pattern 35 Josephus Problem — Circular List Simulation
① Story First
N people stand in a circle. Count around the circle; every kth person is eliminated. Who's last standing? Simulate using a circular linked list: walk k-1 steps, remove the kth person, repeat until one remains. The classic circular list problem.
② The Insight
Circular linked list simulation: maintain a current pointer. Advance k-1 times (stopping one before the node to remove). Remove cur->next. Repeat until the list has one node. There's also a mathematical O(n) formula: f(n,k) = (f(n-1,k)+k) mod n, but the list simulation is more instructive.
③ Step-by-Step Logic
  1. Build circular linked list of N nodes (1 to N).
  2. Start at head. Advance k-1 steps. The next node is eliminated.
  3. Remove it: cur->next = cur->next->next. Free the removed node.
  4. Repeat until cur->next == cur (single node). Return cur->val.

④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *next; } Node;

int josephus(int n, int k) {
    /* Build circular list 1..n */
    Node *head = NULL, *tail = NULL;
    for (int i = 1; i <= n; i++) {
        Node *nd = malloc(sizeof(Node)); nd->val=i;
        if (!head) { head=tail=nd; nd->next=nd; }
        else { tail->next=nd; nd->next=head; tail=nd; }
    }

    Node *cur = head;
    while (cur->next != cur) {         /* while more than one node */
        for (int i=0; i<k-1; i++) cur=cur->next;  /* walk k-1 */
        Node *del = cur->next;
        cur->next = del->next;         /* remove kth node */
        free(del);
    }
    int winner = cur->val;
    free(cur);
    return winner;
}

int main(void) {
    printf("n=5,k=2: winner=%d\n", josephus(5,2));  /* 3 */
    printf("n=6,k=3: winner=%d\n", josephus(6,3));  /* 1 */
    return 0;
}

⚠ Gotcha: Starting position affects the winner

The classic Josephus problem starts counting from person 1. If you start cur at head (person 1) and the first person eliminated is the kth one (not the 1st), make sure your loop walks exactly k-1 steps before eliminating the NEXT node. Off-by-one in the starting position or step count changes who wins.
