Pattern 01 Null Terminator and strlen
① Story First
In C, a string isn't a special type — it's just an array of characters with a contract: the last character is always '\0' (ASCII value 0). Everything from reading to copying to printing stops when it hits that sentinel. strlen just counts characters until it finds the '\0' — that's the whole secret.
② The Insight
The null terminator is the only thing that separates a C string from raw bytes. Remove it (or forget it during manual construction) and every string function will read past the end of your buffer until it finds some zero byte in memory — which could be kilobytes away.
③ Step-by-Step Logic
  1. String literal "hello" stores 6 bytes: h e l l o \0.
  2. strlen walks from index 0 until it finds '\0', returns the count.
  3. Buffer must be at least strlen + 1 bytes to hold the string + terminator.
  4. Manual string construction must explicitly place '\0' at the end.
Diagram
"hello" in memory: index: 0 1 2 3 4 5 char: 'h' 'e' 'l' 'l' 'o' '\0' hex: 68 65 6C 6C 6F 00 strlen("hello") → walks 0,1,2,3,4 → hits '\0' at 5 → returns 5 sizeof("hello") → 6 (includes '\0')
④ Annotated Code
#include <stdio.h>
#include <string.h>   /* for strlen */

/* Manual strlen — returns length without counting '\0' */
size_t my_strlen(const char *s) {
    size_t len = 0;
    while (s[len] != '\0')   /* walk until null terminator */
        len++;
    return len;              /* does not include '\0' */
}

int main(void) {
    char s[] = "hello";           /* 6 bytes: h e l l o \0 */
    printf("strlen=%zu\n", strlen(s));      /* 5 */
    printf("my_strlen=%zu\n", my_strlen(s));/* 5 */
    printf("sizeof=%zu\n", sizeof(s));      /* 6 (includes \0) */

    /* Manual string construction — must place '\0' */
    char buf[6];
    buf[0]='w'; buf[1]='o'; buf[2]='r'; buf[3]='l'; buf[4]='d';
    buf[5] = '\0';             /* WITHOUT this, strlen reads past end! */
    printf("%s len=%zu\n", buf, strlen(buf));   /* world 5 */
    return 0;
}
⑤ Dry Run
my_strlen("hello"): s[0]='h' ≠ '\0' → len=1 s[1]='e' ≠ '\0' → len=2 s[2]='l' ≠ '\0' → len=3 s[3]='l' ≠ '\0' → len=4 s[4]='o' ≠ '\0' → len=5 s[5]='\0' → stop, return 5 ✓
⚠ Gotcha: Buffer must hold strlen+1 bytes

If you declare char buf[5] and copy "hello" into it, there's no room for '\0'. The string appears to work but strlen and printf will read past the end. Always allocate strlen(src) + 1 bytes. Better yet, use strnlen and snprintf in real code.

When working with C strings → think: "every string ends in '\0'; buffer needs strlen+1 bytes."
Pattern 02 Manual strcpy and Buffer Safety
① Story First
Copying a string in C is like transcribing a scroll — you copy character by character until you hit the end marker. The classic strcpy does exactly this. The danger: if you don't know how big your destination scroll is, you might write off the edge and overwrite the next scroll (adjacent memory) — a buffer overflow.
② The Insight
strcpy is unsafe because it trusts the destination is big enough. The safe pattern is always to use snprintf(dest, sizeof(dest), "%s", src) or strncpy (with explicit null termination), and always check that the destination buffer is large enough before copying.
③ Step-by-Step Logic
  1. Allocate destination: at least strlen(src) + 1 bytes.
  2. Copy byte by byte until and including the '\0'.
  3. For safe copy: use snprintf which always null-terminates and never overflows.
  4. Verify destination was large enough (check return value of snprintf).
Diagram
src: [h][e][l][l][o][\0] dst: [?][?][?][?][?][?] (need at least 6 bytes) strcpy loop: i=0: dst[0]='h', i=1: dst[1]='e', ... i=5: dst[5]='\0' → stop BUFFER OVERFLOW: src: [h][e][l][l][o][\0] dst: [?][?][?] (only 3 bytes — writes into adjacent memory!)
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Manual strcpy — educational only, use snprintf in real code */
char *my_strcpy(char *dst, const char *src) {
    char *start = dst;           /* save start to return */
    while ((*dst++ = *src++))    /* copy including '\0'; loop ends when '\0' copied */
        ;
    return start;
}

/* Safe copy using snprintf — always null-terminates */
void safe_copy(char *dst, size_t dst_size, const char *src) {
    int written = snprintf(dst, dst_size, "%s", src);
    if (written >= (int)dst_size)
        fprintf(stderr, "Warning: string truncated\n");
}

int main(void) {
    char src[] = "hello world";

    /* Safe: buffer sized correctly */
    char dst1[20];
    safe_copy(dst1, sizeof(dst1), src);
    printf("copied: %s\n", dst1);

    /* Dangerous: small buffer — snprintf truncates, not overflow */
    char dst2[5];
    safe_copy(dst2, sizeof(dst2), src);  /* "hell\0" — truncated, but safe */
    printf("truncated: %s\n", dst2);     /* prints: hell */
    return 0;
}
⑤ Dry Run
my_strcpy(dst, "hi"): *dst++ = 'h' → dst[0]='h', not '\0' → continue *dst++ = 'i' → dst[1]='i', not '\0' → continue *dst++ = '\0' → dst[2]='\0', condition is '\0'=0=false → stop dst = "hi\0" ✓ safe_copy(dst2, 5, "hello world"): snprintf writes min(11, 5-1)=4 chars + '\0' dst2 = "hell\0" written=11 >= 5 → prints truncation warning
⚠ Gotcha: strncpy does NOT always null-terminate

strncpy(dst, src, n) copies at most n chars but if src is n or more chars long, the result is NOT null-terminated. You must manually add dst[n-1] = '\0'. This surprises nearly every C programmer. Prefer snprintf which always null-terminates within the given size.

N/A (C mechanics)
When copying a C string → think: "destination needs strlen+1 bytes; use snprintf for safety."
Pattern 03 Manual strcmp — Lexicographic Comparison
① Story First
A dictionary sorts words by comparing letters one at a time. "apple" comes before "apply" because at position 4, 'e' (101) comes before 'y' (121) in ASCII. strcmp does exactly this: compare character by character; the first mismatch decides the order; if one string runs out first, it's "less than" the longer one.
② The Insight
strcmp returns negative if s1 < s2, 0 if equal, positive if s1 > s2 — based on the first differing byte's ASCII values. Equality requires every character to match AND both strings end at the same position.
③ Step-by-Step Logic
  1. Walk both strings simultaneously while characters are equal and not '\0'.
  2. When the loop ends: return (unsigned char)s1[i] - (unsigned char)s2[i].
  3. If both are '\0' at the same position, the strings are equal (returns 0).
  4. Cast to unsigned char to avoid sign-extension issues with chars > 127.
Diagram
strcmp("apple", "apply"): i=0: 'a'=='a' → continue i=1: 'p'=='p' → continue i=2: 'p'=='p' → continue i=3: 'l'=='l' → continue i=4: 'e' vs 'y' → 101 - 121 = -20 → return negative (s1 < s2) strcmp("cat", "cat"): i=0,1,2: 'c','a','t' all match i=3: '\0' == '\0' → return 0 (equal)
④ Annotated Code
#include <stdio.h>

/* Manual strcmp: negative if s1<s2, 0 if equal, positive if s1>s2 */
int my_strcmp(const char *s1, const char *s2) {
    /* Walk while characters match and neither string has ended */
    while (*s1 && *s1 == *s2) {
        s1++;
        s2++;
    }
    /* Return difference of first differing bytes (or both '\0' → 0) */
    return (unsigned char)*s1 - (unsigned char)*s2;
}

int main(void) {
    printf("%d\n", my_strcmp("apple", "apply"));  /* negative */
    printf("%d\n", my_strcmp("cat",   "cat"));    /* 0 */
    printf("%d\n", my_strcmp("z",     "a"));      /* positive */

    /* Common use: sorting condition */
    const char *words[] = {"banana", "apple", "cherry"};
    /* Use strcmp result in conditions */
    if (my_strcmp(words[0], words[1]) > 0)
        printf("banana comes after apple\n");
    return 0;
}
⑤ Dry Run
my_strcmp("cat", "car"): *s1='c', *s2='c' → equal, advance *s1='a', *s2='a' → equal, advance *s1='t', *s2='r' → not equal, exit loop return (unsigned char)'t' - (unsigned char)'r' = 116-114 = 2 (positive → s1 > s2)
⚠ Gotcha: Don't compare strings with ==

if (s1 == s2) compares pointer addresses, not string content. Two different string literals with the same content have different addresses (usually). Always use strcmp(s1, s2) == 0 for content equality.

Pattern 04 String Reversal In-Place
① Story First
To reverse a sentence written on a strip of paper, you swap the first and last letters, then the second and second-to-last, and so on, moving inward until the two ends meet in the middle. Two pointers, one from each end, swapping and converging.
② The Insight
In-place reversal uses two pointers (left at 0, right at len-1) that converge toward the center, swapping characters at each step. Stop when left >= right. This uses O(1) extra space and works in O(n) time.
③ Step-by-Step Logic
  1. Compute length, set lo = 0, hi = len - 1.
  2. While lo < hi: swap s[lo] and s[hi].
  3. Advance lo++, retreat hi--.
  4. Loop ends when pointers cross — string is fully reversed.
Diagram
"hello" → reverse → "olleh" Step 1: [h][e][l][l][o] lo=0, hi=4 → swap h↔o [o][e][l][l][h] lo=1, hi=3 → swap e↔l [o][l][l][e][h] lo=2, hi=2 → lo >= hi, stop Result: "olleh" ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

void reverse_string(char *s) {
    int lo = 0, hi = (int)strlen(s) - 1;
    while (lo < hi) {
        char tmp = s[lo];   /* standard 3-step swap */
        s[lo] = s[hi];
        s[hi] = tmp;
        lo++;
        hi--;
    }
}

int main(void) {
    char s[] = "hello";       /* mutable: stack array */
    reverse_string(s);
    printf("%s\n", s);        /* "olleh" */

    char t[] = "abcde";
    reverse_string(t);
    printf("%s\n", t);        /* "edcba" */
    return 0;
}
⑤ Dry Run
"hello", lo=0, hi=4: swap s[0]='h' ↔ s[4]='o' → "oellh", lo=1, hi=3 swap s[1]='e' ↔ s[3]='l' → "oleh...", lo=2, hi=2 lo >= hi → stop result: "olleh" ✓
⚠ Gotcha: String literals are immutable

char *s = "hello"; points to a string literal in read-only memory. Calling reverse_string(s) causes undefined behavior (usually a segfault). To get a mutable copy, use char s[] = "hello"; which copies the literal onto the stack.

Pattern 05 String Search — strstr Logic
① Story First
Looking for the word "cat" in "the black cat sat" — you scan left to right; whenever you find a 'c', you check if the next two characters are 'a' and 't'. If yes, you found it. If no, you move forward one position and keep scanning. This is naïve string search, and it's what strstr does under the hood.
② The Insight
Naïve string search is O(n×m) but works perfectly for typical inputs. For every position in the haystack, attempt to match the needle character by character. The outer loop advances one step at a time; the inner loop checks the full needle. On first mismatch, break inner and advance outer.
③ Step-by-Step Logic
  1. For each position i in haystack (while room remains for needle).
  2. Try matching needle starting at haystack[i].
  3. If all needle chars match, return &haystack[i].
  4. If any mismatch, advance i by 1 and retry.
  5. Return NULL if no match found.
Diagram
haystack: "the black cat sat" needle: "cat" i=0: 't'≠'c' skip i=1: 'h'≠'c' skip ... i=10: 'c'=='c' → check 'a'=='a' → check 't'=='t' → MATCH at i=10 return &haystack[10] → "cat sat"
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Returns pointer to first occurrence of needle in haystack, or NULL */
const char *my_strstr(const char *haystack, const char *needle) {
    if (!*needle) return haystack;   /* empty needle matches at start */
    size_t nlen = strlen(needle);
    size_t hlen = strlen(haystack);
    if (nlen > hlen) return NULL;    /* needle longer than haystack */

    for (size_t i = 0; i <= hlen - nlen; i++) {
        size_t j = 0;
        while (j < nlen && haystack[i+j] == needle[j])
            j++;                     /* advance while chars match */
        if (j == nlen)
            return &haystack[i];     /* full needle matched here */
    }
    return NULL;
}

int main(void) {
    const char *h = "the black cat sat";
    const char *found = my_strstr(h, "cat");
    if (found)
        printf("Found: \"%s\"\n", found);   /* "cat sat" */
    else
        printf("Not found\n");

    printf("strstr check: %s\n", strstr(h, "cat")); /* same result */
    return 0;
}
⑤ Dry Run
haystack="hello world", needle="world" hlen=11, nlen=5, loop i=0..6: i=0: h≠w → j=0 only i=1: e≠w → j=0 only ... i=6: w==w → j=1: o==o → j=2: r==r → j=3: l==l → j=4: d==d → j=5==nlen → MATCH return &haystack[6] → "world" ✓
⚠ Gotcha: O(n×m) worst case

Naïve search is slow for patterns like needle="aaab" in haystack="aaaa...aab" — it retries nearly every position. For production pattern matching with large inputs, use KMP (Pattern 31-32) which is O(n+m).

Pattern 06 Character Frequency Count
① Story First
A librarian counts how many copies of each book are on the shelf by walking along and making a tally mark for each title. In C, a character frequency array is exactly that tally: a 26-element array (or 256 for all ASCII) where each index represents a character and the value is how many times it appeared.
② The Insight
Characters are just small integers (ASCII 0-127). Use the character as an array index: freq[c - 'a']++ for lowercase letters. This gives O(1) lookup and update, and the whole frequency table is built in O(n) time. It's the core building block for anagram checks, permutation problems, and sliding window frequency tracking.
③ Step-by-Step Logic
  1. Declare int freq[26] = {0} (or freq[128] for all ASCII).
  2. Walk the string: for each char c, do freq[c - 'a']++.
  3. To compare two strings' frequencies: build both tables, compare arrays.
  4. To check if a char appears: freq[c - 'a'] > 0.
Diagram
"banana": b → freq[1]++ a → freq[0]++ n → freq[13]++ a → freq[0]++ n → freq[13]++ a → freq[0]++ freq: a=3, b=1, n=2, rest=0
④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <ctype.h>

void char_frequency(const char *s, int freq[26]) {
    memset(freq, 0, 26 * sizeof(int));   /* zero out */
    for (; *s; s++) {
        if (islower(*s))
            freq[*s - 'a']++;   /* 'a'=0, 'b'=1, ..., 'z'=25 */
    }
}

/* Check if two strings are anagrams */
int is_anagram(const char *a, const char *b) {
    if (strlen(a) != strlen(b)) return 0;   /* must be same length */
    int fa[26], fb[26];
    char_frequency(a, fa);
    char_frequency(b, fb);
    return memcmp(fa, fb, sizeof(fa)) == 0; /* byte-wise comparison */
}

int main(void) {
    int freq[26];
    char_frequency("banana", freq);
    for (int i = 0; i < 26; i++)
        if (freq[i]) printf("%c:%d ", 'a'+i, freq[i]);
    printf("\n");   /* a:3 b:1 n:2 */

    printf("anagram: %d\n", is_anagram("listen", "silent"));  /* 1 */
    printf("anagram: %d\n", is_anagram("hello",  "world"));   /* 0 */
    return 0;
}
⑤ Dry Run
is_anagram("listen", "silent"): freq("listen"): e=1,i=1,l=1,n=1,s=1,t=1 freq("silent"): e=1,i=1,l=1,n=1,s=1,t=1 memcmp → 0 (equal) → return 1 (yes, anagram) ✓
⚠ Gotcha: Only works for lowercase ASCII

freq[c - 'a'] only works if c is guaranteed to be a lowercase letter. For mixed-case or arbitrary ASCII, use freq[(unsigned char)c] with a 128 or 256 element array. Always cast to unsigned char before using a char as an array index.

Pattern 07 Remove Duplicates from String
① Story First
A bouncer at a club only lets each person in once. As you walk the guest list, you check a "seen" book. If the name is new, let them in and record them. If the name is already in the book, skip them. The result is a unique-only list in original order.
② The Insight
Use a boolean seen[26] array as a hash set for O(1) lookup. Walk the input string with a read pointer; only copy to the write pointer when the character hasn't been seen yet. This is an in-place two-pointer approach with O(n) time and O(1) space.
③ Step-by-Step Logic
  1. Initialize seen[26] = {0} and write index w = 0.
  2. For each character c in the string:
  3. If !seen[c-'a']: copy to s[w++], mark seen[c-'a'] = 1.
  4. After loop: null-terminate at s[w] = '\0'.
Diagram
"abacbc" r=0: 'a' new → write, seen[a]=1, w=1 r=1: 'b' new → write, seen[b]=1, w=2 r=2: 'a' seen → skip r=3: 'c' new → write, seen[c]=1, w=3 r=4: 'b' seen → skip r=5: 'c' seen → skip result: "abc\0"
④ Annotated Code
#include <stdio.h>
#include <string.h>

void remove_duplicates(char *s) {
    int seen[26] = {0};   /* boolean presence for 'a'..'z' */
    int w = 0;            /* write index */
    for (int r = 0; s[r]; r++) {
        int idx = s[r] - 'a';
        if (!seen[idx]) {
            seen[idx] = 1;   /* mark as seen */
            s[w++] = s[r];   /* copy to write position */
        }
    }
    s[w] = '\0';          /* null-terminate the shortened string */
}

int main(void) {
    char s[] = "abacbc";
    remove_duplicates(s);
    printf("%s\n", s);    /* "abc" */

    char t[] = "programming";
    remove_duplicates(t);
    printf("%s\n", t);    /* "progamin" */
    return 0;
}
⑤ Dry Run
"programming": p→new w=1, r→new w=2, o→new w=3, g→new w=4, r→seen skip, a→new w=5, m→new w=6, m→seen skip, i→new w=7, n→new w=8, g→seen skip s[8]='\0' result: "progamin" ✓
⚠ Gotcha: Only handles lowercase a-z

The seen[26] approach assumes lowercase ASCII letters. For arbitrary characters, use seen[128] with idx = (unsigned char)s[r]. For Unicode, you'd need a hash set.

Pattern 08 String Tokenizer — strtok Logic
① Story First
You're cutting a pizza into slices along the scored lines. You find the first score line, cut there, hand off the slice, then look for the next score line from where you left off. strtok works the same way: find a delimiter, replace it with '\0' (the cut), return the token (the slice), and remember where the next search starts.
② The Insight
strtok is destructive — it writes '\0' into the string at each delimiter. It uses a static pointer to remember its position across calls. Call with the string the first time, then pass NULL for subsequent tokens. Because it uses a hidden static variable, it is NOT thread-safe — use strtok_r in multithreaded code.
③ Step-by-Step Logic
  1. First call: strtok(str, delim) — sets internal pointer to str, finds first token.
  2. Replace delimiter with '\0', return pointer to start of token.
  3. Subsequent calls: strtok(NULL, delim) — continues from saved position.
  4. Returns NULL when no more tokens remain.
Diagram
"one,two,three" ↑saved strtok(s,","): finds ',', writes '\0' → "one\0two,three" returns "one" strtok(NULL,","): resumes at 'two', finds ',' → "one\0two\0three" returns "two" strtok(NULL,","): resumes at 'three', no ',' found → returns "three" strtok(NULL,","): returns NULL (done)
④ Annotated Code
#include <stdio.h>
#include <string.h>

int main(void) {
    char csv[] = "alice,bob,charlie,dave";   /* mutable copy required! */
    const char *delim = ",";

    /* First call: pass the string */
    char *token = strtok(csv, delim);
    while (token != NULL) {
        printf("token: %s\n", token);
        token = strtok(NULL, delim);   /* subsequent calls: pass NULL */
    }
    /* csv is now "alice\0bob\0charlie\0dave" — modified! */

    /* Thread-safe version with strtok_r */
    char path[] = "/usr/local/bin";
    char *saveptr;           /* caller-managed state, not static */
    char *part = strtok_r(path, "/", &saveptr);
    while (part) {
        printf("part: %s\n", part);
        part = strtok_r(NULL, "/", &saveptr);
    }
    return 0;
}
⑤ Dry Run
csv = "alice,bob" strtok(csv, ","): scan: a,l,i,c,e → ',' found at i=5 csv[5] = '\0' → "alice\0bob" saved_ptr = &csv[6] (points to 'b') returns "alice" strtok(NULL, ","): resume from saved_ptr='b' scan: b,o,b → '\0' at end → no more commas returns "bob" strtok(NULL, ","): returns NULL
⚠ Gotcha: strtok modifies the string and is not reentrant

You cannot tokenize two strings simultaneously with strtok because it has one hidden static pointer shared across calls. Also, you cannot pass a string literal — strtok writes '\0' delimiters into the string, which crashes on read-only memory. Always pass a mutable copy (char buf[] = "..."). Use strtok_r for reentrancy.

When splitting a string by delimiter → think: strtok (first call with string, rest with NULL); use strtok_r for threads.
Pattern 09 atoi — String to Integer Conversion
① Story First
You're reading a price tag "42" on a shelf. Your brain converts the characters '4' and '2' into the number forty-two: take the first digit (4), multiply by 10 to make room, add the next digit (2) — done. atoi does exactly this, digit by digit, handling an optional leading sign.
② The Insight
Each digit character has ASCII value ('0' + digit value), so c - '0' gives the numeric digit. Build the number left-to-right: result = result * 10 + digit. Handle optional leading sign and skip leading whitespace. This is O(n) and the basis of LeetCode 8 (myAtoi).
③ Step-by-Step Logic
  1. Skip leading whitespace.
  2. Check for optional '+' or '-' sign; record it.
  3. While the current char is a digit: result = result * 10 + (c - '0').
  4. Apply sign. Clamp to INT_MAX / INT_MIN for robust implementation.
Diagram
" -42abc" skip spaces → '-' sign = -1, advance '4': result = 0*10 + 4 = 4 '2': result = 4*10 + 2 = 42 'a': not digit → stop return -1 * 42 = -42
④ Annotated Code
#include <stdio.h>
#include <limits.h>
#include <ctype.h>

int my_atoi(const char *s) {
    while (isspace(*s)) s++;       /* skip leading whitespace */

    int sign = 1;
    if (*s == '-') { sign = -1; s++; }
    else if (*s == '+') s++;

    long result = 0;
    while (isdigit(*s)) {
        result = result * 10 + (*s - '0');
        /* clamp to avoid overflow before returning */
        if (result * sign >= INT_MAX) return INT_MAX;
        if (result * sign <= INT_MIN) return INT_MIN;
        s++;
    }
    return (int)(sign * result);
}

① Story First

② The Insight
Repeatedly take n % 10 to get the least significant digit, convert to char with '0' + digit, append to buffer, then divide n by 10. The resulting string is reversed — reverse it at the end. Handle negative numbers by recording the sign and working with the absolute value.
③ Step-by-Step Logic
  1. Handle special case: n == 0 → "0".
  2. If n < 0: record sign, negate n (use long for INT_MIN).
  3. While n > 0: buf[i++] = '0' + (n % 10); n /= 10.
  4. If negative: buf[i++] = '-'.
  5. Reverse buf[0..i-1]; null-terminate.

#include <stdio.h>
#include <string.h>

/* Writes integer n as decimal string into buf. buf must be >= 12 bytes. */
void my_itoa(int n, char *buf) {
    if (n == 0) { buf[0]='0'; buf[1]='\0'; return; }

    int neg = (n < 0);
    long val = neg ? -(long)n : (long)n;   /* long handles INT_MIN */

    int i = 0;
    while (val > 0) {
        buf[i++] = '0' + (int)(val % 10);  /* least significant digit first */
        val /= 10;
    }
    if (neg) buf[i++] = '-';   /* add sign last (will be reversed to front) */
    buf[i] = '\0';

    /* reverse: digits were written in reverse order */
    int lo = 0, hi = i - 1;
    while (lo < hi) {
        char tmp = buf[lo]; buf[lo] = buf[hi]; buf[hi] = tmp;
        lo++; hi--;
    }
}

    char buf[12];

    my_itoa(0,     buf); printf("%s\n", buf);   /* "0" */
    return 0;
}

① Story First

#include <stdio.h>
#include <string.h>
#include <limits.h>

void min_window(const char *s, const char *t, char *out) {
    int need[128] = {0}, window[128] = {0};
    int required = 0, formed = 0;

    for (int i = 0; t[i]; i++) {
        if (need[(unsigned char)t[i]]++ == 0) required++;   /* new distinct char */
    }

    int left = 0, best_left = 0, best_len = INT_MAX;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        int c = (unsigned char)s[right];
        window[c]++;
        if (need[c] > 0 && window[c] == need[c]) formed++;   /* satisfied */

        while (formed == required) {   /* valid window — try to shrink */
            if (right - left + 1 < best_len) {
                best_len = right - left + 1;
                best_left = left;
            }
            int lc = (unsigned char)s[left];
            window[lc]--;
            if (need[lc] > 0 && window[lc] < need[lc]) formed--;   /* unsatisfied */
            left++;
        }
    }

    if (best_len == INT_MAX) { out[0] = '\0'; return; }
    strncpy(out, s + best_left, best_len);
    out[best_len] = '\0';
}

    char result[100];
    min_window("ADOBECODEBANC", "ABC", result);
    printf("%s\n", result);   /* "BANC" */
    return 0;
}

int is_anagram(const char *a, const char *b) {

#include <stdio.h>
#include <string.h>

int character_replacement(const char *s, int k) {
    int freq[26] = {0}, left = 0, max_freq = 0, max_len = 0;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        int c = s[right] - 'a';
        freq[c]++;
        if (freq[c] > max_freq) max_freq = freq[c];   /* update dominant freq */

            left++;
        }

        if (window > max_len) max_len = window;
    }
    return max_len;
}

Pattern 18 Count Substrings with Exactly K Distinct Characters
① Story First
Counting windows with exactly K distinct chars is tricky because a window "grows" as you add chars, not cleanly bounded. The trick: express "exactly K" as "at most K" minus "at most K-1." Sliding window gives at-most counts easily; the difference gives the exact count.
② The Insight
count(exactly K) = count(at most K) - count(at most K-1). The at-most-K count: for each right, expand right and shrink left until distinct ≤ K — then every window ending at right starting anywhere from [0..left] is valid, contributing (right - left + 1) windows.
③ Step-by-Step Logic
  1. Write helper at_most_k(s, k) counting substrings with ≤k distinct chars.
  2. Maintain freq[], distinct, left. For each right: add char; shrink until distinct ≤ k.
  3. Add right - left + 1 to count (all windows ending here with valid left start).
  4. Return at_most_k(s, k) - at_most_k(s, k-1).
Diagram

④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Count substrings with AT MOST k distinct characters */
long at_most_k(const char *s, int k) {
    int freq[128] = {0}, distinct = 0, left = 0;
    long count = 0;
    int n = (int)strlen(s);
    for (int right = 0; right < n; right++) {
        if (freq[(unsigned char)s[right]]++ == 0) distinct++;
        while (distinct > k) {
            if (--freq[(unsigned char)s[left]] == 0) distinct--;
            left++;
        }
        count += right - left + 1;   /* all valid windows ending at right */
    }
    return count;
}

/* Count substrings with EXACTLY k distinct characters */
long count_exactly_k(const char *s, int k) {
    return at_most_k(s, k) - at_most_k(s, k - 1);
}

int main(void) {
    printf("%ld\n", count_exactly_k("aab", 1));    /* 4 */
    printf("%ld\n", count_exactly_k("abc", 2));    /* 2 ("ab","bc") */
    printf("%ld\n", count_exactly_k("abcba", 2));  /* 6 */
    return 0;
}

Pattern 19 Minimum Consecutive Cards to Pick Up
① Story First
You're picking cards from a deck one at a time. You need to collect at least one pair of matching cards. What's the minimum number of consecutive cards you must draw to guarantee picking up a matching pair? The moment you see a card you already have in hand, that stretch is your window.
② The Insight
Use a hash map (or frequency array) to track the last seen index of each card value. When you encounter a card you've seen before, the window from its last occurrence to now is a valid window containing a pair. Track the minimum such window length.
③ Step-by-Step Logic
  1. Initialize last_seen[] to -1 for all values.
  2. For each index i: if last_seen[cards[i]] != -1, compute window = i - last_seen[cards[i]] + 1.
  3. Update min_len; always update last_seen[cards[i]] = i.
  4. Return min_len (or -1 if no pair found).

#include <stdio.h>
#include <string.h>
#include <limits.h>

#define MAX_VAL 1001

int minimum_card_pickup(int *cards, int n) {
    int last[MAX_VAL];
    memset(last, -1, sizeof(last));   /* -1 = not seen */

    int min_len = INT_MAX;
    for (int i = 0; i < n; i++) {
        int v = cards[i];
        if (last[v] != -1) {
            int window = i - last[v] + 1;   /* inclusive window length */
            if (window < min_len) min_len = window;
        }
        last[v] = i;   /* always update: we want MOST RECENT occurrence */
    }
    return (min_len == INT_MAX) ? -1 : min_len;
}

int main(void) {
    int c1[] = {3,4,2,3,4,7};
    printf("%d\n", minimum_card_pickup(c1, 6));   /* 4 */

    int c2[] = {1,0,5,3};
    printf("%d\n", minimum_card_pickup(c2, 4));   /* -1 (no pair) */
    return 0;
}

Pattern 20 Max Vowels in Substring of Length K
① Story First
You have a telescope that can only view exactly K consecutive letters at a time. You want to point it at the section that contains the most vowels. Slide it one step at a time — when you move right, you gain one letter (might be a vowel) and lose one letter from the left (might have been a vowel).
② The Insight
Fixed-size sliding window. Count vowels in the initial window of size k. Then slide: if the character entering from the right is a vowel, increment; if the character leaving from the left was a vowel, decrement. O(n) total, O(1) space.
③ Step-by-Step Logic
  1. Count vowels in s[0..k-1]; record as max_v = curr_v.
  2. For each new right position r from k to n-1:
  3. Add is_vowel(s[r]); subtract is_vowel(s[r-k]).
  4. Update max_v = max(max_v, curr_v).

#include <string.h>

static int is_vowel(char c) {
    return c=='a'||c=='e'||c=='i'||c=='o'||c=='u';

int max_vowels(const char *s, int k) {

Pattern 21 Valid Palindrome — Two Pointer
① Story First
A word reads the same forwards and backwards. To check, place one finger on the first letter and one on the last. If they match, move both fingers inward. If they ever don't match, it's not a palindrome. If the fingers meet or cross without a mismatch, it is.
② The Insight
Two pointers from both ends, converging inward. For the "valid palindrome" variant (ignoring non-alphanumeric), skip non-alphanumeric characters before comparing. Compare case-insensitively using tolower.
③ Step-by-Step Logic
  1. Set lo = 0, hi = strlen(s) - 1.
  2. While lo < hi: skip non-alphanumeric chars from both ends.
  3. If tolower(s[lo]) != tolower(s[hi]): return false.
  4. Advance lo++, hi--. If loop completes: return true.
Diagram

④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int is_palindrome(const char *s) {
    int lo = 0, hi = (int)strlen(s) - 1;
    while (lo < hi) {
        while (lo < hi && !isalnum(s[lo])) lo++;   /* skip non-alnum */
        while (lo < hi && !isalnum(s[hi])) hi--;
        if (tolower(s[lo]) != tolower(s[hi])) return 0;
        lo++; hi--;
    }
    return 1;
}

int main(void) {
    printf("%d\n", is_palindrome("A man, a plan, a canal: Panama")); /* 1 */
    printf("%d\n", is_palindrome("race a car"));                     /* 0 */
    printf("%d\n", is_palindrome(" "));                              /* 1 */
    return 0;
}

The inner while (!isalnum(s[lo])) lo++ must also check lo < hi. Without it, on an all-punctuation string, lo would overshoot hi and you'd compare garbage indices.

Pattern 22 Expand Around Center
① Story First
Drop a stone in a pond — ripples expand outward from the center. To find palindromes, do the same: stand at each character (or between two characters), and expand outward as long as the characters on both sides match. The longest expansion you find anywhere is the longest palindromic substring.
② The Insight
A palindrome expands from a center. There are 2n-1 possible centers: n odd-length centers (each character) and n-1 even-length centers (between each pair of adjacent characters). Expand from each center, record the longest.
③ Step-by-Step Logic
  1. For each center i from 0 to n-1: expand odd (lo=hi=i) and even (lo=i, hi=i+1).
  2. Expand while lo ≥ 0 && hi < n && s[lo] == s[hi]: lo--, hi++.
  3. After expansion: palindrome was s[lo+1..hi-1], length = hi-lo-1.
  4. Track best start and length across all centers.
Diagram
"babad": center i=0 'b': expand odd → just 'b', len=1 center i=1 'a': expand odd → 'bab', lo=0,hi=2, len=3 center i=2 'b': expand odd → 'aba', lo=1,hi=3, len=3 center i=3 'a': expand odd → just 'a', len=1 max = "bab" or "aba" (both len=3) ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Returns length of palindrome centered at (lo, hi) */
static int expand(const char *s, int lo, int hi, int n) {
    while (lo >= 0 && hi < n && s[lo] == s[hi]) {
        lo--; hi++;
    }
    return hi - lo - 1;   /* length after over-expansion */
}

void longest_palindrome(const char *s, char *out) {
    int n = (int)strlen(s), best_start = 0, best_len = 1;
    for (int i = 0; i < n; i++) {
        int odd  = expand(s, i, i,   n);   /* odd-length center */
        int even = expand(s, i, i+1, n);   /* even-length center */
        int best = odd > even ? odd : even;
        if (best > best_len) {
            best_len = best;
            best_start = i - (best - 1) / 2;   /* back-calculate start */
        }
    }
    strncpy(out, s + best_start, best_len);
    out[best_len] = '\0';
}

int main(void) {
    char out[100];
    longest_palindrome("babad", out);   printf("%s\n", out); /* bab */
    longest_palindrome("cbbd",  out);   printf("%s\n", out); /* bb */
    return 0;
}

⚠ Gotcha: Even-length center starts at (i, i+1)

Don't forget to check even-length palindromes. "abba" has its center between two 'b's — an odd-center expansion starting at a single character will never find it. Always check both expand(i,i) and expand(i, i+1) at each position.

Pattern 23 Longest Palindromic Substring — DP Table
① Story First
Instead of re-discovering palindromes from scratch at every center, remember past results. If you know "aba" is a palindrome, then "xabax" is a palindrome if the outer characters match — no need to re-check the inner string. A 2D boolean table records which substrings are palindromes.
② The Insight
dp[i][j] = 1 if s[i..j] is a palindrome. Base cases: single chars (all true), adjacent equal chars (true). Recurrence: dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1]. Fill in order of increasing substring length.
③ Step-by-Step Logic
  1. Initialize: all dp[i][i]=1 (length-1 palindromes).
  2. For length 2: dp[i][i+1] = (s[i]==s[i+1]).
  3. For length 3 to n: dp[i][j] = (s[i]==s[j]) && dp[i+1][j-1].
  4. Track best (i,j) where dp[i][j]==1 and j-i is maximum.
Diagram
"babad" (n=5), dp table (1=palindrome): b a b a d b [[ 1 0 1 0 0 ] a [ 0 1 0 1 0 ] b [ 0 0 1 0 0 ] a [ 0 0 0 1 0 ] d [ 0 0 0 0 1 ]] longest: dp[0][2]=1 → "bab", len=3 ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

#define MAXN 1001

void longest_palindrome_dp(const char *s, char *out) {
    int n = (int)strlen(s);
    int dp[MAXN][MAXN] = {0};
    int best_start = 0, best_len = 1;

    /* Base: every single character is a palindrome */
    for (int i = 0; i < n; i++) dp[i][i] = 1;

    /* Base: length-2 substrings */
    for (int i = 0; i < n-1; i++) {
        if (s[i] == s[i+1]) {
            dp[i][i+1] = 1;
            if (best_len < 2) { best_start = i; best_len = 2; }
        }
    }

    /* Fill for length 3 to n */
    for (int len = 3; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            if (s[i] == s[j] && dp[i+1][j-1]) {
                dp[i][j] = 1;
                if (len > best_len) { best_start = i; best_len = len; }
            }
        }
    }

    strncpy(out, s + best_start, best_len);
    out[best_len] = '\0';
}

int main(void) {
    char out[100];
    longest_palindrome_dp("babad", out); printf("%s\n", out); /* bab */
    longest_palindrome_dp("cbbd",  out); printf("%s\n", out); /* bb */
    return 0;
}

The DP table is O(n²) time AND space. For large strings (n=1000+), this is 1M entries. The expand-around-center approach (Pattern 22) gives the same O(n²) time with O(1) space. Use DP when you need to reuse the palindrome membership table for other subproblems.

Pattern 24 Palindrome Partitioning Check
① Story First
You want to cut a string into pieces so that every piece is a palindrome. The minimum number of cuts needed is what you're after. This builds on knowing which substrings are palindromes (from the DP table) and then doing a second DP pass for the minimum cuts.
② The Insight
Two-phase DP. Phase 1: build is_pal[i][j] table. Phase 2: cuts[i] = min cuts for s[0..i]. If s[0..i] is already a palindrome, cuts[i]=0. Otherwise, try all last palindrome pieces: cuts[i] = min(cuts[j-1] + 1) for all j where is_pal[j][i] is true.
③ Step-by-Step Logic
  1. Build is_pal[n][n] as in Pattern 23.
  2. cuts[i] = 0 if is_pal[0][i]. Otherwise cuts[i] = i (worst case: cut every char).
  3. For j from 1 to i: if is_pal[j][i], cuts[i] = min(cuts[i], cuts[j-1]+1).
  4. Return cuts[n-1].

#include <stdio.h>
#include <string.h>

#define MAXN 201

int min_cut(const char *s) {
    int n = (int)strlen(s);
    int is_pal[MAXN][MAXN] = {0};

    /* Phase 1: build palindrome table */
    for (int i = 0; i < n; i++) is_pal[i][i] = 1;
    for (int i = 0; i < n-1; i++) is_pal[i][i+1] = (s[i]==s[i+1]);
    for (int len = 3; len <= n; len++)
        for (int i = 0; i <= n-len; i++) {
            int j = i+len-1;
            is_pal[i][j] = (s[i]==s[j]) && is_pal[i+1][j-1];
        }

    /* Phase 2: min cuts DP */
    int cuts[MAXN];
    for (int i = 0; i < n; i++) {
        if (is_pal[0][i]) { cuts[i] = 0; continue; }
        cuts[i] = i;   /* max = i cuts (one per char) */
        for (int j = 1; j <= i; j++)
            if (is_pal[j][i] && cuts[j-1]+1 < cuts[i])
                cuts[i] = cuts[j-1] + 1;
    }
    return cuts[n-1];
}

    printf("%d\n", min_cut("aaabaa"));   /* 1 */
    return 0;
}

#include <stdio.h>
#include <string.h>

static void rev_range(char *s, int lo, int hi) {
    while (lo < hi) {
        char tmp = s[lo]; s[lo] = s[hi]; s[hi] = tmp;
        lo++; hi--;
    }
}

void reverse_words(char *s) {
    int n = (int)strlen(s);
    rev_range(s, 0, n-1);   /* step 1: reverse entire string */

    int start = 0;
    for (int i = 0; i <= n; i++) {
        if (s[i] == ' ' || s[i] == '\0') {   /* word boundary */
            rev_range(s, start, i-1);          /* step 2: reverse word */
            start = i + 1;
        }
    }
}

    reverse_words(s);

Pattern 26 Valid Parentheses with String
① Story First

  2. Open bracket → push onto stack.
  3. Close bracket → if stack empty or top doesn't match: invalid.
  4. Pop the matching open bracket. After loop: valid iff stack is empty.

#include <string.h>

int is_valid_parens(const char *s) {
    char stack[10001];
    int top = 0;   /* stack pointer (empty when top==0) */

    for (; *s; s++) {
        if (*s == '(' || *s == '[' || *s == '{') {
            stack[top++] = *s;   /* push open bracket */

            if (top == 0) return 0;   /* close with empty stack */

            if (*s == ']' && open != '[') return 0;
            if (*s == '}' && open != '{') return 0;
        }
    }
    return top == 0;   /* valid only if stack is empty at end */
}

}

Pattern 27 Remove K Digits — Monotonic Stack
① Story First
You're building the smallest possible number by removing exactly k digits from a sequence. Greedy rule: whenever a digit is larger than the next one, remove it — because keeping a smaller leading digit always makes the number smaller. A monotonic stack tracks the kept digits in increasing order.
② The Insight
Maintain a stack of kept digits in non-decreasing order. For each digit, pop larger digits from the top while k > 0. After processing all digits, if k > 0, pop the last k digits (they're largest). Strip leading zeros, return the result.
③ Step-by-Step Logic
  1. Iterate through digits; for each digit d while stack top > d and k > 0: pop, k--.
  2. Push d. After loop: if k > 0, truncate stack by k from the top.
  3. Strip leading zeros. If empty, return "0".

#include <stdio.h>
#include <string.h>

void remove_k_digits(const char *num, int k, char *out) {
    int n = (int)strlen(num);
    char stack[n + 1];
    int top = 0;

    for (int i = 0; i < n; i++) {
        /* Pop larger digits while we still have removals left */
        while (top > 0 && k > 0 && stack[top-1] > num[i]) {
            top--; k--;
        }
        stack[top++] = num[i];
    }
    top -= k;   /* if k removals remain, remove from the end (largest left) */

    /* Strip leading zeros */
    int start = 0;
    while (start < top - 1 && stack[start] == '0') start++;
    if (top == 0) { out[0]='0'; out[1]='\0'; return; }
    strncpy(out, stack + start, top - start);
    out[top - start] = '\0';
}

    char out[50];
    remove_k_digits("1432219", 3, out); printf("%s\n", out); /* "1219" */
    remove_k_digits("10200",   1, out); printf("%s\n", out); /* "200"  */
    remove_k_digits("10",      2, out); printf("%s\n", out); /* "0"    */
    return 0;
}

Pattern 28 String Compression — Run-Length Encoding
① Story First
Instead of writing "aaaabbbcc", write "a4b3c2" — group consecutive identical characters and write the character followed by its count. If any group has count 1, just write the character. The compressed form is shorter only when there are long runs.
② The Insight
Walk the string with a read pointer, counting consecutive identical characters. When the character changes (or end is reached), write the character and count to the output. For in-place compression, use a separate write index that only moves forward.
③ Step-by-Step Logic
  1. Start with read=0, write=0.
  2. While read < n: record current char, count its consecutive run.
  3. Write char to s[write++]. If count > 1, write each digit of count.
  4. Return write (new length).
Diagram
"aaabbc": run 'a', count=3 → write 'a','3' run 'b', count=2 → write 'b','2' run 'c', count=1 → write 'c' (no count for 1) result: "a3b2c" (len=5, was 6)
④ Annotated Code
#include <stdio.h>

/* In-place compression; returns new length */
int compress(char *s, int n) {
    int read = 0, write = 0;
    while (read < n) {
        char cur = s[read];
        int count = 0;
        /* Count the run */
        while (read < n && s[read] == cur) { read++; count++; }
        s[write++] = cur;   /* write the character */
        if (count > 1) {
            /* Write count as digits (multi-digit counts possible) */
            char tmp[12];
            int d = 0;
            int c = count;
            while (c > 0) { tmp[d++] = '0' + (c % 10); c /= 10; }
            /* tmp holds digits in reverse; write forward */
            for (int i = d-1; i >= 0; i--) s[write++] = tmp[i];
        }
    }
    s[write] = '\0';
    return write;
}

int main(void) {
    char s[] = "aaabbc";
    int len = compress(s, 6);
    printf("%s (len=%d)\n", s, len);   /* "a3b2c" len=5 */

    char t[] = "aabbccc";
    len = compress(t, 7);
    printf("%s (len=%d)\n", t, len);   /* "a2b2c3" len=6 */
    return 0;
}
⑤ Dry Run
"aabbccc", n=7: read=0: cur='a', count=2 (read→2), write 'a','2' → write=2 read=2: cur='b', count=2 (read→4), write 'b','2' → write=4 read=4: cur='c', count=3 (read→7), write 'c','3' → write=6 s="a2b2c3\0", len=6 ✓

Pattern 29 Zigzag Conversion
① Story First
Write "PAYPALISHIRING" in a zigzag across 3 rows, then read row by row. The characters bounce down and then back up like a sine wave. Instead of actually allocating a 2D grid, you figure out which row each character belongs to, group them, and concatenate.
② The Insight
Simulate the zigzag direction: a row counter starts at 0, goes down to numRows-1, then reverses back up. Each character goes into its current row's bucket. At the end, concatenate all row buckets.
③ Step-by-Step Logic
  1. Create numRows string buffers. Track current row and direction (+1 down, -1 up).
  2. Append each character to rows[cur_row].
  3. Flip direction when cur_row == 0 or cur_row == numRows-1.
  4. Concatenate all rows into output.
Diagram
"PAYPALISHIRING", numRows=3: Row 0: P A H N → "PAHN" Row 1: A P L S I I G → "APLSIIG" Row 2: Y I R → "YIR" Output: "PAHNAPLSIIGYIR" ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

void zigzag(const char *s, int num_rows, char *out) {
    if (num_rows == 1) { strcpy(out, s); return; }

    int n = (int)strlen(s);
    char rows[num_rows][n+1];
    int lens[num_rows];
    for (int i = 0; i < num_rows; i++) { rows[i][0]='\0'; lens[i]=0; }

    int cur = 0, dir = 1;   /* start at row 0, going down */
    for (int i = 0; i < n; i++) {
        rows[cur][lens[cur]++] = s[i];   /* append to current row */
        if (cur == 0)            dir = 1;   /* hit top, go down */
        if (cur == num_rows-1)   dir = -1;  /* hit bottom, go up */
        cur += dir;
    }

    int pos = 0;
    for (int r = 0; r < num_rows; r++) {
        memcpy(out + pos, rows[r], lens[r]);
        pos += lens[r];
    }
    out[pos] = '\0';
}

int main(void) {
    char out[100];
    zigzag("PAYPALISHIRING", 3, out);
    printf("%s\n", out);   /* "PAHNAPLSIIGYIR" */

    zigzag("PAYPALISHIRING", 4, out);
    printf("%s\n", out);   /* "PINALSIGYAHRPI" */
    return 0;
}
⑤ Dry Run
"AB", num_rows=2: i=0:'A', cur=0, dir=1 → rows[0]="A"; cur==0→dir=1, cur+=1=1 i=1:'B', cur=1, dir=-1 → rows[1]="B"; cur==1(num_rows-1)→dir=-1, cur+=(-1)=0 concat: "A"+"B" = "AB" ✓ (no change for 2-row, 2-char input)
⚠ Gotcha: Direction flip at boundary, not after

Flip direction when you arrive at row 0 or numRows-1 (before the next move), not when you leave it. Otherwise the character at the boundary row goes to the correct row but the next character goes in the wrong direction for one step.

Pattern 30 String Parsing — Roman to Integer
① Story First
Roman numerals mostly add from left to right: III = 3, VIII = 8. The exception: when a smaller numeral appears before a larger one, it subtracts — IV = 4 (5-1), IX = 9 (10-1). Walk right to left: if current value < previous value, subtract it; otherwise add it.
② The Insight
Walking right-to-left simplifies the subtraction rule: at each position, compare current value to the maximum seen so far (from the right). If current is less, subtract it; otherwise add it and update the max. This avoids looking ahead.
③ Step-by-Step Logic
  1. Map each roman character to its value.
  2. Walk right to left; track prev value.
  3. If val[s[i]] < prev: subtract; else add and update prev.
  4. Return accumulated result.

#include <string.h>

static int roman_val(char c) {
    switch (c) {
        case 'I': return 1;   case 'V': return 5;
        case 'X': return 10;  case 'L': return 50;
        case 'C': return 100; case 'D': return 500;
        case 'M': return 1000;
    }
    return 0;
}

int roman_to_int(const char *s) {

    for (int i = (int)strlen(s)-1; i >= 0; i--) {
        int val = roman_val(s[i]);
        if (val < prev)
            result -= val;   /* subtraction rule: smaller before larger */
        else {
            result += val;
            prev = val;
        }
    }
    return result;
}

    return 0;
}

Pattern 31 KMP — Failure Function (LPS Array)
① Story First
You're searching for "abcabc" in a long text. After a mismatch at position 5, the naive approach restarts from scratch. But "abcabc" has a prefix "abc" that also appears as a suffix inside itself — so you already know those first 3 characters matched, and can restart from position 3, not 0. The failure function tells you exactly how far to jump back.
② The Insight
The LPS (Longest Proper Prefix which is also Suffix) array for the pattern tells us: at position i, if a mismatch occurs, we can skip back to lps[i-1] instead of 0. This avoids re-comparing characters we already know matched. Building this array is O(m).
③ Step-by-Step Logic
  1. lps[0] = 0 always. Set len=0, i=1.
  2. If pattern[i] == pattern[len]: lps[i] = ++len; i++.
  3. Else if len > 0: len = lps[len-1] (fall back, don't increment i).
  4. Else: lps[i] = 0; i++.
Diagram
pattern = "abcabc" i: 0 1 2 3 4 5 pat: a b c a b c lps: 0 0 0 1 2 3 lps[3]=1: "a" is longest proper prefix-suffix of "abca" lps[5]=3: "abc" is longest proper prefix-suffix of "abcabc"
④ Annotated Code
#include <stdio.h>
#include <string.h>

void build_lps(const char *pat, int m, int *lps) {
    lps[0] = 0;           /* always 0 for first character */
    int len = 0, i = 1;
    while (i < m) {
        if (pat[i] == pat[len]) {
            lps[i++] = ++len;          /* extend current prefix-suffix */
        } else if (len > 0) {
            len = lps[len-1];          /* fall back (don't advance i!) */
        } else {
            lps[i++] = 0;             /* no prefix-suffix, reset */
        }
    }
}

int main(void) {
    const char *p = "abcabc";
    int m = (int)strlen(p);
    int lps[m];
    build_lps(p, m, lps);
    for (int i = 0; i < m; i++) printf("%d ", lps[i]);
    printf("\n");   /* 0 0 0 1 2 3 */

    const char *p2 = "aabaabaaa";
    int m2 = (int)strlen(p2);

    for (int i = 0; i < m2; i++) printf("%d ", lps2[i]);
    printf("\n");   /* 0 1 0 1 2 3 4 5 2 */
    return 0;
}

Pattern 32 KMP — Pattern Search
① Story First
Armed with the failure function (Pattern 31), the search itself is elegant: walk the text with pointer j; walk the pattern with pointer k. On match, advance both. On mismatch, fall back using lps — but never retreat j. Each character of the text is visited at most once.
② The Insight
KMP is O(n+m) because j (text pointer) never goes backwards. When a mismatch occurs at pattern position k, you reset k = lps[k-1] — effectively sliding the pattern right so the already-matched prefix aligns again. Text pointer j stays put.
③ Step-by-Step Logic
  1. Build lps[] for pattern. Set j=0 (text), k=0 (pattern).

  4. Else if k > 0: k = lps[k-1] (fall back pattern, keep j).
  5. Else: j++ (no prefix to fall back to).

Pattern 33 Rabin-Karp Rolling Hash
① Story First
Instead of comparing characters one by one, compute a "fingerprint" (hash) of the pattern and each same-length window of the text. Only when hashes match do you verify character-by-character. The clever part: updating the hash when the window slides is O(1) — just remove the leftmost character and add the new rightmost one.
② The Insight
Rolling hash: h = (h * base + s[i]) % mod going right; remove a character: h = (h - s[left] * base^(m-1)) % mod. With a good base and mod, hash collisions are rare — most mismatches are caught by the O(1) hash compare, making average-case O(n+m).
③ Step-by-Step Logic
  1. Compute pattern hash and initial window hash of length m.
  2. Slide: new_hash = (old_hash - s[left]*h_pow) * base + s[right], mod prime.
  3. On hash match: verify character-by-character (handles collisions).
  4. Repeat until end of text.
Diagram
base=31, mod=1e9+7, pat="abc" (m=3) pat_hash = 'a'*31² + 'b'*31 + 'c' window "abc" in text → hash matches → verify → MATCH slide right: remove 'a'*31², add 'd' → new hash in O(1) window "bcd" → hash differs → skip verification
④ Annotated Code
#include <stdio.h>
#include <string.h>

#define BASE 31L
#define MOD  1000000007L

void rabin_karp(const char *text, const char *pat) {
    int n = (int)strlen(text), m = (int)strlen(pat);
    if (m > n) return;

    /* Precompute BASE^(m-1) % MOD */
    long h_pow = 1;
    for (int i = 0; i < m-1; i++) h_pow = h_pow * BASE % MOD;

    /* Compute pattern hash and first window hash */
    long pat_h = 0, win_h = 0;
    for (int i = 0; i < m; i++) {
        pat_h = (pat_h * BASE + pat[i])  % MOD;
        win_h = (win_h * BASE + text[i]) % MOD;
    }

    for (int i = 0; i <= n - m; i++) {
        if (win_h == pat_h) {
            /* Hash match — verify to rule out collision */
            if (strncmp(text + i, pat, m) == 0)
                printf("Found at %d\n", i);
        }
        if (i < n - m) {
            /* Roll hash: remove leftmost char, add next char */
            win_h = (win_h - (long)text[i] * h_pow % MOD + MOD) % MOD;
            win_h = (win_h * BASE + text[i+m]) % MOD;
        }
    }
}

    rabin_karp("GEEKS FOR GEEKS", "GEEKS");   /* 0, 10 */
    rabin_karp("hello world", "world");        /* 6 */
    return 0;
}

Pattern 34 Edit Distance — Levenshtein
① Story First
"kitten" → "sitting": how many single-character operations (insert, delete, replace) does it take? Think of building the answer for smaller subproblems first: if you know the edit distance for "kitt" → "sitt", you can extend to "kitten" → "sitting" by looking at the last characters and picking the cheapest operation.
② The Insight
dp[i][j] = edit distance between s1[0..i-1] and s2[0..j-1]. If last chars match: dp[i][j] = dp[i-1][j-1]. Else: dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) — delete, insert, replace.
③ Step-by-Step Logic
  1. dp[0][j] = j (insert j chars), dp[i][0] = i (delete i chars).
  2. For each (i,j): if s1[i-1]==s2[j-1]: dp[i][j] = dp[i-1][j-1].
  3. Else: dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]).
  4. Return dp[m][n].
Diagram
"horse" → "ros" (edit dist=3): "" r o s "" 0 1 2 3 h 1 1 2 3 o 2 2 1 2 r 3 2 2 2 s 4 3 3 2 e 5 4 4 3 ← dp[5][3] = 3 ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

#define MIN3(a,b,c) ((a)<(b)?((a)<(c)?(a):(c)):((b)<(c)?(b):(c)))

int edit_distance(const char *s1, const char *s2) {
    int m = (int)strlen(s1), n = (int)strlen(s2);
    int dp[m+1][n+1];

    for (int i = 0; i <= m; i++) dp[i][0] = i;   /* delete all of s1 */
    for (int j = 0; j <= n; j++) dp[0][j] = j;   /* insert all of s2 */

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1]) {
                dp[i][j] = dp[i-1][j-1];   /* last chars match — free */
            } else {
                dp[i][j] = 1 + MIN3(
                    dp[i-1][j-1],  /* replace */
                    dp[i-1][j],    /* delete from s1 */
                    dp[i][j-1]     /* insert into s1 */
                );
            }
        }
    }
    return dp[m][n];
}

int main(void) {
    printf("%d\n", edit_distance("horse",  "ros"));      /* 3 */
    printf("%d\n", edit_distance("intention", "execution")); /* 5 */
    printf("%d\n", edit_distance("",       "abc"));      /* 3 */
    return 0;
}

Pattern 35 Longest Common Subsequence
① Story First
"ABCBDAB" and "BDCAB" share a common subsequence "BCAB" of length 4. A subsequence doesn't need to be contiguous — you just pick characters in order from both strings. The longest such sequence is the LCS.
② The Insight
dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]. If last chars match: dp[i][j] = dp[i-1][j-1] + 1. Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) — take the better of skipping one char from either string.
③ Step-by-Step Logic
  1. dp[0][j] = dp[i][0] = 0 (empty string has LCS 0 with anything).
  2. For each (i,j): if s1[i-1]==s2[j-1]: dp[i][j] = dp[i-1][j-1]+1.
  3. Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).
  4. Return dp[m][n].
Diagram
"ABCD" vs "ACBD": "" A C B D "" [ 0 0 0 0 0 ] A [ 0 1 1 1 1 ] B [ 0 1 1 2 2 ] C [ 0 1 2 2 2 ] D [ 0 1 2 2 3 ] LCS = 3 ("ABD" or "ACD") ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

int lcs(const char *s1, const char *s2) {
    int m = (int)strlen(s1), n = (int)strlen(s2);
    int dp[m+1][n+1];
    for (int i = 0; i <= m; i++) dp[i][0] = 0;
    for (int j = 0; j <= n; j++) dp[0][j] = 0;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;   /* chars match — extend */
            else
                dp[i][j] = dp[i-1][j] > dp[i][j-1]
                            ? dp[i-1][j] : dp[i][j-1];  /* take best skip */
        }
    }
    return dp[m][n];
}

    return 0;
}

Pattern 36 Longest Common Substring
① Story First
Unlike a subsequence (which can have gaps), a substring must be contiguous. "ABCDEF" and "XBCDEY" share the substring "BCDE" of length 4. The moment a character doesn't match, the current run is broken — reset to zero. Track the maximum run seen at any point.
② The Insight
dp[i][j] = length of longest common substring ending at s1[i-1] and s2[j-1]. Match: dp[i][j] = dp[i-1][j-1]+1. No match: dp[i][j] = 0. Track max over all (i,j).
③ Step-by-Step Logic
  1. dp all zeros (both borders and mismatch positions).
  2. For each (i,j): if s1[i-1]==s2[j-1]: dp[i][j] = dp[i-1][j-1]+1; update max.
  3. Else: dp[i][j] = 0 (contiguous run broken).
  4. Return max.
Diagram
"ABCDEF" vs "XBCDEY": X B C D E Y A [ 0 0 0 0 0 0 ] B [ 0 1 0 0 0 0 ] C [ 0 0 2 0 0 0 ] D [ 0 0 0 3 0 0 ] E [ 0 0 0 0 4 0 ] F [ 0 0 0 0 0 0 ] max = 4 → "BCDE" ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

int longest_common_substring(const char *s1, const char *s2) {
    int m = (int)strlen(s1), n = (int)strlen(s2);
    int dp[m+1][n+1];
    int max_len = 0;

    for (int i = 0; i <= m; i++)
        for (int j = 0; j <= n; j++)
            dp[i][j] = 0;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1]) {
                dp[i][j] = dp[i-1][j-1] + 1;    /* extend matching run */
                if (dp[i][j] > max_len) max_len = dp[i][j];
            }
            /* else dp[i][j] stays 0 — run is broken */
        }
    }
    return max_len;
}

int main(void) {
    printf("%d\n", longest_common_substring("ABCDEF", "XBCDEY"));  /* 4 */
    printf("%d\n", longest_common_substring("ABAB",   "BABA"));    /* 3 */
    printf("%d\n", longest_common_substring("abc",    "xyz"));     /* 0 */
    return 0;
}

⚠ Gotcha: Reset to 0 on mismatch — not max(left, up)

The key difference from LCS: on mismatch, dp[i][j] = 0, not max(dp[i-1][j], dp[i][j-1]). The substring must be contiguous — a mismatch breaks the chain completely. Using max(left,up) gives LCS, not the longest common substring.

Pattern 37 Word Break — DP
① Story First
"leetcode" can be split into "leet" + "code" — both in the dictionary. Can a given string be segmented into dictionary words? Think of it as placing "cuts" in the string: if position i is reachable (some prefix up to i is all valid words) and s[i..j] is a word, then j is also reachable.
② The Insight
dp[i] = true if s[0..i-1] can be segmented into dictionary words. Base: dp[0]=true. For each i: check all j < i where dp[j]=true and s[j..i-1] is in the dictionary.
③ Step-by-Step Logic
  1. dp[0] = true (empty string). dp[1..n] = false initially.
  2. For i from 1 to n: for j from 0 to i-1: if dp[j] and s[j..i-1] in dict: dp[i]=true.
  3. Return dp[n].

#include <stdio.h>
#include <string.h>

/* Simple dict lookup: check if word matches any entry */
static int in_dict(const char *s, int start, int end,
                   const char **dict, int dict_size) {
    int len = end - start;
    for (int i = 0; i < dict_size; i++) {
        if ((int)strlen(dict[i]) == len &&
            strncmp(s + start, dict[i], len) == 0)
            return 1;
    }
    return 0;
}

int word_break(const char *s, const char **dict, int dict_size) {
    int n = (int)strlen(s);
    int dp[n+1];
    for (int i = 0; i <= n; i++) dp[i] = 0;
    dp[0] = 1;   /* empty prefix is always "breakable" */

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            if (dp[j] && in_dict(s, j, i, dict, dict_size)) {
                dp[i] = 1;
                break;   /* found one valid split — no need to check more */
            }
        }
    }
    return dp[n];
}

int main(void) {
    const char *d1[] = {"leet", "code"};
    printf("%d\n", word_break("leetcode", d1, 2));    /* 1 */

    const char *d2[] = {"apple", "pen"};
    printf("%d\n", word_break("applepenapple", d2, 2)); /* 1 */

    const char *d3[] = {"cats", "dog", "sand", "and", "cat"};
    printf("%d\n", word_break("catsandog", d3, 5));   /* 0 */
    return 0;
}

Pattern 38 Distinct Subsequences
① Story First
How many ways can you choose characters from "rabbbit" to spell "rabbit"? Each time you pick a character that matches the next letter of the target, you're making a choice. Choices multiply: if there are three 'b's in the source and two in the target, there are multiple picking orders. DP counts all of them.
② The Insight
dp[i][j] = number of ways s[0..i-1] contains t[0..j-1] as a subsequence. If s[i-1]==t[j-1]: take the char OR skip it — dp[i][j] = dp[i-1][j-1] + dp[i-1][j]. If not equal: only skip — dp[i][j] = dp[i-1][j].
③ Step-by-Step Logic
  1. dp[i][0] = 1 (empty t is always a subsequence of any prefix of s).
  2. dp[0][j] = 0 for j>0 (non-empty t cannot come from empty s).
  3. Fill: match → dp[i-1][j-1]+dp[i-1][j]; no match → dp[i-1][j].
  4. Return dp[m][n].
Diagram
"rabbbit" → "rabbit" (3 b's vs 2 b's): At the three 'b' positions: each one can be skipped or used. dp counts all valid picking orders → 3 ways ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

long num_distinct(const char *s, const char *t) {
    int m = (int)strlen(s), n = (int)strlen(t);
    long dp[m+1][n+1];

    for (int i = 0; i <= m; i++) dp[i][0] = 1;   /* empty t: 1 way */
    for (int j = 1; j <= n; j++) dp[0][j] = 0;   /* empty s, non-empty t: 0 ways */

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            dp[i][j] = dp[i-1][j];              /* always: skip s[i-1] */
            if (s[i-1] == t[j-1])
                dp[i][j] += dp[i-1][j-1];       /* also: use s[i-1] to match t[j-1] */
        }
    }
    return dp[m][n];
}

    printf("%ld\n", num_distinct("rabbbit", "rabbit"));  /* 3 */
    printf("%ld\n", num_distinct("babgbag", "bag"));     /* 5 */
    printf("%ld\n", num_distinct("abc",     "abc"));     /* 1 */
    return 0;
}

Pattern 39 Wildcard Matching — ? and *
① Story First
A shell glob pattern like "a*b?c" matches strings that start with 'a', end with any char then 'c', with anything in between. '?' matches exactly one character; '*' matches any sequence (including empty). The DP tracks which positions of both the string and pattern are simultaneously reachable.
② The Insight
dp[i][j] = true if pattern[0..j-1] matches string[0..i-1]. '?' acts like a concrete char — dp[i][j] = dp[i-1][j-1]. '*' can match empty (dp[i][j] = dp[i][j-1]) or one more char (dp[i][j] = dp[i-1][j]).
③ Step-by-Step Logic
  1. dp[0][0]=true; dp[0][j]=true only if pattern[0..j-1] is all '*'.
  2. For each (i,j): if p[j-1]=='*': dp[i][j] = dp[i][j-1] || dp[i-1][j].
  3. Elif p[j-1]=='?' or p[j-1]==s[i-1]: dp[i][j] = dp[i-1][j-1].
  4. Else: dp[i][j] = false.
Diagram

#include <string.h>

int wildcard_match(const char *s, const char *p) {

    for (int i = 0; i <= m; i++)
        for (int j = 0; j <= n; j++) dp[i][j] = 0;

        dp[0][j] = dp[0][j-1] && p[j-1] == '*';

        for (int j = 1; j <= n; j++) {

                /* match empty (dp[i][j-1]) OR match one more char (dp[i-1][j]) */

                dp[i][j] = dp[i-1][j-1];  /* '?' or exact char match */
            }
        }
    }
    return dp[m][n];
}

Pattern 40 Regular Expression Matching — . and *
① Story First
Unlike shell wildcards, regex '*' means "zero or more of the preceding element". "a*" matches "", "a", "aa", etc. ".*" matches anything. "c*a*b" matches "aab" because c* matches empty and a* matches "aa". The '*' always refers back to the character before it — making this trickier than wildcard matching.
② The Insight
When p[j-1]=='*', it pairs with p[j-2]. Two cases: (1) use zero occurrences — dp[i][j] = dp[i][j-2]; (2) use one more — dp[i][j] = dp[i-1][j] if p[j-2] matches s[i-1] (either same char or '.').
③ Step-by-Step Logic
  1. dp[0][0]=true; dp[0][j]=true if p[0..j-1] can match empty string (pairs like "a*b*").
  2. For each (i,j): if p[j-1]='*': zero-use → dp[i][j-2]; or one-more if p[j-2] matches s[i-1].
  3. Elif p[j-1]='.' or p[j-1]==s[i-1]: dp[i][j] = dp[i-1][j-1].
  4. Return dp[m][n].

#include <string.h>

static int matches(char sc, char pc) {
    return pc == '.' || pc == sc;   /* '.' matches any char */
}

int regex_match(const char *s, const char *p) {
    int m = (int)strlen(s), n = (int)strlen(p);
    int dp[m+1][n+1];
    for (int i = 0; i <= m; i++)
        for (int j = 0; j <= n; j++) dp[i][j] = 0;

    dp[0][0] = 1;
    /* "a*b*c*" can match empty string */
    for (int j = 2; j <= n; j++)
        if (p[j-1] == '*') dp[0][j] = dp[0][j-2];

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (p[j-1] == '*') {
                dp[i][j] = dp[i][j-2];    /* zero occurrences of p[j-2] */

            } else if (matches(s[i-1], p[j-1])) {
                dp[i][j] = dp[i-1][j-1];
            }
        }
    }
    return dp[m][n];
}

⚠ Gotcha: Regex * is not the same as wildcard *

In wildcard matching (P39), '*' stands alone and matches any sequence. In regex, '*' modifies the preceding char — "a*" is one unit meaning "zero or more a's". The DP structure is different: regex '*' always looks back two positions in the pattern (p[j-2]), wildcard '*' looks at only the current pattern position.
