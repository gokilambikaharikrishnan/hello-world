Pattern 01 Null Terminator and strlen
① Story First
In C, a string isn't a special type — it's just an array of characters with a contract: the last character is always '\0' (ASCII value 0). Everything from reading to copying to printing stops when it hits that sentinel. strlen just counts characters until it finds the '\0' — that's the whole secret.
② The Insight
The null terminator is the only thing that separates a C string from raw bytes. Remove it (or forget it during manual construction) and every string function will read past the end of your buffer until it finds some zero byte in memory — which could be kilobytes away.
③ Step-by-Step Logic
  1. String literal "hello" stores 6 bytes: h e l l o \0.
  2. strlen walks from index 0 until it finds '\0', returns the count.
  3. Buffer must be at least strlen + 1 bytes to hold the string + terminator.
  4. Manual string construction must explicitly place '\0' at the end.
Diagram
"hello" in memory: index: 0 1 2 3 4 5 char: 'h' 'e' 'l' 'l' 'o' '\0' hex: 68 65 6C 6C 6F 00 strlen("hello") → walks 0,1,2,3,4 → hits '\0' at 5 → returns 5 sizeof("hello") → 6 (includes '\0')
④ Annotated Code
#include <stdio.h>
#include <string.h>   /* for strlen */

/* Manual strlen — returns length without counting '\0' */
size_t my_strlen(const char *s) {
    size_t len = 0;
    while (s[len] != '\0')   /* walk until null terminator */
        len++;
    return len;              /* does not include '\0' */
}

int main(void) {
    char s[] = "hello";           /* 6 bytes: h e l l o \0 */
    printf("strlen=%zu\n", strlen(s));      /* 5 */
    printf("my_strlen=%zu\n", my_strlen(s));/* 5 */
    printf("sizeof=%zu\n", sizeof(s));      /* 6 (includes \0) */

    /* Manual string construction — must place '\0' */
    char buf[6];
    buf[0]='w'; buf[1]='o'; buf[2]='r'; buf[3]='l'; buf[4]='d';
    buf[5] = '\0';             /* WITHOUT this, strlen reads past end! */
    printf("%s len=%zu\n", buf, strlen(buf));   /* world 5 */
    return 0;
}
⑤ Dry Run
my_strlen("hello"): s[0]='h' ≠ '\0' → len=1 s[1]='e' ≠ '\0' → len=2 s[2]='l' ≠ '\0' → len=3 s[3]='l' ≠ '\0' → len=4 s[4]='o' ≠ '\0' → len=5 s[5]='\0' → stop, return 5 ✓
⚠ Gotcha: Buffer must hold strlen+1 bytes

If you declare char buf[5] and copy "hello" into it, there's no room for '\0'. The string appears to work but strlen and printf will read past the end. Always allocate strlen(src) + 1 bytes. Better yet, use strnlen and snprintf in real code.

N/A (C mechanics)Foundation for all string problems
When working with C strings → think: "every string ends in '\0'; buffer needs strlen+1 bytes."
Pattern 02 Manual strcpy and Buffer Safety
① Story First
Copying a string in C is like transcribing a scroll — you copy character by character until you hit the end marker. The classic strcpy does exactly this. The danger: if you don't know how big your destination scroll is, you might write off the edge and overwrite the next scroll (adjacent memory) — a buffer overflow.
② The Insight
strcpy is unsafe because it trusts the destination is big enough. The safe pattern is always to use snprintf(dest, sizeof(dest), "%s", src) or strncpy (with explicit null termination), and always check that the destination buffer is large enough before copying.
③ Step-by-Step Logic
  1. Allocate destination: at least strlen(src) + 1 bytes.
  2. Copy byte by byte until and including the '\0'.
  3. For safe copy: use snprintf which always null-terminates and never overflows.
  4. Verify destination was large enough (check return value of snprintf).
Diagram
src: [h][e][l][l][o][\0] dst: [?][?][?][?][?][?] (need at least 6 bytes) strcpy loop: i=0: dst[0]='h', i=1: dst[1]='e', ... i=5: dst[5]='\0' → stop BUFFER OVERFLOW: src: [h][e][l][l][o][\0] dst: [?][?][?] (only 3 bytes — writes into adjacent memory!)
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Manual strcpy — educational only, use snprintf in real code */
char *my_strcpy(char *dst, const char *src) {
    char *start = dst;           /* save start to return */
    while ((*dst++ = *src++))    /* copy including '\0'; loop ends when '\0' copied */
        ;
    return start;
}

/* Safe copy using snprintf — always null-terminates */
void safe_copy(char *dst, size_t dst_size, const char *src) {
    int written = snprintf(dst, dst_size, "%s", src);
    if (written >= (int)dst_size)
        fprintf(stderr, "Warning: string truncated\n");
}

int main(void) {
    char src[] = "hello world";

    /* Safe: buffer sized correctly */
    char dst1[20];
    safe_copy(dst1, sizeof(dst1), src);
    printf("copied: %s\n", dst1);

    /* Dangerous: small buffer — snprintf truncates, not overflow */
    char dst2[5];
    safe_copy(dst2, sizeof(dst2), src);  /* "hell\0" — truncated, but safe */
    printf("truncated: %s\n", dst2);     /* prints: hell */
    return 0;
}
⑤ Dry Run
my_strcpy(dst, "hi"): *dst++ = 'h' → dst[0]='h', not '\0' → continue *dst++ = 'i' → dst[1]='i', not '\0' → continue *dst++ = '\0' → dst[2]='\0', condition is '\0'=0=false → stop dst = "hi\0" ✓ safe_copy(dst2, 5, "hello world"): snprintf writes min(11, 5-1)=4 chars + '\0' dst2 = "hell\0" written=11 >= 5 → prints truncation warning
⚠ Gotcha: strncpy does NOT always null-terminate

strncpy(dst, src, n) copies at most n chars but if src is n or more chars long, the result is NOT null-terminated. You must manually add dst[n-1] = '\0'. This surprises nearly every C programmer. Prefer snprintf which always null-terminates within the given size.

N/A (C mechanics)
When copying a C string → think: "destination needs strlen+1 bytes; use snprintf for safety."
Pattern 03 Manual strcmp — Lexicographic Comparison
① Story First
A dictionary sorts words by comparing letters one at a time. "apple" comes before "apply" because at position 4, 'e' (101) comes before 'y' (121) in ASCII. strcmp does exactly this: compare character by character; the first mismatch decides the order; if one string runs out first, it's "less than" the longer one.
② The Insight
strcmp returns negative if s1 < s2, 0 if equal, positive if s1 > s2 — based on the first differing byte's ASCII values. Equality requires every character to match AND both strings end at the same position.
③ Step-by-Step Logic
  1. Walk both strings simultaneously while characters are equal and not '\0'.
  2. When the loop ends: return (unsigned char)s1[i] - (unsigned char)s2[i].
  3. If both are '\0' at the same position, the strings are equal (returns 0).
  4. Cast to unsigned char to avoid sign-extension issues with chars > 127.
Diagram
strcmp("apple", "apply"): i=0: 'a'=='a' → continue i=1: 'p'=='p' → continue i=2: 'p'=='p' → continue i=3: 'l'=='l' → continue i=4: 'e' vs 'y' → 101 - 121 = -20 → return negative (s1 < s2) strcmp("cat", "cat"): i=0,1,2: 'c','a','t' all match i=3: '\0' == '\0' → return 0 (equal)
④ Annotated Code
#include <stdio.h>

/* Manual strcmp: negative if s1<s2, 0 if equal, positive if s1>s2 */
int my_strcmp(const char *s1, const char *s2) {
    /* Walk while characters match and neither string has ended */
    while (*s1 && *s1 == *s2) {
        s1++;
        s2++;
    }
    /* Return difference of first differing bytes (or both '\0' → 0) */
    return (unsigned char)*s1 - (unsigned char)*s2;
}

int main(void) {
    printf("%d\n", my_strcmp("apple", "apply"));  /* negative */
    printf("%d\n", my_strcmp("cat",   "cat"));    /* 0 */
    printf("%d\n", my_strcmp("z",     "a"));      /* positive */

    /* Common use: sorting condition */
    const char *words[] = {"banana", "apple", "cherry"};
    /* Use strcmp result in conditions */
    if (my_strcmp(words[0], words[1]) > 0)
        printf("banana comes after apple\n");
    return 0;
}
⑤ Dry Run
my_strcmp("cat", "car"): *s1='c', *s2='c' → equal, advance *s1='a', *s2='a' → equal, advance *s1='t', *s2='r' → not equal, exit loop return (unsigned char)'t' - (unsigned char)'r' = 116-114 = 2 (positive → s1 > s2)
⚠ Gotcha: Don't compare strings with ==

if (s1 == s2) compares pointer addresses, not string content. Two different string literals with the same content have different addresses (usually). Always use strcmp(s1, s2) == 0 for content equality.

When comparing C strings → think: strcmp == 0 for equal; never use == on char pointers.
Pattern 04 String Reversal In-Place
① Story First
To reverse a sentence written on a strip of paper, you swap the first and last letters, then the second and second-to-last, and so on, moving inward until the two ends meet in the middle. Two pointers, one from each end, swapping and converging.
② The Insight
In-place reversal uses two pointers (left at 0, right at len-1) that converge toward the center, swapping characters at each step. Stop when left >= right. This uses O(1) extra space and works in O(n) time.
③ Step-by-Step Logic
  1. Compute length, set lo = 0, hi = len - 1.
  2. While lo < hi: swap s[lo] and s[hi].
  3. Advance lo++, retreat hi--.
  4. Loop ends when pointers cross — string is fully reversed.
Diagram
"hello" → reverse → "olleh" Step 1: [h][e][l][l][o] lo=0, hi=4 → swap h↔o [o][e][l][l][h] lo=1, hi=3 → swap e↔l [o][l][l][e][h] lo=2, hi=2 → lo >= hi, stop Result: "olleh" ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

void reverse_string(char *s) {
    int lo = 0, hi = (int)strlen(s) - 1;
    while (lo < hi) {
        char tmp = s[lo];   /* standard 3-step swap */
        s[lo] = s[hi];
        s[hi] = tmp;
        lo++;
        hi--;
    }
}

int main(void) {
    char s[] = "hello";       /* mutable: stack array */
    reverse_string(s);
    printf("%s\n", s);        /* "olleh" */

    char t[] = "abcde";
    reverse_string(t);
    printf("%s\n", t);        /* "edcba" */
    return 0;
}
⑤ Dry Run
"hello", lo=0, hi=4: swap s[0]='h' ↔ s[4]='o' → "oellh", lo=1, hi=3 swap s[1]='e' ↔ s[3]='l' → "oleh...", lo=2, hi=2 lo >= hi → stop result: "olleh" ✓
⚠ Gotcha: String literals are immutable

char *s = "hello"; points to a string literal in read-only memory. Calling reverse_string(s) causes undefined behavior (usually a segfault). To get a mutable copy, use char s[] = "hello"; which copies the literal onto the stack.

Pattern 05 String Search — strstr Logic
① Story First
Looking for the word "cat" in "the black cat sat" — you scan left to right; whenever you find a 'c', you check if the next two characters are 'a' and 't'. If yes, you found it. If no, you move forward one position and keep scanning. This is naïve string search, and it's what strstr does under the hood.
② The Insight
Naïve string search is O(n×m) but works perfectly for typical inputs. For every position in the haystack, attempt to match the needle character by character. The outer loop advances one step at a time; the inner loop checks the full needle. On first mismatch, break inner and advance outer.
③ Step-by-Step Logic
  1. For each position i in haystack (while room remains for needle).
  2. Try matching needle starting at haystack[i].
  3. If all needle chars match, return &haystack[i].
  4. If any mismatch, advance i by 1 and retry.
  5. Return NULL if no match found.
Diagram
haystack: "the black cat sat" needle: "cat" i=0: 't'≠'c' skip i=1: 'h'≠'c' skip ... i=10: 'c'=='c' → check 'a'=='a' → check 't'=='t' → MATCH at i=10 return &haystack[10] → "cat sat"
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Returns pointer to first occurrence of needle in haystack, or NULL */
const char *my_strstr(const char *haystack, const char *needle) {
    if (!*needle) return haystack;   /* empty needle matches at start */
    size_t nlen = strlen(needle);
    size_t hlen = strlen(haystack);
    if (nlen > hlen) return NULL;    /* needle longer than haystack */

    for (size_t i = 0; i <= hlen - nlen; i++) {
        size_t j = 0;
        while (j < nlen && haystack[i+j] == needle[j])
            j++;                     /* advance while chars match */
        if (j == nlen)
            return &haystack[i];     /* full needle matched here */
    }
    return NULL;
}

int main(void) {
    const char *h = "the black cat sat";
    const char *found = my_strstr(h, "cat");
    if (found)
        printf("Found: \"%s\"\n", found);   /* "cat sat" */
    else
        printf("Not found\n");

    printf("strstr check: %s\n", strstr(h, "cat")); /* same result */
    return 0;
}
⑤ Dry Run
haystack="hello world", needle="world" hlen=11, nlen=5, loop i=0..6: i=0: h≠w → j=0 only i=1: e≠w → j=0 only ... i=6: w==w → j=1: o==o → j=2: r==r → j=3: l==l → j=4: d==d → j=5==nlen → MATCH return &haystack[6] → "world" ✓
⚠ Gotcha: O(n×m) worst case

Naïve search is slow for patterns like needle="aaab" in haystack="aaaa...aab" — it retries nearly every position. For production pattern matching with large inputs, use KMP (Pattern 31-32) which is O(n+m).

Pattern 06 Character Frequency Count
① Story First
A librarian counts how many copies of each book are on the shelf by walking along and making a tally mark for each title. In C, a character frequency array is exactly that tally: a 26-element array (or 256 for all ASCII) where each index represents a character and the value is how many times it appeared.
② The Insight
Characters are just small integers (ASCII 0-127). Use the character as an array index: freq[c - 'a']++ for lowercase letters. This gives O(1) lookup and update, and the whole frequency table is built in O(n) time. It's the core building block for anagram checks, permutation problems, and sliding window frequency tracking.
③ Step-by-Step Logic
  1. Declare int freq[26] = {0} (or freq[128] for all ASCII).
  2. Walk the string: for each char c, do freq[c - 'a']++.
  3. To compare two strings' frequencies: build both tables, compare arrays.
  4. To check if a char appears: freq[c - 'a'] > 0.
Diagram
"banana": b → freq[1]++ a → freq[0]++ n → freq[13]++ a → freq[0]++ n → freq[13]++ a → freq[0]++ freq: a=3, b=1, n=2, rest=0
④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <ctype.h>

void char_frequency(const char *s, int freq[26]) {
    memset(freq, 0, 26 * sizeof(int));   /* zero out */
    for (; *s; s++) {
        if (islower(*s))
            freq[*s - 'a']++;   /* 'a'=0, 'b'=1, ..., 'z'=25 */
    }
}

/* Check if two strings are anagrams */
int is_anagram(const char *a, const char *b) {
    if (strlen(a) != strlen(b)) return 0;   /* must be same length */
    int fa[26], fb[26];
    char_frequency(a, fa);
    char_frequency(b, fb);
    return memcmp(fa, fb, sizeof(fa)) == 0; /* byte-wise comparison */
}

int main(void) {
    int freq[26];
    char_frequency("banana", freq);
    for (int i = 0; i < 26; i++)
        if (freq[i]) printf("%c:%d ", 'a'+i, freq[i]);
    printf("\n");   /* a:3 b:1 n:2 */

    printf("anagram: %d\n", is_anagram("listen", "silent"));  /* 1 */
    printf("anagram: %d\n", is_anagram("hello",  "world"));   /* 0 */
    return 0;
}
⑤ Dry Run
is_anagram("listen", "silent"): freq("listen"): e=1,i=1,l=1,n=1,s=1,t=1 freq("silent"): e=1,i=1,l=1,n=1,s=1,t=1 memcmp → 0 (equal) → return 1 (yes, anagram) ✓
⚠ Gotcha: Only works for lowercase ASCII

freq[c - 'a'] only works if c is guaranteed to be a lowercase letter. For mixed-case or arbitrary ASCII, use freq[(unsigned char)c] with a 128 or 256 element array. Always cast to unsigned char before using a char as an array index.

Pattern 07 Remove Duplicates from String
① Story First
A bouncer at a club only lets each person in once. As you walk the guest list, you check a "seen" book. If the name is new, let them in and record them. If the name is already in the book, skip them. The result is a unique-only list in original order.
② The Insight
Use a boolean seen[26] array as a hash set for O(1) lookup. Walk the input string with a read pointer; only copy to the write pointer when the character hasn't been seen yet. This is an in-place two-pointer approach with O(n) time and O(1) space.
③ Step-by-Step Logic
  1. Initialize seen[26] = {0} and write index w = 0.
  2. For each character c in the string:
  3. If !seen[c-'a']: copy to s[w++], mark seen[c-'a'] = 1.
  4. After loop: null-terminate at s[w] = '\0'.
Diagram
"abacbc" r=0: 'a' new → write, seen[a]=1, w=1 r=1: 'b' new → write, seen[b]=1, w=2 r=2: 'a' seen → skip r=3: 'c' new → write, seen[c]=1, w=3 r=4: 'b' seen → skip r=5: 'c' seen → skip result: "abc\0"
④ Annotated Code
#include <stdio.h>
#include <string.h>

void remove_duplicates(char *s) {
    int seen[26] = {0};   /* boolean presence for 'a'..'z' */
    int w = 0;            /* write index */
    for (int r = 0; s[r]; r++) {
        int idx = s[r] - 'a';
        if (!seen[idx]) {
            seen[idx] = 1;   /* mark as seen */
            s[w++] = s[r];   /* copy to write position */
        }
    }
    s[w] = '\0';          /* null-terminate the shortened string */
}

int main(void) {
    char s[] = "abacbc";
    remove_duplicates(s);
    printf("%s\n", s);    /* "abc" */

    char t[] = "programming";
    remove_duplicates(t);
    printf("%s\n", t);    /* "progamin" */
    return 0;
}
⑤ Dry Run
"programming": p→new w=1, r→new w=2, o→new w=3, g→new w=4, r→seen skip, a→new w=5, m→new w=6, m→seen skip, i→new w=7, n→new w=8, g→seen skip s[8]='\0' result: "progamin" ✓
⚠ Gotcha: Only handles lowercase a-z

The seen[26] approach assumes lowercase ASCII letters. For arbitrary characters, use seen[128] with idx = (unsigned char)s[r]. For Unicode, you'd need a hash set.

Pattern 08 String Tokenizer — strtok Logic
① Story First
You're cutting a pizza into slices along the scored lines. You find the first score line, cut there, hand off the slice, then look for the next score line from where you left off. strtok works the same way: find a delimiter, replace it with '\0' (the cut), return the token (the slice), and remember where the next search starts.
② The Insight
strtok is destructive — it writes '\0' into the string at each delimiter. It uses a static pointer to remember its position across calls. Call with the string the first time, then pass NULL for subsequent tokens. Because it uses a hidden static variable, it is NOT thread-safe — use strtok_r in multithreaded code.
③ Step-by-Step Logic
  1. First call: strtok(str, delim) — sets internal pointer to str, finds first token.
  2. Replace delimiter with '\0', return pointer to start of token.
  3. Subsequent calls: strtok(NULL, delim) — continues from saved position.
  4. Returns NULL when no more tokens remain.
Diagram
"one,two,three" ↑saved strtok(s,","): finds ',', writes '\0' → "one\0two,three" returns "one" strtok(NULL,","): resumes at 'two', finds ',' → "one\0two\0three" returns "two" strtok(NULL,","): resumes at 'three', no ',' found → returns "three" strtok(NULL,","): returns NULL (done)
④ Annotated Code
#include <stdio.h>
#include <string.h>

int main(void) {
    char csv[] = "alice,bob,charlie,dave";   /* mutable copy required! */
    const char *delim = ",";

    /* First call: pass the string */
    char *token = strtok(csv, delim);
    while (token != NULL) {
        printf("token: %s\n", token);
        token = strtok(NULL, delim);   /* subsequent calls: pass NULL */
    }
    /* csv is now "alice\0bob\0charlie\0dave" — modified! */

    /* Thread-safe version with strtok_r */
    char path[] = "/usr/local/bin";
    char *saveptr;           /* caller-managed state, not static */
    char *part = strtok_r(path, "/", &saveptr);
    while (part) {
        printf("part: %s\n", part);
        part = strtok_r(NULL, "/", &saveptr);
    }
    return 0;
}
⑤ Dry Run
csv = "alice,bob" strtok(csv, ","): scan: a,l,i,c,e → ',' found at i=5 csv[5] = '\0' → "alice\0bob" saved_ptr = &csv[6] (points to 'b') returns "alice" strtok(NULL, ","): resume from saved_ptr='b' scan: b,o,b → '\0' at end → no more commas returns "bob" strtok(NULL, ","): returns NULL
⚠ Gotcha: strtok modifies the string and is not reentrant

You cannot tokenize two strings simultaneously with strtok because it has one hidden static pointer shared across calls. Also, you cannot pass a string literal — strtok writes '\0' delimiters into the string, which crashes on read-only memory. Always pass a mutable copy (char buf[] = "..."). Use strtok_r for reentrancy.

N/A (C standard library)Used in: CSV parsing, path splitting
When splitting a string by delimiter → think: strtok (first call with string, rest with NULL); use strtok_r for threads.
Pattern 09 atoi — String to Integer Conversion
① Story First
You're reading a price tag "42" on a shelf. Your brain converts the characters '4' and '2' into the number forty-two: take the first digit (4), multiply by 10 to make room, add the next digit (2) — done. atoi does exactly this, digit by digit, handling an optional leading sign.
② The Insight
Each digit character has ASCII value ('0' + digit value), so c - '0' gives the numeric digit. Build the number left-to-right: result = result * 10 + digit. Handle optional leading sign and skip leading whitespace. This is O(n) and the basis of LeetCode 8 (myAtoi).
③ Step-by-Step Logic
  1. Skip leading whitespace.
  2. Check for optional '+' or '-' sign; record it.
  3. While the current char is a digit: result = result * 10 + (c - '0').
  4. Apply sign. Clamp to INT_MAX / INT_MIN for robust implementation.
Diagram
" -42abc" skip spaces → '-' sign = -1, advance '4': result = 0*10 + 4 = 4 '2': result = 4*10 + 2 = 42 'a': not digit → stop return -1 * 42 = -42
④ Annotated Code
#include <stdio.h>
#include <limits.h>
#include <ctype.h>

int my_atoi(const char *s) {
    while (isspace(*s)) s++;       /* skip leading whitespace */

    int sign = 1;
    if (*s == '-') { sign = -1; s++; }
    else if (*s == '+') s++;

    long result = 0;
    while (isdigit(*s)) {
        result = result * 10 + (*s - '0');
        /* clamp to avoid overflow before returning */
        if (result * sign >= INT_MAX) return INT_MAX;
        if (result * sign <= INT_MIN) return INT_MIN;
        s++;
    }
    return (int)(sign * result);
}

    printf("%d\n", my_atoi("  -42abc"));  /* -42 */
    printf("%d\n", my_atoi("+100"));      /* 100 */
    printf("%d\n", my_atoi("abc"));       /* 0 (no digits) */
    return 0;
}

Pattern 10 itoa — Integer to String Conversion
① Story First
Writing a number on paper: extract the last digit with modulo (42 % 10 = 2), write it, then shorten the number (42 / 10 = 4), repeat. But you wrote the digits in reverse order — so flip the result at the end. That's itoa in a nutshell.
② The Insight
Repeatedly take n % 10 to get the least significant digit, convert to char with '0' + digit, append to buffer, then divide n by 10. The resulting string is reversed — reverse it at the end. Handle negative numbers by recording the sign and working with the absolute value.
③ Step-by-Step Logic
  1. Handle special case: n == 0 → "0".
  2. If n < 0: record sign, negate n (use long for INT_MIN).
  3. While n > 0: buf[i++] = '0' + (n % 10); n /= 10.
  4. If negative: buf[i++] = '-'.
  5. Reverse buf[0..i-1]; null-terminate.
Diagram

④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Writes integer n as decimal string into buf. buf must be >= 12 bytes. */
void my_itoa(int n, char *buf) {
    if (n == 0) { buf[0]='0'; buf[1]='\0'; return; }

    int neg = (n < 0);
    long val = neg ? -(long)n : (long)n;   /* long handles INT_MIN */

    int i = 0;
    while (val > 0) {
        buf[i++] = '0' + (int)(val % 10);  /* least significant digit first */
        val /= 10;
    }
    if (neg) buf[i++] = '-';   /* add sign last (will be reversed to front) */
    buf[i] = '\0';

    /* reverse: digits were written in reverse order */
    int lo = 0, hi = i - 1;
    while (lo < hi) {
        char tmp = buf[lo]; buf[lo] = buf[hi]; buf[hi] = tmp;
        lo++; hi--;
    }
}

int main(void) {
    char buf[12];
    my_itoa(1234,  buf); printf("%s\n", buf);   /* "1234" */
    my_itoa(-567,  buf); printf("%s\n", buf);   /* "-567" */
    my_itoa(0,     buf); printf("%s\n", buf);   /* "0" */
    return 0;
}

#include <stdio.h>
#include <string.h>

int length_of_longest_substring(const char *s) {
    int freq[128] = {0};   /* ASCII frequency in current window */
    int left = 0, max_len = 0;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        freq[(unsigned char)s[right]]++;   /* expand window right */

        /* Shrink from left until duplicate is removed */

            freq[(unsigned char)s[left]]--;
            left++;
        }

        int win = right - left + 1;
        if (win > max_len) max_len = win;
    }
    return max_len;
}

Pattern 12 Minimum Window Substring
① Story First
You need to collect a specific set of ingredients from a buffet table. You pick items as you walk right; as soon as your tray holds all required ingredients, you try to put back items from the left to make the tray as small as possible while still having everything. Record the smallest valid tray size seen.
② The Insight
Track how many distinct characters from the target are "satisfied" (window count >= target count) using a formed counter. Expand right to satisfy requirements; once all satisfied, shrink left to minimize. The window is valid when formed == required.
③ Step-by-Step Logic
  1. Build target frequency map from t. Count distinct chars in target: required.
  2. Expand right: update window freq; if char's window count equals target count, formed++.
  3. When formed == required: record window; shrink left until formed < required.
  4. Repeat. Return the smallest recorded window.

④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <limits.h>

void min_window(const char *s, const char *t, char *out) {
    int need[128] = {0}, window[128] = {0};
    int required = 0, formed = 0;

    for (int i = 0; t[i]; i++) {
        if (need[(unsigned char)t[i]]++ == 0) required++;   /* new distinct char */
    }

    int left = 0, best_left = 0, best_len = INT_MAX;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        int c = (unsigned char)s[right];
        window[c]++;
        if (need[c] > 0 && window[c] == need[c]) formed++;   /* satisfied */

        while (formed == required) {   /* valid window — try to shrink */
            if (right - left + 1 < best_len) {
                best_len = right - left + 1;
                best_left = left;
            }
            int lc = (unsigned char)s[left];
            window[lc]--;
            if (need[lc] > 0 && window[lc] < need[lc]) formed--;   /* unsatisfied */
            left++;
        }
    }

    if (best_len == INT_MAX) { out[0] = '\0'; return; }
    strncpy(out, s + best_left, best_len);
    out[best_len] = '\0';
}

int main(void) {
    char result[100];
    min_window("ADOBECODEBANC", "ABC", result);
    printf("%s\n", result);   /* "BANC" */
    return 0;
}

⚠ Gotcha: Only update formed when count exactly hits need

Only increment formed when window[c] == need[c] (not just > 0). Similarly, only decrement when window[c] drops below need[c]. Having more than needed is fine — we only care about meeting the exact requirement.

① Story First

#include <stdio.h>
#include <string.h>

int longest_k_distinct(const char *s, int k) {
    if (k == 0) return 0;
    int freq[128] = {0};
    int left = 0, distinct = 0, max_len = 0;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        int c = (unsigned char)s[right];
        if (freq[c]++ == 0) distinct++;   /* new character enters window */

        while (distinct > k) {
            int lc = (unsigned char)s[left];
            if (--freq[lc] == 0) distinct--;   /* character leaves window */
            left++;
        }

        int win = right - left + 1;
        if (win > max_len) max_len = win;
    }
    return max_len;
}

    return 0;
}

Pattern 14 Anagram Check — Frequency Array Comparison
① Story First
"listen" and "silent" — do they use the same letters the same number of times? Instead of sorting both (expensive), just tally each letter in the first string and un-tally for the second. If all tallies hit zero at the end, they're anagrams.
② The Insight
Use a single frequency array — increment for string A, decrement for string B. If they're anagrams, every entry returns to 0. This avoids sorting (O(n log n)) and uses O(1) space (26 or 128 integers, fixed).
③ Step-by-Step Logic
  1. If lengths differ: return false immediately.
  2. Walk both strings simultaneously: freq[a[i]-'a']++, freq[b[i]-'a']--.
  3. After the loop: check if all freq[] entries are 0.
  4. Any non-zero entry means one string has a character the other doesn't.

#include <stdio.h>
#include <string.h>

int is_anagram(const char *a, const char *b) {
    if (strlen(a) != strlen(b)) return 0;   /* must be same length */
    int freq[26] = {0};
    /* Increment for a, decrement for b — net effect is zero if anagram */
    for (int i = 0; a[i]; i++) {
        freq[a[i] - 'a']++;
        freq[b[i] - 'a']--;
    }
    for (int i = 0; i < 26; i++)
        if (freq[i] != 0) return 0;   /* mismatch found */
    return 1;
}

int main(void) {
    printf("%d\n", is_anagram("anagram", "nagaram"));  /* 1 */
    printf("%d\n", is_anagram("rat",     "car"));      /* 0 */
    printf("%d\n", is_anagram("listen",  "silent"));   /* 1 */
    return 0;
}

#include <stdio.h>
#include <string.h>

void find_anagrams(const char *s, const char *p) {

    if (ns < np) return;

    int need[26] = {0}, win[26] = {0};
    for (int i = 0; i < np; i++) need[p[i]-'a']++;

    /* Initialize window with first np chars */
    for (int i = 0; i < np; i++) win[s[i]-'a']++;

#include <string.h>

int check_inclusion(const char *s1, const char *s2) {
    int n1 = (int)strlen(s1), n2 = (int)strlen(s2);
    if (n1 > n2) return 0;

    int need[26] = {0}, win[26] = {0};
    for (int i = 0; i < n1; i++) { need[s1[i]-'a']++; win[s2[i]-'a']++; }

    /* Count how many of 26 buckets already match */
    int match = 0;
    for (int i = 0; i < 26; i++) if (need[i] == win[i]) match++;
    if (match == 26) return 1;

    for (int right = n1; right < n2; right++) {
        int add = s2[right] - 'a';
        int rem = s2[right - n1] - 'a';

        /* Add new right character */
        win[add]++;
        if (win[add] == need[add]) match++;           /* just became equal */
        else if (win[add] == need[add] + 1) match--;  /* just became unequal */

        /* Remove old left character */
        win[rem]--;
        if (win[rem] == need[rem]) match++;
        else if (win[rem] == need[rem] - 1) match--;

        if (match == 26) return 1;
    }
    return 0;
}

① Story First
You have a string of letters and can change at most k of them to any letter. You want the longest run where all letters are the same. ② The Insight

③ Step-by-Step Logic

  2. Expand right: freq[s[right]-'a']++; update max_freq = max(max_freq, freq[...]).

  4. max_len = max(max_len, right - left + 1).

#include <stdio.h>
#include <string.h>

int character_replacement(const char *s, int k) {
    int freq[26] = {0}, left = 0, max_freq = 0, max_len = 0;
    int n = (int)strlen(s);

    for (int right = 0; right < n; right++) {
        int c = s[right] - 'a';
        freq[c]++;
        if (freq[c] > max_freq) max_freq = freq[c];   /* update dominant freq */

        /* cost = window_size - max_freq = letters that need changing */
        int window = right - left + 1;
        if (window - max_freq > k) {
            freq[s[left] - 'a']--;   /* shrink — only move by 1 */
            left++;
        }

        window = right - left + 1;
        if (window > max_len) max_len = window;
    }
    return max_len;
}

int main(void) {
    printf("%d\n", character_replacement("AABABBA", 1));   /* 4 */
    printf("%d\n", character_replacement("ABAB",    2));   /* 4 */
    printf("%d\n", character_replacement("AAAA",    2));   /* 4 */
    return 0;
}
⑤ Dry Run
"ABAB", k=2: r=0:'A' freq[A]=1, max=1, win=1, cost=0 ≤2, len=1 r=1:'B' freq[B]=1, max=1, win=2, cost=1 ≤2, len=2 r=2:'A' freq[A]=2, max=2, win=3, cost=1 ≤2, len=3 r=3:'B' freq[B]=2, max=2, win=4, cost=2 ≤2, len=4 return 4 ✓ (can replace 2 chars to get "AAAA" or "BBBB")
⚠ Gotcha: max_freq can become stale — and that's okay

When shrinking left, max_freq might not decrease even if the dominant character was removed. This means the window might sometimes be smaller than it "could" be — but it never incorrectly reports a window as valid when it isn't. The max_len never gets inflated because the window size can only grow if max_freq actually increases.

Pattern 18 Count Substrings with Exactly K Distinct Characters
① Story First
Counting windows with exactly K distinct chars is tricky because a window "grows" as you add chars, not cleanly bounded. The trick: express "exactly K" as "at most K" minus "at most K-1." Sliding window gives at-most counts easily; the difference gives the exact count.
② The Insight
count(exactly K) = count(at most K) - count(at most K-1). The at-most-K count: for each right, expand right and shrink left until distinct ≤ K — then every window ending at right starting anywhere from [0..left] is valid, contributing (right - left + 1) windows.
③ Step-by-Step Logic
  1. Write helper at_most_k(s, k) counting substrings with ≤k distinct chars.
  2. Maintain freq[], distinct, left. For each right: add char; shrink until distinct ≤ k.
  3. Add right - left + 1 to count (all windows ending here with valid left start).
  4. Return at_most_k(s, k) - at_most_k(s, k-1).
Diagram
"aab", k=1: at_most(k=1): "a","a","b","aa" but "aa" has 1 distinct, "aab" has 2 (excluded) r=0:'a' distinct=1, left=0, count += 1 → 1 r=1:'a' distinct=1, left=0, count += 2 → 3 r=2:'b' distinct=2>1, shrink: remove 'a',left=1; 'a'→freq=0→distinct=1,left=2 count += 1 → 4 at_most(k=1) = 4 at_most(k=0) = 0 (no empty substring counts) exactly(1) = 4 - 0 = 4? Let's count: "a","a","aa","b" = 4 ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

/* Count substrings with AT MOST k distinct characters */
long at_most_k(const char *s, int k) {
    int freq[128] = {0}, distinct = 0, left = 0;
    long count = 0;
    int n = (int)strlen(s);
    for (int right = 0; right < n; right++) {
        if (freq[(unsigned char)s[right]]++ == 0) distinct++;
        while (distinct > k) {
            if (--freq[(unsigned char)s[left]] == 0) distinct--;
            left++;
        }
        count += right - left + 1;   /* all valid windows ending at right */
    }
    return count;
}

/* Count substrings with EXACTLY k distinct characters */
long count_exactly_k(const char *s, int k) {
    return at_most_k(s, k) - at_most_k(s, k - 1);
}

int main(void) {
    printf("%ld\n", count_exactly_k("aab", 1));    /* 4 */
    printf("%ld\n", count_exactly_k("abc", 2));    /* 2 ("ab","bc") */
    printf("%ld\n", count_exactly_k("abcba", 2));  /* 6 */
    return 0;
}
⑤ Dry Run
at_most_k("abc", 2): r=0:'a' distinct=1, count+=1=1 r=1:'b' distinct=2, count+=2=3 r=2:'c' distinct=3>2, shrink: remove 'a',left=1,distinct=2 count+=2=5 at_most("abc",2) = 5 at_most("abc", 1): r=0: count=1 r=1: 'b' distinct=2>1, shrink: distinct=1, count+=1=2 r=2: 'c' distinct=2>1, shrink: distinct=1, count+=1=3 at_most("abc",1) = 3 exactly(2) = 5 - 3 = 2 → "ab","bc" ✓
⚠ Gotcha: The at-most trick is the key insight

"Exactly K" windows are hard to count directly because adding a character can transition from invalid to valid to invalid again. The at-most trick avoids this by using monotone validity (adding chars can only increase distinct count, removing chars can only decrease it).

Pattern 19 Minimum Consecutive Cards to Pick Up
① Story First
You're picking cards from a deck one at a time. You need to collect at least one pair of matching cards. What's the minimum number of consecutive cards you must draw to guarantee picking up a matching pair? The moment you see a card you already have in hand, that stretch is your window.
② The Insight
Use a hash map (or frequency array) to track the last seen index of each card value. When you encounter a card you've seen before, the window from its last occurrence to now is a valid window containing a pair. Track the minimum such window length.
③ Step-by-Step Logic
  1. Initialize last_seen[] to -1 for all values.
  2. For each index i: if last_seen[cards[i]] != -1, compute window = i - last_seen[cards[i]] + 1.
  3. Update min_len; always update last_seen[cards[i]] = i.
  4. Return min_len (or -1 if no pair found).
Diagram
cards = [3,4,2,3,4,7] i=0: val=3, last=-1, record last[3]=0 i=1: val=4, last=-1, record last[4]=1 i=2: val=2, last=-1, record last[2]=2 i=3: val=3, last=0 → window=3-0+1=4, min=4; last[3]=3 i=4: val=4, last=1 → window=4-1+1=4, min=4; last[4]=4 min = 4 ✓ (pick up "3,4,2,3" or "4,2,3,4")
④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <limits.h>

#define MAX_VAL 1001

int minimum_card_pickup(int *cards, int n) {
    int last[MAX_VAL];
    memset(last, -1, sizeof(last));   /* -1 = not seen */

    int min_len = INT_MAX;
    for (int i = 0; i < n; i++) {
        int v = cards[i];
        if (last[v] != -1) {
            int window = i - last[v] + 1;   /* inclusive window length */
            if (window < min_len) min_len = window;
        }
        last[v] = i;   /* always update: we want MOST RECENT occurrence */
    }
    return (min_len == INT_MAX) ? -1 : min_len;
}

int main(void) {
    int c1[] = {3,4,2,3,4,7};
    printf("%d\n", minimum_card_pickup(c1, 6));   /* 4 */

    int c2[] = {1,0,5,3};
    printf("%d\n", minimum_card_pickup(c2, 4));   /* -1 (no pair) */
    return 0;
}
⑤ Dry Run
cards=[3,4,2,3,4,7]: i=0: last[3]=-1 → last[3]=0 i=1: last[4]=-1 → last[4]=1 i=2: last[2]=-1 → last[2]=2 i=3: last[3]=0 ≠ -1 → win=3-0+1=4, min=4; last[3]=3 i=4: last[4]=1 ≠ -1 → win=4-1+1=4, min=4; last[4]=4 i=5: last[7]=-1 → last[7]=5 return 4 ✓
⚠ Gotcha: Update last_seen even after finding a pair

Always update last_seen[v] = i after checking, even when a match is found. A later occurrence of the same value combined with an even earlier match might produce a shorter window — but only if you use the most recent previous occurrence, not the first one.

Pattern 20 Max Vowels in Substring of Length K
① Story First
You have a telescope that can only view exactly K consecutive letters at a time. You want to point it at the section that contains the most vowels. Slide it one step at a time — when you move right, you gain one letter (might be a vowel) and lose one letter from the left (might have been a vowel).
② The Insight
Fixed-size sliding window. Count vowels in the initial window of size k. Then slide: if the character entering from the right is a vowel, increment; if the character leaving from the left was a vowel, decrement. O(n) total, O(1) space.
③ Step-by-Step Logic
  1. Count vowels in s[0..k-1]; record as max_v = curr_v.
  2. For each new right position r from k to n-1:
  3. Add is_vowel(s[r]); subtract is_vowel(s[r-k]).
  4. Update max_v = max(max_v, curr_v).
Diagram
"abciiidef", k=3: init [abc]: a=1,b=0,c=0 → curr=1, max=1 slide [bci]: -a(1), +i(1) → curr=1, max=1 slide [cii]: -b(0), +i(1) → curr=2, max=2 slide [iii]: -c(0), +i(1) → curr=3, max=3 slide [iid]: -i(1), +d(0) → curr=2, max=3 ... max = 3 ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

static int is_vowel(char c) {
    return c=='a'||c=='e'||c=='i'||c=='o'||c=='u';
}

int max_vowels(const char *s, int k) {
    int n = (int)strlen(s);
    int curr = 0;

    /* Count vowels in initial window */
    for (int i = 0; i < k; i++) curr += is_vowel(s[i]);
    int best = curr;

    /* Slide: add right char, remove left char */
    for (int r = k; r < n; r++) {
        curr += is_vowel(s[r]);         /* entering */
        curr -= is_vowel(s[r - k]);     /* leaving */
        if (curr > best) best = curr;
    }
    return best;
}

int main(void) {
    printf("%d\n", max_vowels("abciiidef", 3));   /* 3 */
    printf("%d\n", max_vowels("aeiou",     2));   /* 2 */
    printf("%d\n", max_vowels("leetcode",  3));   /* 2 */
    return 0;
}
⑤ Dry Run

⚠ Gotcha: Fixed window — no shrinking needed

This is a fixed-size window problem: the window is always exactly k characters. Unlike variable-size windows, you never need to shrink — just add one from the right and remove one from the left at every step.
