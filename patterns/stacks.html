Pattern 01 Array-Based Stack Implementation
① Story First
A stack of plates: you can only put a new plate on top (push) or take the top plate off (pop). You cannot access plates in the middle. Last in, first out. An array stack uses an integer index (top) pointing at the topmost element — increment on push, decrement on pop.
② The Insight
Array stack is the simplest and fastest stack: O(1) push, pop, and peek with no heap allocation. The top index starts at -1 (empty). Push: data[++top] = val. Pop: return data[top--]. The only failure mode is overflow (top == capacity-1) and underflow (top == -1).
③ Step-by-Step Logic
  1. struct Stack { int data[MAX]; int top; }. Initialize top = -1.
  2. push(val): if top == MAX-1, overflow. Else data[++top] = val.
  3. pop(): if top == -1, underflow. Else return data[top--].
  4. peek(): return data[top] without modifying top.
Diagram
Empty: top=-1 [] push(1): top=0 [1] push(2): top=1 [1,2] push(3): top=2 [1,2,3] pop()→3: top=1 [1,2] peek()→2: top=1 [1,2] (unchanged)
④ Annotated Code
#include <stdio.h>
#include <assert.h>

#define MAX 1024

typedef struct { int data[MAX]; int top; } Stack;

void stack_init(Stack *s) { s->top = -1; }
int  stack_empty(Stack *s) { return s->top == -1; }
int  stack_full(Stack *s)  { return s->top == MAX-1; }

void stack_push(Stack *s, int val) {
    assert(!stack_full(s));    /* catch overflow in debug builds */
    s->data[++s->top] = val;
}
int stack_pop(Stack *s) {
    assert(!stack_empty(s));   /* catch underflow */
    return s->data[s->top--];
}
int stack_peek(Stack *s) {
    assert(!stack_empty(s));
    return s->data[s->top];
}

int main(void) {
    Stack s; stack_init(&s);
    stack_push(&s, 10);
    stack_push(&s, 20);
    stack_push(&s, 30);
    printf("peek=%d\n", stack_peek(&s));  /* 30 */
    printf("pop=%d\n",  stack_pop(&s));   /* 30 */
    printf("pop=%d\n",  stack_pop(&s));   /* 20 */
    printf("empty=%d\n",stack_empty(&s)); /* 0 (10 still there) */
    return 0;
}
⑤ Dry Run
init: top=-1 push(10): data[0]=10, top=0 push(20): data[1]=20, top=1 push(30): data[2]=30, top=2 peek: data[2]=30 ✓ pop: return data[2]=30, top=1 ✓ pop: return data[1]=20, top=0 ✓
⚠ Gotcha: top starts at -1, not 0

If top starts at 0, the first push writes to data[1] (skipping data[0]) or you need a special case for the first push. Starting at -1 means the pre-increment data[++top] writes to data[0] on the first push, which is natural and correct.

N/A (fundamental data structure)
When you need LIFO access → think: array stack, top=-1, push: data[++top]=val, pop: return data[top--].
Pattern 02 Linked List Stack
① Story First
A stack where each item knows what's below it. No fixed capacity — the stack grows as you push and shrinks as you pop. Each push allocates a new node at the top; each pop frees it. The head of the linked list IS the top of the stack.
② The Insight
Linked stack: head = top of stack. Push = insert at head. Pop = remove head. O(1) for both, unlimited capacity (until heap exhausted). Overhead: one malloc/free per push/pop — slower than array stack in practice due to memory allocation cost.
③ Step-by-Step Logic
  1. Push: allocate node, node->next = head, head = node.
  2. Pop: save head->val, temp = head, head = head->next, free(temp), return val.
  3. Peek: return head->val.
  4. Empty: head == NULL.
Diagram
push(1): head→[1]→NULL push(2): head→[2]→[1]→NULL push(3): head→[3]→[2]→[1]→NULL pop()→3: head→[2]→[1]→NULL, free [3]
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>

typedef struct SNode { int val; struct SNode *next; } SNode;
typedef struct { SNode *head; int size; } LStack;

void ls_init(LStack *s) { s->head=NULL; s->size=0; }
int  ls_empty(LStack *s) { return s->head==NULL; }

void ls_push(LStack *s, int val) {
    SNode *n = malloc(sizeof(SNode));
    n->val = val; n->next = s->head;
    s->head = n; s->size++;
}
int ls_pop(LStack *s) {
    assert(!ls_empty(s));
    SNode *tmp = s->head;
    int val = tmp->val;
    s->head = tmp->next;
    free(tmp); s->size--;
    return val;
}
int ls_peek(LStack *s) { assert(!ls_empty(s)); return s->head->val; }

int main(void) {
    LStack s; ls_init(&s);
    ls_push(&s,1); ls_push(&s,2); ls_push(&s,3);
    printf("%d %d %d\n", ls_pop(&s), ls_pop(&s), ls_pop(&s)); /* 3 2 1 */
    return 0;
}
⑤ Dry Run
push(1): head=[1]→NULL, size=1 push(2): head=[2]→[1]→NULL, size=2 push(3): head=[3]→[2]→[1]→NULL, size=3 pop: val=3, head=[2]→[1], free [3], size=2 pop: val=2, head=[1], free [2], size=1 pop: val=1, head=NULL, free [1], size=0 ✓
⚠ Gotcha: Save val BEFORE freeing the node

In pop: save val = tmp->val before calling free(tmp). After free, reading tmp->val is undefined behavior. This is the same pattern as linked list traversal — always save what you need before releasing memory.

N/A (used in DFS, expression eval)
When you need a stack without fixed capacity → think: linked stack, head = top, push = insert at head, pop = remove head.
Pattern 03 Valid Parentheses
① Story First
Every opening bracket needs a matching closing bracket in the right order. A stack tracks unmatched openers. On an opener, push. On a closer, pop — if the popped opener doesn't match, it's invalid. If the stack is empty when closing, invalid. If non-empty at end, unclosed openers remain — invalid.
② The Insight
Stack is perfect here because brackets must close in reverse order of opening (LIFO). The top of the stack is always the most recently opened, unmatched bracket — exactly what needs to match the next closer.
③ Step-by-Step Logic
  1. For each char: if opener, push. If closer and stack empty, return false.
  2. If closer: pop top. If top doesn't match the closer type, return false.
  3. After loop: return stack is empty (all openers matched).
Diagram
"({[]})" '(' → push: ['('] '{' → push: ['(', '{'] '[' → push: ['(', '{', '['] ']' → pop '[', matches ']' ✓: ['(', '{'] '}' → pop '{', matches '}' ✓: ['('] ')' → pop '(', matches ')' ✓: [] empty → VALID ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

int is_valid(const char *s) {
    char stack[10001];
    int top = -1;
    for (; *s; s++) {
        if (*s=='(' || *s=='[' || *s=='{') {
            stack[++top] = *s;             /* push opener */
        } else {
            if (top == -1) return 0;       /* nothing to match */
            char open = stack[top--];      /* pop */
            if (*s==')' && open!='(') return 0;
            if (*s==']' && open!='[') return 0;
            if (*s=='}' && open!='{') return 0;
        }
    }
    return top == -1;   /* all matched iff stack empty */
}

int main(void) {
    printf("%d\n", is_valid("()[]{}"));  /* 1 */
    printf("%d\n", is_valid("([)]"));    /* 0 */
    printf("%d\n", is_valid("{[]}"));    /* 1 */
    printf("%d\n", is_valid("]"));       /* 0 */
    return 0;
}
⑤ Dry Run
is_valid("([)]"): '(' push, top=0: ['('] '[' push, top=1: ['(','['] ')' → pop '[': open='[', ')' needs '(' but got '[' → return 0 ✓
⚠ Gotcha: Check top==-1 before popping on a closer

If the string starts with a closer (e.g., "]abc"), top is -1 and there's nothing to pop. Without the empty-stack check, stack[top--] with top=-1 reads stack[-1] — undefined behavior. Always check before popping.

Pattern 04 Min Stack — O(1) getMin
① Story First
A stack where you can ask "what's the current minimum?" in O(1) at any time. The trick: maintain a second parallel stack that tracks the minimum at each level. When you push a new value, push min(new_val, current_min) onto the min stack too. When you pop, pop both stacks.
② The Insight
Two stacks — one for data, one for minimums. The min stack's top always reflects the minimum of all values currently in the data stack. When the minimum value is popped from the data stack, the min stack also pops, revealing the previous minimum automatically.
③ Step-by-Step Logic
  1. push(val): push val to data stack. Push min(val, min_stack.top) to min stack.
  2. pop(): pop both data stack and min stack.
  3. getMin(): return min stack top. O(1).
  4. top(): return data stack top.
Diagram
push(5): data=[5], min=[5] push(3): data=[5,3], min=[5,3] push(7): data=[5,3,7], min=[5,3,3] ← min stays 3 getMin()→3 ✓ pop(): data=[5,3], min=[5,3] pop(): data=[5], min=[5] getMin()→5 ✓
④ Annotated Code
#include <stdio.h>
#include <assert.h>

#define MAX 10001

typedef struct {
    int data[MAX], min_s[MAX];
    int dtop, mtop;
} MinStack;

void ms_init(MinStack *s) { s->dtop = s->mtop = -1; }

void ms_push(MinStack *s, int val) {
    s->data[++s->dtop] = val;
    int cur_min = (s->mtop == -1) ? val : (val < s->min_s[s->mtop] ? val : s->min_s[s->mtop]);
    s->min_s[++s->mtop] = cur_min;   /* push current minimum */
}
int ms_pop(MinStack *s) {
    assert(s->dtop >= 0);
    s->mtop--;                        /* pop min stack in sync */
    return s->data[s->dtop--];
}
int ms_top(MinStack *s)    { return s->data[s->dtop]; }
int ms_get_min(MinStack *s){ return s->min_s[s->mtop]; }  /* O(1) */

int main(void) {
    MinStack s; ms_init(&s);
    ms_push(&s,5); ms_push(&s,3); ms_push(&s,7);
    printf("min=%d\n", ms_get_min(&s));  /* 3 */
    ms_pop(&s);
    printf("min=%d\n", ms_get_min(&s));  /* 3 */
    ms_pop(&s);
    printf("min=%d\n", ms_get_min(&s));  /* 5 */
    return 0;
}
⑤ Dry Run
push(5): data=[5], min=[5] push(3): cur_min=min(3,5)=3 → data=[5,3], min=[5,3] push(7): cur_min=min(7,3)=3 → data=[5,3,7], min=[5,3,3] get_min → min[2]=3 ✓ pop: data=[5,3], min=[5,3]; get_min=3 ✓ pop: data=[5], min=[5]; get_min=5 ✓
⚠ Gotcha: Pop BOTH stacks together — they must stay in sync

If you only pop the data stack (forgetting the min stack), they go out of sync and getMin returns the wrong value. The min stack always has exactly as many elements as the data stack — they grow and shrink together.

Pattern 05 Evaluate Reverse Polish Notation (RPN)
① Story First
"3 4 + 2 *" means (3+4)*2. No parentheses needed — the order of operands and operators already encodes the precedence. Walk left to right: push numbers; on an operator, pop two numbers, apply the operation, push the result back.
② The Insight
RPN evaluation is the canonical stack use case. A number means "save for later" (push). An operator means "use the last two saved values" (pop two, operate, push result). When you reach the end of a valid RPN expression, exactly one value remains on the stack — the answer.
③ Step-by-Step Logic
  1. For each token: if number, push it.
  2. If operator: pop b (top), pop a (second). Result = a op b. Push result.
  3. After all tokens: answer is stack[0].
Diagram
Tokens: ["2","1","+","3","*"] "2" → push: [2] "1" → push: [2,1] "+" → pop 1, pop 2, push 2+1=3: [3] "3" → push: [3,3] "*" → pop 3, pop 3, push 3*3=9: [9] Result: 9 ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int eval_rpn(char **tokens, int n) {
    long stack[n];
    int top = -1;

    for (int i = 0; i < n; i++) {
        char *t = tokens[i];
        if (strcmp(t,"+")==0 || strcmp(t,"-")==0 ||
            strcmp(t,"*")==0 || strcmp(t,"/")==0) {
            long b = stack[top--];   /* second operand (top) */
            long a = stack[top--];   /* first operand */
            if      (*t=='+') stack[++top] = a + b;
            else if (*t=='-') stack[++top] = a - b;
            else if (*t=='*') stack[++top] = a * b;
            else              stack[++top] = a / b;  /* truncates toward zero */
        } else {
            stack[++top] = atol(t);   /* convert token to number and push */
        }
    }
    return (int)stack[0];
}

int main(void) {
    char *t1[] = {"2","1","+","3","*"};
    printf("%d\n", eval_rpn(t1, 5));   /* 9 */

    char *t2[] = {"4","13","5","/","+"};
    printf("%d\n", eval_rpn(t2, 5));   /* 6 */
    return 0;
}
⑤ Dry Run
["4","13","5","/","+"]: "4" → push 4: [4] "13" → push 13: [4,13] "5" → push 5: [4,13,5] "/" → b=5, a=13; 13/5=2; push 2: [4,2] "+" → b=2, a=4; 4+2=6; push 6: [6] result=6 ✓
⚠ Gotcha: Pop order matters for non-commutative ops

For subtraction and division, order matters: the first pop gives b (the second operand), the second pop gives a (the first operand). The expression is a op b. Reversing the pop order gives wrong results for "5 3 -" (should be 5-3=2, not 3-5=-2).

Pattern 06 Daily Temperatures — Next Warmer Day
① Story First
For each day, how many days until a warmer temperature? "73 74 75 71 69 72 76 73" → "1 1 4 2 1 1 0 0". Walk left to right. If today is warmer than some previous days, those days now have their answer. A stack of unresolved days (indices) waits for their warmer future.
② The Insight
Monotonic decreasing stack of indices. For each day i: while the stack top's temperature < today's temperature, pop it — that day's answer is i - popped_index. Then push i. Days still on the stack at the end have no warmer future (answer = 0).
③ Step-by-Step Logic
  1. ans[] = {0}, stack of indices, initially empty.
  2. For each i: while stack not empty and temps[stack.top] < temps[i]: pop j; ans[j] = i - j.
  3. Push i.
  4. Remaining indices on stack have ans = 0 (already initialized).
Diagram
temps=[73,74,75,71,69,72,76,73] i=0: push 0. stack=[0] i=1: 74>73 → pop 0, ans[0]=1-0=1. push 1. stack=[1] i=2: 75>74 → pop 1, ans[1]=2-1=1. push 2. stack=[2] i=3: 71<75. push 3. stack=[2,3] i=4: 69<71. push 4. stack=[2,3,4] i=5: 72>69→pop 4,ans[4]=1; 72>71→pop 3,ans[3]=2; 72<75. push 5. stack=[2,5] i=6: 76>72→pop 5,ans[5]=1; 76>75→pop 2,ans[2]=4. push 6. stack=[6] i=7: 73<76. push 7. stack=[6,7] ans: [1,1,4,2,1,1,0,0] ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

void daily_temperatures(int *temps, int n, int *ans) {
    int stack[n];   /* stack of unresolved indices */
    int top = -1;
    memset(ans, 0, n * sizeof(int));

    for (int i = 0; i < n; i++) {
        /* Pop days that are colder than today */
        while (top >= 0 && temps[stack[top]] < temps[i]) {
            int j = stack[top--];
            ans[j] = i - j;   /* days waited = today - that day */
        }
        stack[++top] = i;     /* push today's index (unresolved) */
    }
}

int main(void) {
    int temps[] = {73,74,75,71,69,72,76,73};
    int ans[8];
    daily_temperatures(temps, 8, ans);
    for (int i=0; i<8; i++) printf("%d ", ans[i]);
    /* 1 1 4 2 1 1 0 0 */
    return 0;
}

See diagram above — full trace matches expected output ✓
⚠ Gotcha: Stack stores INDICES, not temperatures

The stack holds indices (positions) so you can compute the distance i - j. If you stored temperatures, you couldn't recover the original day's position. This index-stack pattern appears in most monotonic stack problems.

Pattern 07 Next Greater Element I
① Story First
Given two arrays, for each element in the first array, find the next greater element in the second array (looking rightward from where that element appears). Precompute "next greater" for all elements in the second array using a monotonic stack, then look up answers for the first array in a hash map.
② The Insight
Build a "next greater" map for all elements of nums2 using a monotonic stack in one pass. Then for each element in nums1, look up its next greater value in the map. O(n+m) total. The stack processes each element of nums2 at most twice (once pushed, once popped).
③ Step-by-Step Logic
  1. Process nums2 left to right with a decreasing stack.
  2. When nums2[i] > stack top: that top's "next greater" is nums2[i]. Record in map. Pop.
  3. Push nums2[i]. Elements still on stack have no next greater (-1).
  4. For each element in nums1: look up in map.
Diagram
nums2=[1,3,4,2], build next-greater map: push 1: stack=[1] 3>1: pop 1, map[1]=3; push 3: stack=[3] 4>3: pop 3, map[3]=4; push 4: stack=[4] 2<4: push 2: stack=[4,2] end: map[4]=-1, map[2]=-1 nums1=[4,1,2]: lookup → [-1, 3, -1] ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

#define MAXVAL 10001

void next_greater_element(int *nums1, int n1, int *nums2, int n2, int *res) {
    int nge[MAXVAL];              /* nge[v] = next greater of value v in nums2 */
    memset(nge, -1, sizeof(nge));

    int stack[n2], top = -1;
    for (int i = 0; i < n2; i++) {
        while (top >= 0 && stack[top] < nums2[i])
            nge[stack[top--]] = nums2[i];   /* nums2[i] is next greater for popped */
        stack[++top] = nums2[i];
    }
    /* remaining on stack: no next greater → already -1 */

    for (int i = 0; i < n1; i++)
        res[i] = nge[nums1[i]];
}

int main(void) {
    int nums1[] = {4,1,2}, nums2[] = {1,3,4,2};
    int res[3];
    next_greater_element(nums1, 3, nums2, 4, res);
    for(int i=0;i<3;i++) printf("%d ",res[i]); /* -1 3 -1 */
    return 0;
}
⑤ Dry Run
nums2=[1,3,4,2]: i=0: push 1. stack=[1] i=1: 3>1→nge[1]=3, pop; push 3. stack=[3] i=2: 4>3→nge[3]=4, pop; push 4. stack=[4] i=3: 2<4; push 2. stack=[4,2] nge[4]=-1, nge[2]=-1 (still in stack) lookup nums1=[4,1,2]: [-1, 3, -1] ✓
⚠ Gotcha: This only works when all values are unique

Mapping by value (nge[val]) requires all values in nums2 to be distinct. If duplicates exist, the map would be overwritten. For duplicate values, map by index instead and use the index to look up the original value's position in nums2.

Pattern 08 Next Greater Element II — Circular Array
① Story First
Same problem but the array wraps around — after the last element, you continue from the first. "3 1 2 3" circularly: for the first 3, the next greater wrapping around... doesn't exist. For 1, it's 2. For 2, it's 3. Simulate two passes by doubling the indices.
② The Insight
Simulate circular traversal by iterating indices 0 to 2n-1, using i % n to get the actual array index. Only push indices (not values) for the first n elements (second pass only resolves, doesn't add new candidates). Run the same monotonic stack logic.
③ Step-by-Step Logic
  1. ans[] = {-1}. Stack of indices, initially empty.
  2. Loop i from 0 to 2n-1: idx = i % n.
  3. While stack not empty and nums[stack.top] < nums[idx]: pop j; ans[j] = nums[idx].
  4. If i < n: push idx (only push actual positions in first pass).
Diagram
nums=[5,4,3,2,1], n=5, circular: First pass (i=0..4): push indices 0,1,2,3,4. No pops (decreasing sequence). Second pass (i=5..9, idx=0..4): i=5,idx=0: nums[0]=5 > nums[4]=1 → pop 4, ans[4]=5 5 > nums[3]=2 → pop 3, ans[3]=5 5 > nums[2]=3 → pop 2, ans[2]=5 5 > nums[1]=4 → pop 1, ans[1]=5 5 == nums[0]=5 → stop i=6,idx=1: nums[1]=4 not > nums[0]=5 → stop ...no more pops ans[0]=-1 (5 never found a larger in circle) ✓
④ Annotated Code
#include <stdio.h>
#include <string.h>

void next_greater_circular(int *nums, int n, int *ans) {
    memset(ans, -1, n * sizeof(int));
    int stack[n], top = -1;

    for (int i = 0; i < 2 * n; i++) {
        int idx = i % n;
        while (top >= 0 && nums[stack[top]] < nums[idx])
            ans[stack[top--]] = nums[idx];
        if (i < n) stack[++top] = idx;   /* only push in first pass */
    }
}

int main(void) {
    int nums[] = {1,2,1};
    int ans[3];
    next_greater_circular(nums, 3, ans);
    for(int i=0;i<3;i++) printf("%d ",ans[i]); /* 2 -1 2 */
    return 0;
}
⑤ Dry Run
nums=[1,2,1], n=3: i=0,idx=0: push 0. stack=[0] i=1,idx=1: 2>1→pop 0, ans[0]=2; push 1. stack=[1] i=2,idx=2: 1<2; push 2. stack=[1,2] i=3,idx=0: 1<2; no push (i>=n) i=4,idx=1: 2>1→pop 2, ans[2]=2; 2==2 stop; no push i=5,idx=2: 1<2; no push ans=[2,-1,2] ✓
⚠ Gotcha: Only push in the first pass (i < n)

In the second pass (i ≥ n), you only resolve existing stack entries — you don't push new indices. If you push in the second pass too, you'd get duplicate index entries and the ans[j] = nums[idx] assignments would corrupt already-resolved answers.

Pattern 09

Largest Rectangle in Histogram

Imagine a city skyline of buildings side by side, each with different heights. You want to find the largest billboard you can paste on a contiguous section of that skyline — it must fit under every building in the section. The billboard's height equals the shortest building it spans.
Core insight: For each bar, the largest rectangle it can be the minimum of extends left until a shorter bar appears and right until a shorter bar appears. A monotonic increasing stack tracks exactly those left-boundary bars — when you pop a bar, the current bar is its right boundary and the new top is its left boundary.
③ Step-by-step Logic
  1. Maintain a stack of indices in increasing-height order.
  2. For each bar i: while stack top has height ≥ heights[i], pop it as the height of a candidate rectangle.
  3. Width = i − stack[top] − 1 (or i if stack empty after pop).
  4. Area = popped_height × width; track max.
  5. After the loop, pop remaining indices with width extending to the end (n − stack[top] − 1).

Pattern 10

Trapping Rain Water (Stack)

Think of the histogram as a valley profile. Rain fills between the walls. For each lower bar, the water it can hold depends on the shorter of the two walls flanking it — like a bathtub filling up to the rim of the lower wall.
Core insight: A monotonic decreasing stack of bar indices lets you compute water layer by layer horizontally. When a taller bar appears, the popped bar is the bottom of a pool. The water height is min(left wall, right wall) − bottom, and width is the gap between the walls.
③ Step-by-step Logic
  1. Maintain a stack of bar indices in decreasing-height order.
  2. For each bar i: while stack top has height ≤ current bar's height, pop it as the pool bottom.
  3. If stack is non-empty after pop, left wall = stack top, right wall = i.
  4. Water height = min(h[left], h[i]) − h[bottom]; width = i − left − 1.
  5. Add width × water height to the total.
④ Annotated Code
#include <stdio.h>

int trap(int *h, int n) {
    int stack[n], top = -1, water = 0;
    for (int i = 0; i < n; i++) {
        while (top >= 0 && h[stack[top]] <= h[i]) {
            int bot = stack[top--];           /* pool floor */
            if (top < 0) break;              /* no left wall */
            int left  = stack[top];
            int bound = h[left] < h[i] ? h[left] : h[i];
            water += (bound - h[bot]) * (i - left - 1);
        }
        stack[++top] = i;
    }
    return water;
}

int main(void) {
    int h[] = {0,1,0,2,1,0,1,3,2,1,2,1};
    printf("%d\n", trap(h, 12));  /* 6 */
    return 0;
}

Pattern 11

Sum of Subarray Minimums

You have an array of numbers and you want to sum up the smallest value in every possible contiguous subarray. The naive approach checks all O(n²) subarrays, but a monotonic stack lets you figure out how many subarrays each element is the minimum of — and multiply once.
Core insight: For each element A[i], find the range [left_bound, right_bound] where A[i] is the minimum. The count of subarrays where A[i] is the minimum = (i − left) × (right − i). Sum A[i] × count for all i. Use a monotonic increasing stack to compute these boundaries in O(n).
③ Step-by-step Logic
  1. For each i, find left[i] = distance to the nearest smaller element to the left (or start).
  2. Find right[i] = distance to the nearest smaller-or-equal element to the right (or end). Use strict < on one side to avoid double-counting duplicates.
  3. contribution[i] = A[i] × left[i] × right[i].
  4. Answer = sum of all contributions (mod 1e9+7).
④ Annotated Code
#include <stdio.h>
#define MOD 1000000007

long long sum_subarray_min(int *A, int n) {
    int left[n], right[n];
    int stack[n], top = -1;

    /* left[i] = number of subarrays ending at i where A[i] is min */
    for (int i = 0; i < n; i++) {
        while (top >= 0 && A[stack[top]] >= A[i]) top--;
        left[i] = (top < 0) ? i + 1 : i - stack[top];
        stack[++top] = i;
    }

    top = -1;
    /* right[i] = number of subarrays starting at i where A[i] is min */
    for (int i = n - 1; i >= 0; i--) {
        while (top >= 0 && A[stack[top]] > A[i]) top--;
        right[i] = (top < 0) ? n - i : stack[top] - i;
        stack[++top] = i;
    }

    long long ans = 0;
    for (int i = 0; i < n; i++)
        ans = (ans + (long long)A[i] * left[i] % MOD * right[i]) % MOD;
    return ans;
}

int main(void) {
    int A[] = {3,1,2,4};
    printf("%lld\n", sum_subarray_min(A, 4));  /* 17 */
    return 0;
}
⑤ Dry Run

A stock analyst wants to know, for each day, how many consecutive days leading up to and including today had a price less than or equal to today's price. This "span" helps measure momentum. A monotonic stack of (price, span) pairs collapses consecutive dominated days in O(1) amortized.
Core insight: Maintain a stack of (price, span) pairs in decreasing-price order. When today's price is ≥ the top, pop it and absorb its span into today's span. The stack only keeps days that could still limit future spans.
③ Step-by-step Logic
  1. Initialize stack with a sentinel (INT_MAX price, span=0) to avoid empty-stack checks.
  2. For each price p, set span = 1.
  3. While stack top price ≤ p, pop and add its span to current span.
  4. Push (p, span) onto the stack.
  5. Output span for each day.
④ Annotated Code
#include <stdio.h>
#include <limits.h>

typedef struct { int price, span; } Frame;

void stock_span(int *prices, int n, int *span) {
    Frame stack[n+1];
    int top = 0;
    stack[0] = (Frame){INT_MAX, 0};   /* sentinel */

        while (stack[top].price <= prices[i])
            s += stack[top--].span;   /* absorb dominated spans */

        span[i] = s;
    }
}

}

int ocean_view(int *h, int n, int *result) {

Pattern 14

Remove K Digits (Monotonic Stack)

You have a number like "1432219" and need to remove exactly 3 digits to make the smallest possible number. Greedily, whenever you see a digit smaller than the one before it, removing the larger one reduces the number — like squeezing out bumps in the number.
Core insight: Use a monotonic increasing stack for the digits. Whenever the current digit is smaller than the stack top, pop the top (remove it) and decrement k. After the scan, if k > 0, pop from the top (remove trailing large digits). Then strip leading zeros.
③ Step-by-step Logic
  1. For each digit, while k > 0 and stack not empty and top > current digit, pop top (use one removal).
  2. Push current digit.
  3. After loop, if k > 0, truncate the stack by k from the top.
  4. Reconstruct the number, skipping leading zeros.
  5. Return "0" if the result is empty.
④ Annotated Code
#include <stdio.h>
#include <string.h>

void remove_k_digits(const char *num, int k, char *result) {
    int n = strlen(num);
    char stack[n+1];
    int top = -1;

    for (int i = 0; i < n; i++) {
        while (k > 0 && top >= 0 && stack[top] > num[i]) {
            top--;
            k--;
        }
        stack[++top] = num[i];
    }
    /* if k still > 0, remove from the end */
    top -= k;

    /* strip leading zeros */
    int start = 0;
    while (start < top && stack[start] == '0') start++;

    if (start > top) { result[0]='0'; result[1]='\0'; return; }
    int len = 0;
    for (int i = start; i <= top; i++) result[len++] = stack[i];
    result[len] = '\0';
}

int main(void) {
    char result[20];
    remove_k_digits("1432219", 3, result);
    printf("%s\n", result);   /* 1219 */
    remove_k_digits("10200", 1, result);
    printf("%s\n", result);   /* 200 → "0200" → strip → "200"... actually "0200"→leading→"200" wait → "0" if all removed */
    return 0;
}

132 Pattern Detection

You want to know if an array contains a subsequence (i, j, k) with i < j < k and nums[i] < nums[k] < nums[j] — like a 1-3-2 shape. The trick is to scan right to left: track the "2" candidate using a monotonic stack, and remember the best "3" seen so far.
Core insight: Scan from right to left. Keep a monotonic decreasing stack. Whenever you pop an element (because something bigger just appeared), that popped element is a valid "2" candidate — it's smaller than the current "3" (the element that caused the pop). If you ever see a "1" (nums[i]) smaller than the best "2", you found the pattern.
③ Step-by-step Logic
  1. Scan right to left, maintain a monotonic decreasing stack.
  2. Track `third` = the best "2" candidate seen so far (initialized to INT_MIN).
  3. When nums[i] > stack top, pop into `third` (it's a valid "2" since a larger "3" exists to its right).
  4. If nums[i] < third, then nums[i] is "1", third is "2", the element that caused the pop is "3" → return true.
  5. Push nums[i] as a "3" candidate.
④ Annotated Code
#include <stdio.h>
#include <limits.h>

int find132pattern(int *nums, int n) {
    int stack[n], top = -1;
    int third = INT_MIN;   /* best "2" candidate (nums[k] in i<j<k) */

    for (int i = n - 1; i >= 0; i--) {
        if (nums[i] < third) return 1;          /* nums[i] is "1" */
        while (top >= 0 && stack[top] < nums[i])
            third = stack[top--];               /* pop: becomes "2" */
        stack[++top] = nums[i];                 /* push as "3" candidate */
    }
    return 0;
}

    printf("%d\n", find132pattern(a, 4));  /* 1 (1,4,2) */
    int b[] = {1,2,3,4};
    printf("%d\n", find132pattern(b, 4));  /* 0 */
    return 0;
}

Pattern 16

Max Width Ramp

A "ramp" in an array is a pair (i, j) where i < j and A[i] ≤ A[j]. The width of the ramp is j − i. Find the maximum width ramp. Think of it as: find the farthest apart pair where the left value doesn't exceed the right value.
Core insight: In two passes — first, build a decreasing stack of "left candidate" indices (only indices where A[i] is a new minimum from the left are useful left endpoints). Then scan from right to left, and for each right index j, pop from the stack while A[stack top] ≤ A[j], recording j − stack top as the width.
③ Step-by-step Logic
  1. Forward pass: push index i onto stack only if A[i] is smaller than all previous stack tops (strict decreasing prefix minima).
  2. Backward pass: scan j from n−1 to 0.
  3. While stack not empty and A[stack top] ≤ A[j], pop and update max width = j − popped_index.
  4. Continue (don't break after pop — j can match multiple left candidates).
④ Annotated Code
#include <stdio.h>

int max_width_ramp(int *A, int n) {
    int stack[n], top = -1;

    /* build decreasing-value prefix stack */
    for (int i = 0; i < n; i++)
        if (top < 0 || A[stack[top]] > A[i])
            stack[++top] = i;

    int ans = 0;
    /* scan right to left, greedily match deepest left candidate */
    for (int j = n - 1; j >= 0; j--) {
        while (top >= 0 && A[stack[top]] <= A[j]) {
            int w = j - stack[top--];
            if (w > ans) ans = w;
        }
    }
    return ans;
}

int main(void) {
    int A[] = {6,0,8,2,1,5};
    printf("%d\n", max_width_ramp(A, 6));  /* 4  (pair: i=1,j=5, A[1]=0<=A[5]=5) */
    return 0;
}

  2. For each row: update each height — increment if cell='1', reset to 0 if '0'.

#include <stdio.h>

static int hist_max(int *h, int n) {
    int stack[n+1], top = -1, best = 0;
    for (int i = 0; i <= n; i++) {
        int cur = (i == n) ? 0 : h[i];
        while (top >= 0 && h[stack[top]] >= cur) {
            int ht = h[stack[top--]];
            int w  = (top < 0) ? i : i - stack[top] - 1;
            if (ht * w > best) best = ht * w;
        }
        stack[++top] = i;
    }
    return best;
}

        for (int c = 0; c < cols; c++)
            heights[c] = (matrix[r][c] == '1') ? heights[c] + 1 : 0;
        int a = hist_max(heights, cols);
        if (a > ans) ans = a;
    }
    return ans;
}

  4. On letter: append to current string.
  5. Return current string at the end.

Pattern 19

Asteroid Collision

Asteroids move in a row, some going right (+) and some left (−). When a right-moving asteroid meets a left-moving asteroid head-on, the smaller one explodes. Same size = both explode. Right-going asteroids never collide with each other. Model this with a stack: the stack holds the surviving asteroids.
Core insight: Only a collision can happen when a negative asteroid (moving left) encounters a positive one (moving right) at the top of the stack. Keep processing until the negative one survives or gets destroyed. Push surviving asteroids onto the stack.
③ Step-by-step Logic
  1. For each asteroid a: if a > 0, push it (no collision yet).
  2. If a < 0: while stack not empty and top > 0 (collision): if |a| > top, pop (top destroyed); if |a| == top, pop and mark a dead; if |a| < top, mark a dead.
  3. If a is still alive after collisions, push it.
④ Annotated Code
#include <stdio.h>

int asteroid_collision(int *ast, int n, int *result) {
    int stack[n], top = -1;

    for (int i = 0; i < n; i++) {
        int a = ast[i];
        int alive = 1;
        while (alive && a < 0 && top >= 0 && stack[top] > 0) {
            if (stack[top] < -a)       { top--; }          /* top explodes */
            else if (stack[top] == -a) { top--; alive = 0; }/* both explode */
            else                       {        alive = 0; }/* a explodes   */
        }
        if (alive) stack[++top] = a;
    }
    int cnt = top + 1;
    for (int i = 0; i < cnt; i++) result[i] = stack[i];
    return cnt;
}

    int ast[] = {5, 10, -5};
    int result[3];
    int cnt = asteroid_collision(ast, 3, result);
    for (int i = 0; i < cnt; i++) printf("%d ", result[i]);
    /* 5 10 */
    return 0;
}

Monotonic Stack — Previous/Next Smaller & Greater (Template)

Four variations of the same idea: for each element, find the nearest element to the left (or right) that is strictly smaller (or strictly greater). These four queries — previous smaller, next smaller, previous greater, next greater — are the building blocks for dozens of harder problems. Knowing the template cold saves time on every monotonic-stack problem.
Core insight: The direction of scan and the comparison operator determine which of the four queries you compute. Pop when the new element "wins" against the top — the top's answer is the new element. What remains in the stack at the end has no answer (−1 or n).
③ Step-by-step Logic
  1. Choose scan direction: left→right for NEXT queries, right→left for PREVIOUS queries.
  2. Choose comparison: pop when A[new] < A[top] for SMALLER; pop when A[new] > A[top] for GREATER.
  3. On pop: ans[top_index] = new_element (or new_index for distance).
  4. Push current index; remaining stack at end has no answer.
④ Annotated Code
#include <stdio.h>

/* Template: next smaller element for each index */
void next_smaller(int *A, int n, int *ans) {
    int stack[n], top = -1;
    for (int i = 0; i < n; i++) ans[i] = -1;

    for (int i = 0; i < n; i++) {
        /* pop: A[i] is the next smaller for stack top */
        while (top >= 0 && A[stack[top]] > A[i])
            ans[stack[top--]] = A[i];
        stack[++top] = i;
    }
}

/* Variant: previous greater element for each index */
void prev_greater(int *A, int n, int *ans) {
    int stack[n], top = -1;
    for (int i = 0; i < n; i++) ans[i] = -1;

    for (int i = 0; i < n; i++) {
        /* pop: not the previous greater; current is answer */
        while (top >= 0 && A[stack[top]] <= A[i])
            top--;
        ans[i] = (top < 0) ? -1 : A[stack[top]];
        stack[++top] = i;
    }
}

    prev_greater(A, 5, pg);
    for (int i=0;i<5;i++) printf("ns[%d]=%d pg[%d]=%d\n",i,ns[i],i,pg[i]);
    return 0;
}

Pattern 21

Basic Calculator I (Parentheses + +/−)

Evaluate a math expression with only '+', '−', spaces, and parentheses — no '*' or '/'. The challenge is parentheses: a '−' before '(' flips the sign of everything inside. A stack saves the running total and the current sign before each '('.
Core insight: Track a running result and a current sign (+1 or −1). On '(', push the current result and sign onto the stack, then reset both. On ')', pop the saved sign and result and combine: result = saved_result + saved_sign × current_result.
③ Step-by-step Logic
  1. Maintain `result` (running total), `num` (current number being parsed), `sign` (+1 or −1).
  2. On digit: build num = num×10 + digit.
  3. On '+'/'-': flush num into result (result += sign × num); update sign; reset num=0.
  4. On '(': push result and sign; reset result=0, sign=+1.
  5. On ')': flush num; result = stack_result + stack_sign × result; pop.
  6. Final: flush any remaining num.
④ Annotated Code
#include <stdio.h>
#include <ctype.h>

int calculate(const char *s) {
    int result = 0, num = 0, sign = 1;
    int res_stack[100], sign_stack[100], top = -1;

    for (int i = 0; s[i]; i++) {
        char c = s[i];
        if (isdigit(c)) {
            num = num * 10 + (c - '0');
        } else if (c == '+' || c == '-') {
            result += sign * num;
            num = 0;
            sign = (c == '+') ? 1 : -1;
        } else if (c == '(') {
            res_stack[++top]  = result;
            sign_stack[top]   = sign;
            result = 0; sign = 1;
        } else if (c == ')') {
            result += sign * num;
            num = 0;
            result = res_stack[top] + sign_stack[top] * result;
            top--;
        }
    }
    return result + sign * num;
}

int main(void) {
    printf("%d\n", calculate("1 + (2 - (3 + 1))"));  /* -1 */
    printf("%d\n", calculate("(1+(4+5+2)-3)+(6+8)")); /* 23 */
    return 0;
}

Basic Calculator II (+/−/×/÷, no parentheses)

Now the expression has all four operations but no parentheses. The trick: you can't just process left to right because × and ÷ bind tighter than + and −. Instead, defer additions and subtractions, but apply multiplications and divisions immediately to the most recent term on a stack.
Core insight: Push numbers onto a stack. For '+'/'-', push +num or −num. For '×'/'÷', pop the last number, apply the operation, push back the result. Final answer = sum of everything on the stack (all additions and subtractions were already baked in as signs).
③ Step-by-step Logic
  1. Track last_op (starts as '+'), num (current parsed number).
  2. On operator or end-of-string: apply last_op to num and the stack.
  3. For '+': push num. For '−': push −num.
  4. For '×': pop top, push top × num. For '÷': pop top, push top / num.
  5. Sum the stack for the result.
④ Annotated Code
#include <stdio.h>
#include <ctype.h>

int calculate2(const char *s) {
    int stack[200], top = -1, num = 0;
    char last_op = '+';

    for (int i = 0; s[i] || i == 0; i++) {
        char c = s[i];
        if (isdigit(c)) {
            num = num * 10 + (c - '0');
        }
        if ((!isdigit(c) && c != ' ') || s[i+1] == '\0') {
            /* flush: apply last_op with num */
            if (last_op == '+')      stack[++top] =  num;
            else if (last_op == '-') stack[++top] = -num;
            else if (last_op == '*') stack[top]  *= num;
            else if (last_op == '/') stack[top]  /= num;
            last_op = c;
            num = 0;
        }
    }
    int result = 0;
    while (top >= 0) result += stack[top--];
    return result;
}

int main(void) {
    printf("%d\n", calculate2("3+2*2"));       /* 7 */
    printf("%d\n", calculate2(" 3/2 "));       /* 1 */
    printf("%d\n", calculate2(" 3+5 / 2 "));   /* 5 */
    return 0;
}

Infix to Postfix (Shunting-Yard)

Compilers convert human-readable infix expressions (3 + 4 × 2) into postfix (3 4 2 × +) where operands always precede their operator — no parentheses needed. Dijkstra's shunting-yard algorithm uses a stack to hold operators waiting for a lower-precedence operator or ')' to flush them.
Core insight: Numbers go directly to output. Operators wait on a stack; pop and output any stack operator with equal-or-higher precedence before pushing the new one. '(' pushes unconditionally; ')' pops until '('.
③ Step-by-step Logic
  1. For each token: if number, append to output.
  2. If '(', push onto operator stack.
  3. If ')', pop and output until '(' is found; discard '('.
  4. If operator op, while stack top is an operator with prec ≥ prec(op), pop and output; then push op.
  5. At end, pop all remaining operators to output.
④ Annotated Code
#include <stdio.h>
#include <ctype.h>
#include <string.h>

static int prec(char op) {
    if (op == '+' || op == '-') return 1;
    if (op == '*' || op == '/') return 2;
    return 0;
}

void infix_to_postfix(const char *in, char *out) {
    char op_stack[100]; int top = -1;
    int oi = 0;

    for (int i = 0; in[i]; i++) {
        char c = in[i];
        if (isdigit(c)) {
            out[oi++] = c; out[oi++] = ' ';
        } else if (c == '(') {
            op_stack[++top] = c;
        } else if (c == ')') {
            while (top >= 0 && op_stack[top] != '(')
                { out[oi++] = op_stack[top--]; out[oi++] = ' '; }
            top--;  /* discard '(' */
        } else if (prec(c)) {
            while (top >= 0 && prec(op_stack[top]) >= prec(c))
                { out[oi++] = op_stack[top--]; out[oi++] = ' '; }
            op_stack[++top] = c;
        }
    }
    while (top >= 0) { out[oi++] = op_stack[top--]; out[oi++] = ' '; }
    out[oi] = '\0';
}

int main(void) {
    char out[100];
    infix_to_postfix("3+4*2", out);
    printf("%s\n", out);  /* 3 4 2 * + */
    infix_to_postfix("(3+4)*2", out);
    printf("%s\n", out);  /* 3 4 + 2 * */
    return 0;
}

Simplify Unix Path

A Unix path like "/home/../usr//local/./bin" resolves to "/usr/local/bin". Split on '/', process each component: push real directory names, pop on '..', ignore '.' and empty tokens.
Core insight: Split the path by '/' and use a stack of directory names. Push on a real name, pop on '..', do nothing on '.' or empty string. Then join the stack with '/' separators.
③ Step-by-step Logic
  1. Tokenize path by '/' using strtok or a manual scanner.
  2. For each token: if empty or ".", skip. If "..", pop (if non-empty stack). Otherwise push the token.
  3. Reconstruct: join stack elements with "/" prefix for each.
  4. If stack empty, return "/".
④ Annotated Code
#include <stdio.h>
#include <string.h>

void simplify_path(const char *path, char *result) {
    char buf[300], *parts[100];
    int top = -1;
    strncpy(buf, path, 299);

    char *tok = strtok(buf, "/");
    while (tok) {
        if (strcmp(tok, "..") == 0) {
            if (top >= 0) top--;
        } else if (strcmp(tok, ".") != 0 && tok[0] != '\0') {
            parts[++top] = tok;
        }
        tok = strtok(NULL, "/");
    }

    if (top < 0) { strcpy(result, "/"); return; }
    int ri = 0;
    for (int i = 0; i <= top; i++) {
        result[ri++] = '/';
        for (int j = 0; parts[i][j]; j++) result[ri++] = parts[i][j];
    }
    result[ri] = '\0';
}

int main(void) {
    char out[300];
    simplify_path("/home/../usr//local/./bin", out);
    printf("%s\n", out);  /* /usr/local/bin */
    simplify_path("/../", out);
    printf("%s\n", out);  /* / */
    return 0;
}

Score of Parentheses

A balanced parentheses string has a score: "()" = 1, and nesting doubles — "(())" = 2. Concatenation adds — "()()" = 2. You want to compute the score without recursion, using a stack that tracks the running score at each depth level.
Core insight: The stack holds the accumulated score at each nesting depth. On '(', push 0 (start a new level). On ')', pop the inner score v: if v == 0 the pair is "()" so contribute 1; otherwise contribute 2×v. Add that to the new top.
③ Step-by-step Logic
  1. Initialize stack with 0 (the base level score).
  2. On '(': push 0.
  3. On ')': pop v. Add max(2×v, 1) to the new top (1 if inner was empty "()", 2×v otherwise).
  4. Return stack[0] at the end.

            stack[top] += (v == 0) ? 1 : 2 * v;
        }
    }
    return stack[0];
}

Recursive DFS uses the call stack implicitly. Converting it to an iterative version uses an explicit stack — useful when the graph is huge (stack overflow risk) or when you need fine-grained control over the traversal (e.g. detecting back edges).
Core insight: Push the start node. While stack not empty: pop a node, process it, push its unvisited neighbors. The order of neighbor pushing determines traversal order (push in reverse to match recursive DFS order).
③ Step-by-step Logic

Binary Tree Inorder Traversal (Iterative)

Inorder traversal (left, root, right) of a BST produces sorted output. Recursive inorder uses the call stack; the iterative version mimics it: dive left as far as possible, visit when you can't go further left, then step right.
Core insight: Use a stack and a current pointer. Push nodes while going left. When current is NULL, pop a node (visit it), then set current to its right child. This perfectly mirrors the recursive call stack.
③ Step-by-step Logic
  1. current = root, stack empty.
  2. While current != NULL or stack not empty:
  3. Push current and go left until NULL.
  4. Pop node, visit (print) it.
  5. Set current = node→right.
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *left, *right; } Node;

Node *new_node(int v) {
    Node *n = malloc(sizeof(Node));
    n->val = v; n->left = n->right = NULL;
    return n;
}

void inorder_iterative(Node *root) {
    Node *stack[50], *cur = root;
    int top = -1;

    while (cur || top >= 0) {
        while (cur) { stack[++top] = cur; cur = cur->left; }
        cur = stack[top--];
        printf("%d ", cur->val);
        cur = cur->right;
    }
}

int main(void) {
    /*       4
            / \
           2   6
          / \ / \
         1  3 5  7   */
    Node *root = new_node(4);
    root->left = new_node(2); root->right = new_node(6);
    root->left->left = new_node(1); root->left->right = new_node(3);
    root->right->left = new_node(5); root->right->right = new_node(7);
    inorder_iterative(root);   /* 1 2 3 4 5 6 7 */
    return 0;
}
⑤ Dry Run
root=4 cur=4→push 4, cur=2→push 2, cur=1→push 1, cur=NULL pop 1, visit 1. cur=1->right=NULL pop 2, visit 2. cur=2->right=3 push 3, cur=NULL pop 3, visit 3. cur=NULL pop 4, visit 4. cur=4->right=6 push 6, cur=5→push 5, cur=NULL pop 5, visit 5. cur=NULL pop 6, visit 6. cur=7→push 7, cur=NULL pop 7, visit 7. Output: 1 2 3 4 5 6 7 ✓
⚠ Gotcha: Loop condition includes both cur and stack

The while loop must continue as long as either cur != NULL or the stack is non-empty. Using only one condition exits early — cur becomes NULL before the stack is drained when visiting a node with no right child.

Pattern 28

Binary Tree Preorder & Postorder (Iterative)

Preorder (root, left, right) and postorder (left, right, root) can also be done iteratively. Preorder is natural with a stack — visit on push. Postorder is trickier but has a neat trick: reverse preorder with right-before-left gives postorder.
Core insight for preorder: push root, loop: pop, visit, push right then left (so left is processed first). For postorder: same as preorder but push left then right (reverse), and reverse the output at the end — or use a two-stack method.
③ Step-by-step Logic
  1. Preorder: push root. While not empty: pop u, visit, push u→right, push u→left.
  2. Postorder (reverse trick): push root. While not empty: pop u, prepend to output, push u→left, push u→right. Output is reversed preorder = postorder.
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int val; struct Node *left, *right; } Node;

void preorder(Node *root) {
    Node *stack[50]; int top = -1;
    if (!root) return;
    stack[++top] = root;
    while (top >= 0) {
        Node *u = stack[top--];
        printf("%d ", u->val);                    /* visit on pop */
        if (u->right) stack[++top] = u->right;   /* right pushed first */
        if (u->left)  stack[++top] = u->left;    /* left popped first  */
    }
}

void postorder(Node *root) {
    Node *stack[50]; int top = -1;
    int out[50]; int oi = 0;
    if (!root) return;
    stack[++top] = root;
    while (top >= 0) {
        Node *u = stack[top--];
        out[oi++] = u->val;                       /* collect (reversed) */
        if (u->left)  stack[++top] = u->left;    /* push left first    */
        if (u->right) stack[++top] = u->right;   /* right popped first */
    }
    for (int i = oi-1; i >= 0; i--) printf("%d ", out[i]);
}

/* tree: 1->(2->(4,5), 3) */
⑤ Dry Run
Tree: 1(2(4,5), 3) Preorder: stack=[1]; pop 1 visit. push right=3, push left=2. stack=[3,2] pop 2 visit. push right=5, push left=4. stack=[3,5,4] pop 4 visit. no children. stack=[3,5] pop 5 visit. no children. stack=[3] pop 3 visit. no children. Output: 1 2 4 5 3 ✓ Postorder (reverse trick): Collect reversed: 1,3,5,4,2 → reversed = 2 4 5 3 1 ✓
⚠ Gotcha: Push order is reversed from desired visit order

For preorder (root, left, right): push right before left so left is popped (processed) first. It feels backwards — remember that the stack reverses order. Push what you want processed last first.

Pattern 29

Flatten Nested List Iterator (Stack)

A nested list like [[1,2],[3,[4,5]]] needs to be flattened to 1,2,3,4,5. A stack-based iterator does this lazily — it only unpacks the next level when asked for the next integer, perfect for streaming large nested structures.
Core insight: Initialize the stack with the outermost list (in reverse). When peeking at the top: if it's an integer, ready; if it's a list, pop it and push its elements in reverse. This ensures the leftmost element is always at the top when ready.
③ Step-by-step Logic
  1. Define a tagged union for NestedInteger (int or list).
  2. Initialize stack by pushing root list elements in reverse.
  3. hasNext(): while top is a list, pop it and push its elements in reverse.
  4. next(): call hasNext(), then pop and return the top integer.
④ Annotated Code
#include <stdio.h>
#include <stdlib.h>

typedef struct NestedInt {
    int is_int;
    int val;
    struct NestedInt **list;
    int list_len;
} NI;

NI *make_int(int v) {
    NI *n = malloc(sizeof(NI)); n->is_int = 1; n->val = v; return n;
}
NI *make_list(NI **arr, int len) {
    NI *n = malloc(sizeof(NI)); n->is_int = 0; n->list = arr; n->list_len = len; return n;
}

NI *stack[200]; int top = -1;

void push_list(NI *lst) {
    for (int i = lst->list_len - 1; i >= 0; i--)
        stack[++top] = lst->list[i];
}

int has_next(void) {
    while (top >= 0 && !stack[top]->is_int)
        push_list(stack[top--]);
    return top >= 0;
}

int next_val(void) {
    has_next();
    return stack[top--]->val;
}

int main(void) {
    /* [[1,2],[3,[4,5]]] */
    NI *inner[] = {make_int(4), make_int(5)};
    NI *mid[]   = {make_int(3), make_list(inner, 2)};
    NI *outer[] = {make_list((NI*[]){make_int(1),make_int(2)}, 2),
                   make_list(mid, 2)};
    NI root = {0, 0, outer, 2};
    push_list(&root);
    while (has_next()) printf("%d ", next_val());  /* 1 2 3 4 5 */
    return 0;
}
⑤ Dry Run
[[1,2],[3,[4,5]]] init: push [3,[4,5]] then [1,2]. stack=[[1,2],[3,[4,5]]] has_next: top=[3,[4,5]] is list → pop, push [4,5] then 3. stack=[[1,2],3,[4,5]] ... actually: push root list in reverse: push [3,[4,5]], then [1,2]. stack=[[3,[4,5]],[1,2]] has_next: [1,2] is list → pop, push 2,1. stack=[[3,[4,5]],2,1] next: pop 1 → 1 next: pop 2 → 2 has_next: [3,[4,5]] is list → pop, push [4,5],3. stack=[[4,5],3] next: pop 3 → 3 has_next: [4,5] is list → pop, push 5,4. stack=[5,4] next: 4, then 5. Output: 1 2 3 4 5 ✓
⚠ Gotcha: Push list elements in reverse

To preserve left-to-right order, push elements from right to left so the leftmost element ends up on top of the stack. If you push left-to-right, elements come out reversed.

Pattern 30

Queue Using Two Stacks

You only have a stack (LIFO) but need a queue (FIFO). Use two stacks: push everything into the "inbox" stack; when dequeuing, if the "outbox" is empty, pour all inbox items into outbox (reversing order). The outbox then dispenses them in FIFO order.
Core insight: Items are transferred from inbox to outbox lazily — only when outbox is empty. Each item is transferred at most once total, giving O(1) amortized dequeue despite the occasional O(n) transfer.
③ Step-by-step Logic
  1. enqueue(x): push x onto inbox.
  2. dequeue(): if outbox empty, pop all from inbox onto outbox. Pop from outbox.
  3. peek(): same transfer logic, then peek outbox top without popping.
  4. empty(): both stacks empty.
④ Annotated Code
#include <stdio.h>

typedef struct {
    int inbox[100],  in_top;
    int outbox[100], out_top;
} MyQueue;

void q_init(MyQueue *q) { q->in_top = q->out_top = -1; }

void q_push(MyQueue *q, int x) { q->inbox[++q->in_top] = x; }

static void transfer(MyQueue *q) {
    if (q->out_top < 0)
        while (q->in_top >= 0)
            q->outbox[++q->out_top] = q->inbox[q->in_top--];
}

int q_pop(MyQueue *q)  { transfer(q); return q->outbox[q->out_top--]; }
int q_peek(MyQueue *q) { transfer(q); return q->outbox[q->out_top];   }
int q_empty(MyQueue *q){ return q->in_top < 0 && q->out_top < 0;     }

int main(void) {
    MyQueue q; q_init(&q);
    q_push(&q, 1); q_push(&q, 2); q_push(&q, 3);
    printf("%d\n", q_pop(&q));   /* 1 */
    printf("%d\n", q_peek(&q));  /* 2 */
    q_push(&q, 4);
    printf("%d\n", q_pop(&q));   /* 2 */
    printf("%d\n", q_pop(&q));   /* 3 */
    return 0;
}
⑤ Dry Run
push 1,2,3: inbox=[1,2,3], outbox=[] pop: outbox empty → transfer: outbox=[3,2,1]; pop outbox top=1. outbox=[3,2] peek: outbox non-empty → peek outbox top=2. push 4: inbox=[4], outbox=[3,2] pop: outbox non-empty → pop 2. outbox=[3] pop: outbox non-empty → pop 3. outbox=[] Output: 1 2 2 3 ✓
⚠ Gotcha: Only transfer when outbox is completely empty

Transfer inbox→outbox only when outbox is empty. If you transfer on every dequeue, you break FIFO order by mixing partially consumed outbox items with newly transferred ones.

Stack with getMax() / getMin() in O(1)

A stack that also answers "what's the current maximum?" in O(1) at any time. Naively scanning the stack is O(n). The trick: maintain a parallel max-stack that stores the running maximum at each level — updated on every push, and popped in sync.
Core insight: On push(x), the new running maximum = max(x, max_stack top). Push that onto the max_stack. On pop, pop both stacks in sync. max_stack top always holds the current maximum of all elements in the data stack.
③ Step-by-step Logic
  1. Maintain two stacks: data[] and max_s[].
  2. push(x): push x on data; push max(x, max_s top) on max_s.
  3. pop(): pop both data and max_s; return data popped value.
  4. getMax(): return max_s top (current maximum).
  5. For getMin(): same pattern, store running min instead.
④ Annotated Code
#include <stdio.h>

typedef struct {
    int data[100], max_s[100], top;
} MaxStack;

void ms_init(MaxStack *s) { s->top = -1; }

void ms_push(MaxStack *s, int x) {
    s->data[++s->top] = x;
    int prev_max = (s->top == 0) ? x : s->max_s[s->top - 1];
    s->max_s[s->top] = (x > prev_max) ? x : prev_max;
}

int ms_pop(MaxStack *s) {
    return s->data[s->top--];  /* max_s[top] automatically invalidated */
}

int ms_get_max(MaxStack *s) { return s->max_s[s->top]; }

int main(void) {
    MaxStack s; ms_init(&s);
    ms_push(&s, 3);
    ms_push(&s, 1);
    ms_push(&s, 5);
    printf("max=%d\n", ms_get_max(&s));  /* 5 */
    ms_pop(&s);
    printf("max=%d\n", ms_get_max(&s));  /* 3 */
    ms_pop(&s);
    printf("max=%d\n", ms_get_max(&s));  /* 3 */
    return 0;
}
⑤ Dry Run
push 3: data=[3], max_s=[3] push 1: data=[3,1], max_s=[3,3] (max(1,3)=3) push 5: data=[3,1,5], max_s=[3,3,5] getMax()=5 ✓ pop(): data=[3,1], max_s=[3,3] getMax()=3 ✓ pop(): data=[3], max_s=[3] getMax()=3 ✓
⚠ Gotcha: max_s stores the running max, not the pushed element

max_s[i] is not just the pushed element — it's the maximum of everything from index 0 to i. If you only store pushed values, popping an intermediate maximum leaves max_s out of sync with the true maximum below it.

Largest Rectangle in Histogram — Two-Pass (Simpler Variant)

An alternative approach to the classic histogram problem (P09): for each bar, find its left boundary (first shorter bar to the left) and its right boundary (first shorter bar to the right) separately in two dedicated passes, then compute area = height × (right − left − 1). This is O(n) with two stacks and easier to debug step by step.
Core insight: left_boundary[i] = index of the nearest bar shorter than h[i] to the left (or −1). right_boundary[i] = index of the nearest bar shorter than h[i] to the right (or n). Area at i = h[i] × (right[i] − left[i] − 1). The two separate passes make the logic explicit.
③ Step-by-step Logic
  1. Left pass (left to right): monotonic increasing stack. On each i, pop while stack top ≥ h[i]; left[i] = stack top index (or −1 if empty). Push i.
  2. Right pass (right to left): same but scanning backwards; right[i] = stack top index (or n if empty).
  3. Compute area[i] = h[i] × (right[i] − left[i] − 1) for each i; return max.
④ Annotated Code
#include <stdio.h>

int largest_rect_two_pass(int *h, int n) {
    int left[n], right[n];
    int stack[n], top = -1;

    /* left boundary: nearest index with h < h[i] */
    for (int i = 0; i < n; i++) {
        while (top >= 0 && h[stack[top]] >= h[i]) top--;
        left[i] = (top < 0) ? -1 : stack[top];
        stack[++top] = i;
    }

    top = -1;
    /* right boundary: nearest index with h < h[i] */
    for (int i = n-1; i >= 0; i--) {
        while (top >= 0 && h[stack[top]] >= h[i]) top--;
        right[i] = (top < 0) ? n : stack[top];
        stack[++top] = i;
    }

    int ans = 0;
    for (int i = 0; i < n; i++) {
        int area = h[i] * (right[i] - left[i] - 1);
        if (area > ans) ans = area;
    }
    return ans;
}

int main(void) {
    int h[] = {2,1,5,6,2,3};
    printf("%d\n", largest_rect_two_pass(h, 6));  /* 10 */
    return 0;
}
⑤ Dry Run
h=[2,1,5,6,2,3] Left pass: i=0: stack empty, left[0]=-1. push 0 i=1: h[0]=2>=1→pop; stack empty, left[1]=-1. push 1 i=2: h[1]=1<5; left[2]=1. push 2 i=3: h[2]=5<6; left[3]=2. push 3 i=4: h[3]=6>=2→pop; h[2]=5>=2→pop; h[1]=1<2; left[4]=1. push 4 i=5: h[4]=2<3; left[5]=4. push 5 left=[-1,-1,1,2,1,4] Right pass (symmetric): right=[1,6,4,4,6,6] Areas: 2*(1-(-1)-1)=2, 1*(6-(-1)-1)=6, 5*(4-1-1)=10, 6*(4-2-1)=6, 2*(6-1-1)=8, 3*(6-4-1)=3 max=10 ✓
⚠ Gotcha: Use strict < when finding boundaries (handle equal heights)

When finding boundaries, pop equal-height bars (>=) to avoid assigning both equal-height bars as each other's boundaries — that would over-count width. If h=[3,3], each should see the other as a boundary; with >= on both sides each bar's area is correctly limited to its own span.
